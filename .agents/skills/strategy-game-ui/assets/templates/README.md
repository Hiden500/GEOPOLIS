# Audit templates

Copy or adapt these templates only when the user asks for a persistent artifact.
For conversational audits, use their structure without creating files.

- [scenario-interface-matrix.md](scenario-interface-matrix.md) — derive surfaces
  from player scenarios and information timing.
- [state-coverage-matrix.md](state-coverage-matrix.md) — record applicable
  interaction and strategy-domain states.
- [visual-qa-register.md](visual-qa-register.md) — capture rendered evidence by
  viewport, input, locale, and state.
- [audit-report.md](audit-report.md) — final evidence-based audit report.

Templates intentionally contain no fixed screen list. Add rows only after
repository evidence establishes a mechanic, scenario, or existing surface.
