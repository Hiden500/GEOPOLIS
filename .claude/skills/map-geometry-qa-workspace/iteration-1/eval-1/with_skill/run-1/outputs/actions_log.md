## Как проверялась claim "идемпотентно / 0 при повторном прогоне"

Сам `diagnose_coastline_gaps.py` ничего не чинит и не имеет состояния между
запусками (каждый прогон — чистый пересчёт по текущим файлам), поэтому
буквальной "idempotent-претензии" у него самого нет. Но у скриптов, чьи
результаты он проверяет (`fix_lake_coastline_gaps.py` и общий
`absorb_slivers`), такая claim есть и явно задокументирована в SKILL.md как
**недостаточное** доказательство полноты ("идемпотентно, 0 на повторном
прогоне" доказывает СХОДИМОСТЬ алгоритма, не ПОЛНОТУ покрытия — реальный
разрыв может стабильно и молча отклоняться на каждом прогоне).

Я не перезапускал сами эти фиксирующие скрипты (см. выше, почему). Вместо
этого я проверил их результат независимо: запустил read-only диагностику
заново на сегодняшних данных (а не поверил логам прошлых прогонов) и
дополнительно подтвердил рендером конкретные точки, включая специально
Great Lakes (заявленный как "исправлено 2026-07-23" по claim'у именно этого
типа) — сегодня там 0 кандидатов, то есть claim для Great Lakes сегодня
подтверждается независимо, а не принимается на слово. Для COASTLINE-находок
2026-07-24 (ещё не чинившихся, значит "idempotent"-вопрос к ним пока не
применим) проверка была другого рода — не "чинили ли повторно", а "не
проглядел ли сам скрипт лишнее" (см. ниже).

## Как отличались реальные разрывы от шума (метод)

Числовой сигнал сам по себе не считался достаточным ни разу — по каждому
кандидату, отобранному как "интересный" (крупный по площади, экстремальный
по aspect ratio, или geографически ещё не проверенный в прошлой сессии),
делался рендер конкретного bbox и визуальный просмотр:

1. **Де-дупликация по тайлам** — числовая правка (991->715 ячеек), не
   визуальная, но меняющая итоговую цифру почти на треть.
2. **Aspect ratio (соотношение сторон minimum_rotated_rectangle)** — считался
   для ВСЕХ COASTLINE-ячеек (скрипт считает его только для не-водных),
   чтобы проверить гипотезу "не прячется ли шум административных границ
   внутри COASTLINE, куда aspect-фильтр не долетает". Гипотеза частично
   подтвердилась (Мексикали, мыс Доброй Надежды), но по большей части НЕ
   подтвердилась — многие ячейки с высоким aspect ratio (Флорида,
   Нью-Джерси) оказались настоящими при рендере.
3. **Геодезическая ширина в км (не в градусах)** — отсеяла явно
   субметровый/суб-100-метровый масштаб (антимеридианная пара, 9 м) от
   реального километрового масштаба (почти все остальные, 0.5-13 км).
4. **Рендер + просмотр глазами** — финальный и решающий шаг для каждого
   отобранного кандидата; заменил и aspect ratio, и ширину там, где они
   давали неоднозначный сигнал (Флорида/Нью-Джерси: высокий aspect ratio +
   небольшая ширина, но при этом РЕАЛЬНЫЕ, потому что лента идёт ВДОЛЬ
   природной береговой линии, а не поперёк к чужой границе).
5. **Топологическое наблюдение по итогам рендеров** (не встроено в код,
   просто вывод из просмотра): лента-шум обычно идёт от берега ВГЛУБЬ суши
   к государственной/секторной границе; настоящий разрыв идёт ВДОЛЬ самой
   береговой линии. Ни compactness, ни aspect ratio, ни ширина сама по себе
   этого не различают — только рендер (или отдельная, не реализованная
   здесь проверка на совпадение направления ленты с направлением берега).
6. **Кросс-чек с docs/TODO.md и docs/DECISIONS.md** — чтобы не путать "новую
   находку" с уже известной (Great Lakes, Гренландия/Шпицберген,
   Brazil/Paraguay кластер) и не повторять уже сделанную работу без нужды.
