# Открытые вопросы калибровки/дизайна

**Калибровка ВВП/чел бедных стран 1946** (найдено 2026-07-06, не решено):
страны с очень низким стартовым ВВП/чел (`CHN` ~$83/чел против референса $850,
также `ARG`/`BRA`/`ITA`) теряют население даже в мирное время — формула
`standardOfLiving = min(gdpPerCapita/850, 2)` корректно даёт им множитель у
нижнего пола 0.5, это не баг "неверный ключ/константа". Два возможных
источника: (а) формула рождаемости слишком резко давит на нижнем конце шкалы
ВВП/чел (историческая рождаемость у бедных аграрных стран в 1946 обычно была
ВЫШЕ, не ниже — см. `docs/HISTORICAL_ACCURACY.md`), (б) стартовые региональные
экономические данные занижены относительно источников (`docs/SCENARIOS.md`
отмечает, что числа 128 стран не калибровались по надёжным источникам).
Решать перед кодом — не понижать `MAX_PEACETIME_ANNUAL_POPULATION_DECLINE` в
тесте, чтобы скрыть. **Кандидат на историческую калибровку Gemini** — не
выбрано формально пользователем.

**Национальные цели стран — приостановлено пользователем 2026-07-06.**
Черновик (только major, read-only, ~10 целей, план по СССР как иллюстрация
формата) остановлен — пользователь усомнился в составе тира major прежде, чем
авторить цели под него. Не возвращаться, пока состав стран не пересмотрен
(следующий пункт).

**Состав тиров major/regional и пробелы ростера — ждёт ответа пользователя.**
`TierTick.ts::HISTORICAL_TIERS_1946` придуман Claude-сессией 2026-06-30
единолично, без утверждения пользователем по конкретным странам. Конкретные
претензии: `CHN` в списке major, а `TWN` — нет, хотя в датасете `TWN`
(Гоминьдан) держит 34 региона материка и место в Совбезе ООН 1946, а `CHN`
(коммунистические районы) — только 8 регионов; `ARG`/`BRA` — под вопросом как
великие державы 1946 года; Индия вообще не отдельная сущность (под `QCG`,
British Colonies) — та же группа пробелов, что "Заблокировано" в
`docs/tasks/HISTORICAL_HINGE_POINTS_1946.md` (Индия, Индонезия, Индокитай,
Палестина/Израиль). Область работы (пересмотр списка, или ещё добавление
недостающих сущностей) — не решена.

**План 08, Шаги 2-4 (war score/`PeaceTerms`/мирные договоры; потери →
демография; госдолг)** — реализован только Шаг 1 (оккупация ≠ аннексия), см.

  Вест-Индия и т.д.) — переделать `country_merge.json`/`generate_country_registry.py`
  на курируемую конфигурацию, не авто-мердж по сюзерену.
- **Выбор страны** — список на старте (`ScenarioSelector.tsx`) уезжает за
  нижнюю границу экрана при 126 странах, только 3-буквенные коды без
  иерархии важности. Нужно: (а) curated-список "крупных держав" + кнопка
  "показать все"/переход на полную карту, (б) выбор страны кликом по карте.
  Требует поля `tier` (см. выше).
- **Границы регионов — один уровень, не зависят от зума.** Нужно два слоя

- **Флаги стран** — нет ассетов вообще. Нужен набор SVG по ISO/private-use

- **Текстурная подложка морей** — сейчас плоская заливка. Нужен растровый
