# Открытые вопросы калибровки/дизайна

**Калибровка ВВП/чел бедных стран 1946** — **формульная сторона решена
2026-07-11** (по решению пользователя «углубить фикс формулы»): корень был в
том, что формула рождаемости привязана положительно к богатству/образованию/
welfare (обратно демографическому переходу — бедные аграрные общества 1946
имели ВЫСОКУЮ фертильность + высокую смертность). Бедность тройно подавляла
рождаемость. Фикс: пол уровня жизни в рождаемости
(`STANDARD_OF_LIVING_BIRTH_FLOOR=0.5`) + базы education/welfare подняты к
нейтрали (1.0) — бедность не штрафуется ниже аграрной нормы, траты дают лишь
мягкий бонус, преимущество развитых в приросте идёт через низкую смертность.
`campaignSmoke` зелёный, регрессионный тест в `PopulationTick.test.ts`.
**Осталась сторона данных (домен Gemini):** сами стартовые ВВП/чел 128 стран
не сверялись с источниками (`docs/SCENARIOS.md`) — историческая калибровка
чисел остаётся кандидатом на проход Gemini, но население больше не убывает.

**Национальные цели ИИ-стран (major, для флейвора LLM) — приостановлено
пользователем 2026-07-06.** Черновик (только major, read-only, ~10 целей, план
по СССР как иллюстрация формата) остановлен — пользователь усомнился в составе
тира major прежде, чем авторить цели под него. Не возвращаться, пока состав
стран не пересмотрен (следующий пункт). **Отдельно:** цели ИГРОКА
(самопоставленные, оцениваемые движком) реализованы 2026-07-11 —
`docs/OBJECTIVES.md`, это другая задача (не про флейвор ИИ).

**Состав тиров major/regional и пробелы ростера — ждёт ответа пользователя.**

## UI-редизайн (весь трек заморожен — см. «Постоянные рамки»; пункты ниже — для будущего решения)
- **Новая композиция Header и плоских информационных панелей** (линия B) —

  реализуется до выбора канонической UI-линии пользователем. Отдельный

- **1946 `countries.json` не содержит стартовый `stockpile`** — найдено при

  MAP-пайплайн (`scripts/map/generate_country_registry.py` и соседние) его не
  заполняет — казна/ВВП растут с хода 0, а `stockpile` остаётся нулевым до

  .ts` содержат авторские значения `stockpile`, но это **мёртвый код** для
  сценария 1946 (используются только 1836/2000, которые собираются не из
  MAP-пайплайна). Решить осознанно: либо пайплайн сам считает стартовый
  stockpile (например, от `deposits`/инфраструктуры региона), либо это
  намеренно пустое состояние — не чинить умолчанием. Клиент уже обрабатывает
  пустой список корректно (ряд ресурсов в шапке скрывается, а не показывает
  пустую полосу).
- **Леджер уведомлений** — отложен целиком (решение пользователя 2026-07-13):
  в `GameState` нет сущности «уведомление», только `eventHistory`. Колокольчик

  N событий из `eventHistory` с уровнями crit/warn/info по типу события,
  бейдж непросмотренных за последний ход.
- **Визуальный QA перекраски карты по mapmode не закрыт** — Browser pane в
  сессии Среза 2г держал вкладку `document.hidden`, requestAnimationFrame-луп
  MapLibre не тикал, пиксельно подтвердить `regionModeColors` не удалось
  (см. docs/plans/12_UI_REDESIGN.md, Срез 2, «Отклонения»). Логика проверена
  независимо (тиринг на живом `GameState`), но нужен обычный браузер или
  видимая вкладка, чтобы визуально сверить с эталоном.
- **Mobile Header overflow (<600px)** — найдено Chrome/CDP QA 2026-07-16
  сессией онбординга (bootstrap-линия): RU/EN на 1440×900 и 760×900 без
  overlap/clipping, но на 390×844 Header делает документ шире viewport —
  stats-якорь почти уезжает за экран, кнопка следующего хода недоступна.
  Coach-card сам помещается. Композиция Header общая с `main`, так что
  находка вероятно применима к обеим линиям, но повторная проверка на самом
  `main` не выполнялась. Нужен отдельный responsive scope для композиции
  Header (после разморозки UI), а не локальный фикс онбординга.

  фронт резче, чем движок ожидал) было вызвано spread-вызовами `Math.max/min`;
  они заменены итеративным extent и покрыты полигоном из 150 000 точек.
- **`MapFeature` типы, кроме `capital`, визуально неотличимы друг от друга.**
  Слой `map-features-icons` в `MapView.tsx` проверяет только `type === 'capital'`
  → спрайт столицы, иначе всегда generic `city-icon`. Функции
  `getIconForType`/`getColorForType` в файле есть, но ни один слой их не
  читает — мёртвый код. Пользователь решил (2026-07-06) не чинить сейчас —
  война подтверждена через цвет региона, не через иконку.

### Визуал карты
- **Динамическая смена цвета в рантайме и Режимы карты (крупная фича).** Цвет
  как `f(состояние страны, режим карты) → цвет` на клиенте. Режимы:
  Политический (есть), Идеологический (коммунизм/либдем/национализм — цвета),
  Дипломатический/Блоки (относительно игрока), Экономический (интенсивность
  по ВВП/ресурсам).
- **Поле `tier`** (важность страны) — бюджет регионов при пере-нарезке
  геометрии, насыщенность цвета, стартовый шортлист держав. Состав
  major/regional согласовать с пользователем (см. "Открытые вопросы" выше).

### Прочее
- настоящая `isCoastalRegion()` в `generateMapFeatures.ts` (сейчас всегда
  false → порты не генерируются). **Зависимость:** блокирует морские десанты
  в war-системе (`docs/WAR.md`, Phase 1 явно пропускает — навал-превосходство
  `navyStrength` открывает контакт в `WarTick.ts`, цель — ближайший
  прибрежный регион, не реализовывать плейсхолдером на `capitalRegionId`).
- `scripts/map/config/country_merge.json` — дефолтная группировка колоний по
  сюзерену (один блок на сюзерена), не финал — ручная доводка по географии ожидаема.
- `scripts/map/README.md` "Внешние источники" — нет прямых ссылок на загрузку
  geoBoundaries/китайских исторических шейпов, только имена файлов.
- **Береговые линии не стыкуются** — полигоны суши/моря из MAP местами не
  совпадают по границе, заметно при приближении. Геометрическая проблема
  исходных данных MAP, не тривиальная правка. Конкретизировано 2026-07-23
  двумя независимыми находками (`docs/DECISIONS.md` 2026-07-23):
  - ~~20 дыр-островов в морях/озёрах без сырого источника~~ —
    **исправлено 2026-07-23** (`fill_sea_holes.py::UNSOURCED_HOLE_OWNERS`),
    см. `docs/DECISIONS.md`.
  - ~~~2086 км² разрывов суша↔озеро по всем 4 Великим озёрам~~ —
    **исправлено 2026-07-23** (новый `fix_lake_coastline_gaps.py`, 2110.7
    км² добавлено суше), см. `docs/DECISIONS.md`.
  - ~~`fix_sea_coastline_gaps.py` детерминированно не сходится для
    Oceania~~ — **исправлено 2026-07-23**, см. `docs/DECISIONS.md`.
  - **`fix_sea_coastline_gaps.py` печатает отрицательные "+X км2" для части
    морей при повторном прогоне на уже обработанном `seas_1946.geojson`**
    (найдено 2026-07-23 при верификации фикса Oceania): Norwegian
    Sea/Индийский океан — Центральный сектор показывают одинаковую
    "потерю" (-12.7/-0.6 км2) на каждом из 3 подряд идущих реальных
    прогонов. Проверено — НЕ накапливается: сохранённое свойство
    `area_km2` у Norwegian Sea осталось бит-в-бит одинаковым (1456629.1)
    после 2-го и 3-го прогона, т.е. реальная сохранённая геометрия
    стабильна, печатаемая дельта — транзиентный артефакт измерения внутри
    `unary_union([full_before, grown_piece])` (вероятно float-шум
    noding'а GEOS при объединении MultiPolygon с обрезанной копией самого
    себя), не реальная потеря площади. Не докопано до точного механизма
    (вне scope находки Oceania) — мелкое, не блокирует, кандидат на
    отдельный разбор, если когда-то понадобится точная (не приблизительная)
    площадь морей.
- **Колониальные блоки — не реальная историческая структура.** Сейчас "1
  блок на сюзерена" (всё британское — единый QCG). Реально были признанные
  административные единицы (Французская Западная Африка/AOF, Британская
  Вест-Индия и т.д.) — переделать `country_merge.json`/`generate_country_registry.py`
  на курируемую конфигурацию, не авто-мердж по сюзерену.
- **Выбор страны** — список на старте (`ScenarioSelector.tsx`) уезжает за
  нижнюю границу экрана при 126 странах, только 3-буквенные коды без
  иерархии важности. Нужно: (а) curated-список "крупных держав" + кнопка
  "показать все"/переход на полную карту, (б) выбор страны кликом по карте.
  Требует поля `tier` (см. выше).
- **Границы регионов — один уровень, не зависят от зума.** Нужно два слоя
  (внутренние тоньше/скрыты при малом zoom, внешние толще, всегда видны) +
  зум определяет выбор региона vs всей страны.
- **Флаги стран** — нет ассетов вообще. Нужен набор SVG по ISO/private-use
  кодам (`flag-icons` закрывает суверенов; кастомные `QGS`/`QCG`/... — свои
  плейсхолдеры). Кандидат на Nano Banana (Gemini), не выбрано формально.
- **Текстурная подложка морей** — сейчас плоская заливка. Нужен растровый
  тайлсет или процедурная текстура — источник/лицензия не исследованы.
  Кандидат на Nano Banana (Gemini), не выбрано формально.
