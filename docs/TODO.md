### Визуал карты
Палитра держав (EU5/HOI-стиль), прозрачность границ, удаление устаревшей
кнопки "Карта 1946" — **реализовано 2026-06-28/29**, см. `docs/DECISIONS.md`.
Блокер выбора сценария (128 стран обрезали кнопку «Начать игру») —
**реализовано 2026-06-29** (прокрутка `.country-list`/`.scenario-selector`,
см. `docs/DECISIONS.md`). Курируемый шортлист держав вместо 128 кодов —
отдельно, после поля `tier` (см. ниже).

- **Динамическая смена цвета в рантайме и Режимы карты (крупная фича) — перенесено в бэклог**. Цвет как `f(состояние страны, режим карты) → цвет` на клиенте. Необходимые режимы:
  - *Политический* (по умолчанию): раскраска стран по их государственным цветам (уже есть, вассалы тонируются).
  - *Идеологический*: цвета по политическому режиму/идеологии (коммунизм — красный, либеральная демократия — синий, национализм — коричневый/желтый и т.д.).
  - *Дипломатический / Блоки*: цвета относительно игрока (союзники/вассалы — зеленые, соперники/враги — красные, нейтралы — серые).
  - *Экономический*: интенсивность цвета в зависимости от ВВП региона или ресурсов.
- **Поле `tier`** (важность страны) — даёт сразу три выигрыша: бюджет
  регионов при пере-нарезке геометрии, насыщенность цвета, стартовый
  шортлист держав (см. ниже). Состав major/regional согласовать с
  пользователем, не выдумывать.

### Прочее
- настоящая `isCoastalRegion()` в `generateMapFeatures.ts` (сейчас всегда false → порты не генерируются).
- `scripts/map/config/country_merge.json` — дефолтная группировка колоний по сюзерену
  (один блок на сюзерена), не финал — ручная доводка по географии ожидаема.
- `scripts/map/README.md` "Внешние источники" — нет прямых ссылок на загрузку
  geoBoundaries/китайских исторических шейпов, только имена файлов.
- `Country.name`/`shortName` ещё `string`, не `LocalizedText` (см. AGENTS.md
  "Design for Multi-Locale From the Start") — мигрировать вместе с 12
  рукописными файлами стран, когда дойдут руки.
- **Береговые линии не стыкуются** — полигоны суши/моря из MAP местами не
  совпадают по границе (видны рваные тёмные клинья на стыке суши и воды),
  заметно при приближении. Геометрическая проблема исходных данных MAP, не
  тривиальная правка — отдельная задача, не делать походом.
- **Австрия не поделена на зоны оккупации** — как Германия, реально была
  поделена на 4 зоны (+ Вена на 4 сектора) до 1955, но ни MAP, ни текущий
  импорт это не отражают (9 регионов под единым `AUT`). Нужен ручной оверлей
  по `region_id`, аналогичный `occupation_overlay.json` для Германии —
  распределение зон уточнить перед кодом, не угадывать.
- **Колониальные блоки — не реальная историческая структура.** Сейчас "1
  блок на сюзерена" (всё британское — единый QCG, от Карибов до Гонконга).
  Реально были признанные административные единицы (Французская Западная
  Африка/AOF, Французская Экваториальная Африка/AEF, Британская Вест-Индия
  и т.д.) — переделать `country_merge.json`/`generate_country_registry.py`
  на курируемую конфигурацию по реальным историческим федерациям, не
  авто-мердж по сюзерену.
- **Выбор страны** — список стран на старте (`ScenarioSelector.tsx`) уезжает
  за нижнюю границу экрана при 126 странах, только 3-буквенные коды без
  иерархии важности. Нужно: (а) curated-список "крупных держав" на стартовом
  экране + кнопка "показать все"/переход на полную карту, (б) выбор страны
  кликом по карте до старта игры. Требует нового поля типа `tier` в
  `Country` — не выдумывать набор держав без проверки с пользователем.
- **Границы регионов — один уровень, не зависят от зума.** Все границы
  (внутри страны и между странами) одной толщины/цвета всегда. Нужно: два
  слоя (внутренние тоньше/скрыты при малом zoom, внешние толще, всегда
  видны) + при выборе региона зум определяет, выбирается ли регион или вся
  страна (ниже порога — страна, выше — конкретный регион).
- **Флаги стран** — нет ассетов вообще. Нужен набор SVG по ISO/private-use
  кодам (готовые наборы типа `flag-icons` закрывают суверенов; для
  кастомных кодов — `QGS`/`QCG`/... — свои плейсхолдеры).
- **Текстурная подложка морей** — сейчас плоская заливка (границы между
  морями уже есть, см. `oceans-fill`/`oceans-outline` в `MapView.tsx`), но
  не "красивая". Нужен источник растрового тайлсета или процедурная текстура
  — отдельное исследование источника/лицензии.
