# Приоритеты

## P1 — Замкнуть экономические петли (фундамент для всего остального)
**РЕАЛИЗОВАНО.** `taxRevenue = gdp × taxRate` (2026-06-23); добыча — только `ResourceTick`
(вопрос 4 закрыт); единицы экономики — модель "ВВП-якорь + доли" (`EconomyProfile` +
архетипы по `EconomyType`, вопрос 9 закрыт, 2026-06-26) — расходы/дефицит теперь реально
влияют на рост ВВП/manpower/рождаемость/исследования. Попутно исправлен баг "рост ВВП
стирался каждый ход" и id-баг Italy/ITA. Детали — `docs/ECONOMY.md`, `docs/DECISIONS.md`.
export/stateEnterprise/other остаются статичными в первом проходе (см. P3, торговля).

## P2 — Оживить ИИ-страны (детерминированно, без полноценного utility-AI)
**РЕАЛИЗОВАНО (2026-06-23)** доступное подмножество — `server/src/simulation/ai/AiBehaviorTick.ts`,
вписан в `SimulationEngine`, +11 тестов, проверено на 12 ходах сценария 1946.
- ~~Правило A~~ — аустерити по дефициту (−5%/тик дискреции, пол 50%, снимок в `createGame`).
- ~~Правило B~~ — Threat с полной балансировкой: военный ответ + контр-блок + power→influence→сфера.
  Числа (THREAT=50, шаги, потолки) — константы в начале файла, балансировать на симуляции.
- Замечание: эффект пока ограничен — союзы/сфера без «зубов» (нет войны/бонусов). budget↔gdp
  коэффициенты исправлены (P1, вопрос 9) — теперь не ≈0, но не перебалансированы под P2 совместно.

**Заблокировано (вышло наружу при дизайне 2026-06-23) — это новые предпосылки, не P2:**
- **Динамика политики**: `politics.stability/legitimacy/governmentSupport` статичны (никто не пишет) →
  нудж «низкая stability→welfare» и кризис легитимности невозможны. Нужно спроектировать драйверы.
- **War-система**: состояния войны нет вообще → war-нудж, кризис после войны, «зубы» союзов/сферы.
- Вариативность характера (`aggressiveness`/`riskTolerance`) и тиры стран — после, не блокеры.

## Карта/регионы (общая ответственность)

Ближний Восток 1946 — историческая точность владения (Иранский кризис →
`QAZ`/`QMH`, Иордания → брит. мандат, Аден → `QCG`, Сирия/Ливан/Суэц →

### Следующий геометрический проход (отдельный блок, дороже)
- **Ближний Восток — пере-нарезать тоньше.** Источник `client/src/assets/
  game_map.json` (4596 провинций) на месте — текущий мердж слишком грубый
  (Турция 81→9, Сирия 15→10, Иордания 12→6). Турция/Сирия политически верно
  (Хатай у Турции), но имена/нарезка обманчивы («Sanliurfa» поглощает Хатай).
  Хатай — отдельным регионом.
- ARE (Trucial States) → 1 полигон вместо 7; схлопнуть переподробных миноров
  (DOM 19 регионов на 48k км², ARE, OMN, центральноамериканский кластер) —
  лучше через новое поле `tier` (см. ниже), не вручную страна за страной.
- **Баги данных:** Руанда (`RWA`) и Урунди (`BDI`) — одна страна 1946 под
  двумя кодами с одинаковым именем "Ruanda-Urundi", надо объединить. Столицы
  считаются как "регион максимальной площади" → у Египта столица не Каир,
  нужна курируемая привязка capital_region к реальному городу. Прочие
  спецзоны на будущее: Триест, Танжер, Саар, Кёнигсберг, Шпицберген.

### Визуал карты
- **Палитра держав** — нынешний MD5-хэш/«имперский розовый» для UK не
  смотрится; перейти на курированную палитру в стиле EU5/HOI (приглушённая,
  различимая, ~60-100 слотов).
- **Границы регионов** — `#0b0e14` слишком чёрные, добавить прозрачности.
- **Названия стран при отдалении** — symbol-слой с лейблами на малом зуме.
- **Динамическая смена цвета в рантайме** (крупная фича) — цвет как
  `f(состояние страны, режим карты) → цвет` на клиенте, а не запечённый при
  генерации. У каждой страны — intrinsic «цвет-идентичность» из палитры;
  вассалитет лишь перекрывает тонировкой сюзерена (вышла из-под вассалитета →
  снять тонировку, показать свой цвет). Режимы карты поверх: идеология/блоки/
  отношение к игроку/экономика/развитие.
- **Артефакты рендера** — иногда проскакивают визуальные баги, нужно
  воспроизвести и локализовать прежде, чем чинить (`MapView.tsx`).
- **Поле `tier`** (важность страны) — даёт сразу три выигрыша: бюджет
  регионов при пере-нарезке геометрии, насыщенность цвета, стартовый
  шортлист держав (см. ниже). Состав major/regional согласовать с
  пользователем, не выдумывать.

### Прочее
- производительность карты, Vector Tiles при необходимости.
- настоящая `isCoastalRegion()` в `generateMapFeatures.ts` (сейчас всегда false → порты не генерируются).
- `scripts/map/config/country_merge.json` — дефолтная группировка колоний по сюзерену
  (один блок на сюзерена), не финал — ручная доводка по географии ожидаема.
- `scripts/map/README.md` "Внешние источники" — нет прямых ссылок на загрузку
  geoBoundaries/китайских исторических шейпов, только имена файлов.
- `Country.name`/`shortName` ещё `string`, не `LocalizedText` (см. AGENTS.md
  "Design for Multi-Locale From the Start") — мигрировать вместе с 12
  рукописными файлами стран, когда дойдут руки.
- Экономика/население/ресурсы регионов 1946 — плейсхолдеры-нули, заполнение
  отдельной моделью (см. план интеграции MAP, не TODO-таск здесь).
- **Береговые линии не стыкуются** — полигоны суши/моря из MAP местами не
  совпадают по границе (видны рваные тёмные клинья на стыке суши и воды),
  заметно при приближении. Геометрическая проблема исходных данных MAP, не
  тривиальная правка — отдельная задача, не делать походом.
- **Австрия не поделена на зоны оккупации** — как Германия, реально была
  поделена на 4 зоны (+ Вена на 4 сектора) до 1955, но ни MAP, ни текущий
  импорт это не отражают (9 регионов под единым `AUT`). Нужен ручной оверлей
  по `region_id`, аналогичный `occupation_overlay.json` для Германии —
  распределение зон уточнить перед кодом, не угадывать.
- **Колониальные блоки — не реальная историческая структура.** Сейчас "1
  блок на сюзерена" (всё британское — единый QCG, от Карибов до Гонконга).
  Реально были признанные административные единицы (Французская Западная
  Африка/AOF, Французская Экваториальная Африка/AEF, Британская Вест-Индия
  и т.д.) — переделать `country_merge.json`/`generate_country_registry.py`
  на курируемую конфигурацию по реальным историческим федерациям, не
  авто-мердж по сюзерену.
- **Выбор страны** — список стран на старте (`ScenarioSelector.tsx`) уезжает
  за нижнюю границу экрана при 126 странах, только 3-буквенные коды без
  иерархии важности. Нужно: (а) curated-список "крупных держав" на стартовом
  экране + кнопка "показать все"/переход на полную карту, (б) выбор страны
  кликом по карте до старта игры. Требует нового поля типа `tier` в
  `Country` — не выдумывать набор держав без проверки с пользователем.
- **Границы регионов — один уровень, не зависят от зума.** Все границы
  (внутри страны и между странами) одной толщины/цвета всегда. Нужно: два
  слоя (внутренние тоньше/скрыты при малом zoom, внешние толще, всегда
  видны) + при выборе региона зум определяет, выбирается ли регион или вся
  страна (ниже порога — страна, выше — конкретный регион).
- **Флаги стран** — нет ассетов вообще. Нужен набор SVG по ISO/private-use
  кодам (готовые наборы типа `flag-icons` закрывают суверенов; для
  кастомных кодов — `QGS`/`QCG`/... — свои плейсхолдеры).
- **Текстурная подложка морей** — сейчас плоская заливка (границы между
  морями уже есть, см. `oceans-fill`/`oceans-outline` в `MapView.tsx`), но
  не "красивая". Нужен источник растрового тайлсета или процедурная текстура
  — отдельное исследование источника/лицензии.
