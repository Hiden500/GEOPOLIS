# Технологии

Last updated: 2026-07-06

> **Реализовано** (`docs/DECISIONS.md`, 2026-07-06) — без каталога именных
> технологий. Разбор кода в этот день показал, что старая модель
> (`TechnologyDefinition`/`ResearchProject`/дропдаун в `ResearchPanel.tsx`)
> была полностью разорвана — прогресс никогда не зачислялся в реальный домен
> (`domain: "Research"` вместо настоящего). Заменена целиком, не починена
> точечно.

## Модель

Нет каталога/дерева именных технологий. Тир домена — непрерывная функция
накопленных вложений, не выбор из меню:

- `Country.technology.domains: Record<string, number>` — накопленный
  прогресс по домену (ключ — имя домена текущей эры, `shared/src/data/eras.ts`).
- `Country.technology.researchAllocation?: Partial<Record<string, number>>`
  — доля `economy.researchSpending` на явно указанный домен (0 до
  `MAX_RESEARCH_SHARE = 0.7`, `shared/src/defines/research.ts`; потолок
  применяет глагол `research_shift` в `PrimitiveEngine`, и активная война его
  снижает на `WAR_RESEARCH_SHARE_PENALTY` за каждую). Домены без явной
  доли делят остаток поровну — детерминированный дефолт.
- Тир = `getDomainTier(progress)` (`shared/src/utils/technology.ts`) —
  `floor(progress / TIER_PROGRESS_THRESHOLD)`, не хранится отдельно (нет
  риска рассинхрона). Прогресс на тир замедляется с каждым следующим тиром
  (`TIER_SLOWDOWN_PER_TIER`, `ResearchTick.ts`) — поздний прорыв
  непропорционально труднее раннего.
- Порядок ("нельзя тир 5 без тир 1-4") сохраняется автоматически — это
  накопительная сумма, не выбор из меню, пропустить ступень физически нельзя.

## Кто направляет фокус

- Игрок — через `PlayerIntent` (свободный текст → LLM формулирует как
  `LLMAction { type: 'research_shift', data: { domain, share } }`).
- Топ-державы (major/Spotlight) — LLM выпускает тот же `research_shift` от их
  имени, тем же паттерном, что объявление войны (`sourceCountryId` — любая
  страна ростера).
- Остальные страны — детерминированный дефолт (поровну по доменам эры), LLM
  их не направляет каждый цикл.

## "Прорывы" — не авторятся заранее

Когда домен пересекает значимый тир, конкретное содержание прорыва ("что
именно изобрели") придумывает LLM в нарративе момента — не заранее написанный
каталог. Инструкция об этом — в `## Instructions` промта
(`LLMService.generatePrompt()`).

## Что дальше (не сделано)

- **Домены без единой технологии до сих пор не имеют содержательного
  контекста** — сами по себе домены (armor/aviation/naval/infantry/...) уже
  реально растут и дают тир, простое накопление числа не требует именного
  контента. Это решает исходную проблему ("технологии не растут"), не требует
  правки.
- **Национальные цели стран** (`docs/DECISIONS.md`, 2026-07-06) — отдельный,
  не начатый заход: может со временем влиять на то, какие домены страна
  инвестирует по умолчанию (сейчас дефолт — равномерно).
- **Мапping доменов 1836/2000 годов** — сознательно не решался: домены этих
  эр называются иначе (`eras.ts`), тестируется сейчас только 1946 год.
- **Декоративные названия прорывов по эре** (ППШ/АК-стиль для оружия) —
  отдельный, отложенный заход (`docs/DECISIONS.md`, 2026-07-06) — сейчас
  LLM просто придумывает название в моменте, без структурированной таблицы.
