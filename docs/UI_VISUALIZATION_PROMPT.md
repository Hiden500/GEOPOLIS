# Prompt для визуализации UI-концепции в ChatGPT

Перед отправкой приложить к сообщению два текущих скриншота панелей
«Население» и «Рейтинги». Затем вставить prompt ниже целиком.

```text
Ты — senior game UI art director и interaction designer. Создай наглядный
high-fidelity concept board интерфейса desktop grand strategy Geopolis.

Используй приложенные скриншоты только как источник текущего визуального языка
и проблем компоновки. Не копируй вложенные карточки и ошибки таблицы.

Визуальный язык, который нужно сохранить:
- геополитическая ситуационная комната 1946 года;
- тёмный антрацитово-зелёный фон, латунно-золотые акценты;
- строгие углы 0–2 px, тонкие hairline-разделители;
- Oswald/condensed display для заголовков, IBM Plex Sans для текста,
  IBM Plex Mono для чисел;
- высокая информационная плотность, никаких SaaS-карточек, glassmorphism,
  fantasy HUD или крупных скруглений;
- карта мира остаётся главным визуальным пространством.

Сделай один горизонтальный 16:9 presentation board в разрешении не ниже
1920×1080. Раздели его на четыре хорошо читаемых кадра. Если четыре кадра не
получаются достаточно крупными для уверенного чтения геометрии, сгенерируй
четыре отдельных изображения 16:9 в том же порядке вместо уменьшения деталей:

КАДР A — основной HUD поверх мировой карты.
- Не делай полноширинную верхнюю панель.
- Слева должен быть компактный Г-образный HUD.
- Флаг страны — вертикальный блок примерно 88 px шириной, занимает две строки.
- Справа от флага в первой строке находятся GDP, казна, население, manpower,
  стабильность, легитимность и компактные ресурсы.
- Ширина строки статов определяется содержимым и ограничена max-width.
- Во второй строке, справа от флага, находятся ровно девять квадратных кнопок
  книг. Фон панели заканчивается сразу после девятой кнопки. Не оставляй
  пустого хвоста и не продолжай рамку по экрану.
- За пределами фактических элементов должна быть видна карта.
- LLM-status по центру и блок даты/следующего хода справа — отдельные компактные
  content-sized элементы, без фонового моста между ними.

КАДР B — тот же HUD с открытым national briefing.
- В закрытом состоянии briefing отсутствует на карте.
- По клику на флаг под ним открывается popover шириной около 320–360 px.
- В popover: мировой ранг, национальная сила, прогресс целей, 2–3 изменения
  последнего хода и кнопка «Открыть обзор страны».
- Popover визуально привязан к флагу и не изменяет геометрию Header.

КАДР C — боковая панель «Население» шириной около 420–440 px.
- Убери эффект «окно внутри окна».
- Не используй большую внутреннюю карточку вокруг содержимого.
- Не оборачивай каждый регион в отдельную карточку.
- Покажи плоский список территорий с тонкими горизонтальными разделителями.
- В одной строке: название региона слева, население справа.
- Ниже компактно: «Пища 2.27K/мес · Древесина 81/мес».
- Высота обычной строки 64–76 px.
- Hover или выбранная строка обозначается слабой общей заливкой.

КАДР D — боковая панель «Рейтинги» той же ширины.
- Таблица находится прямо на основной поверхности панели, без внутренней рамки
  и карточки.
- Колонки: страна, население, ВВП, казна.
- Страна выровнена влево, числа вправо.
- Используй компактные значения 15.9M, 2.17B, 108.3M без переносов строк.
- Только тонкие горизонтальные разделители.
- Строка China выделена слабой латунной заливкой.
- Покажи тонкий тёмный scrollbar, не белый системный.

Добавь короткие графические аннотации со стрелками:
- «width = content» у строки статов;
- «width = 9 buttons» у панели книг;
- «map remains visible» в свободной зоне;
- «no nested card» у двух боковых панелей.

Критические запреты:
- никакой подложки Header на всю ширину viewport;
- никакой панели кнопок шире самих кнопок;
- никакого постоянного briefing поверх карты;
- никаких карточек внутри карточек;
- никаких переносов чисел по отдельным символам.

Сначала сгенерируй именно изображение concept board. Не пиши код и не давай
длинное текстовое объяснение. После изображения перечисли максимум пять
заметных компромиссов дизайна, которые стоит обсудить перед реализацией.
```
