## 2. TDD-шаблон для игровой механики

Порядок написания теста механики — всегда: **arrange мир → act тик/команда →
assert состояние**. Использовать фикстуры `server/src/test-utils/fixtures.ts`
(расширять их, а не строить мир вручную в каждом тесте).

```ts
describe("<Механика> (<план NN>)", () => {
  // 1. Критерии приёмки плана — по it() на критерий, писать ДО реализации
  it("критерий 1: <формулировка из плана>", () => {
    const game = makeGameFixture({ /* минимальный мир под критерий */ });
    <команда или simulateMonth>(game);
    expect(<наблюдаемое состояние>).toBe(<ожидание>);
  });

  // 2. Граничные случаи — обязательный минимум:
  it("не взрывается при нулевом/пустом входе (gdp=0, нет регионов, нет цели)");
  it("уважает капы из defines (значение на границе и за границей)");
  it("детерминизм: два прогона с одним seed идентичны");

  // 3. Сериализация — если добавлено поле состояния:
  it("новое поле переживает JSON round-trip и загрузку старого сейва отклоняет по version");

  // 4. LLM-контракт — если добавлено действие:
  it("валидное действие применяется; за-каповое отклоняется с причиной");
});
```

Кампания-смок (для механик с многомесячной динамикой) — добавить сценарий в
`server/src/simulation/__tests__/campaignSmoke.test.ts`: прогнать 24–120
месяцев, assert'ы на инварианты (нет NaN/Infinity/отрицательного населения,
величины в правдоподобных порядках), а не на точные числа.

## 3. Чек-лист код-ревью (прогонять на собственный дифф до коммита)

**Конституция:**
- [ ] В state нет Map/Set/классов/производных индексов (правило 1)
- [ ] Мутации через команды; ни одного нового прямого присваивания в обход (2)
- [ ] Временные эффекты — модификаторы, не if-ветки в тиках (3)
- [ ] Ни одной новой числовой константы баланса в коде — всё в defines (4)
- [ ] Нет Math.random/Date.now/new Date() в симуляции (5)
- [ ] LLM-вход/выход через Zod; никаких координат/сырых чисел от LLM (6)
- [ ] Новый контент — через реестр данных, не TS-union (7)
- [ ] Отображаемые поля — LocalizedText; строки UI — t('key') + ru/en json (8)
- [ ] Производное вычисляется, не хранится (9)
- [ ] shared/ не импортирует server/client (10)

**Качество:**
- [ ] Тесты покрывают критерии приёмки И граничные случаи, не только happy path
- [ ] Ошибки не глотаются; невалидное отклоняется с внятной причиной
- [ ] Именование/стиль совпадают с соседним кодом; комментарии объясняют
      ограничения, а не пересказывают код
- [ ] Нет дублирования существующей утилиты/сервиса
- [ ] Порядок фаз simulateMonth не нарушен; новый лаг межфазный — задокументирован

**Процесс:**
- [ ] Док-футпринт: TODO / DECISIONS / статус плана / системный док
- [ ] Дифф не содержит «заодно»-правок вне скоупа задачи
- [ ] Сообщение коммита: что и зачем (не «fix», не «update»)
