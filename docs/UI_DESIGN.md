## Концепция

**Situation-room briefing** — интерфейс военного штаба/разведсводки, не
дашборд SaaS и не игровое «фэнтези-стекло». Игрок читает карту и цифры так,
как читал бы оперативную сводку 1946 года: антрацит, латунь, штампы,
моноширинные данные.

Референс структуры/плотности — HOI4/EU4 (верхняя панель статов, плотные
панели), но **не палитра** — палитра и типографика свои
(`docs/decisions/2026-06.md`, «Редизайн интерфейса», 2026-06-23).

## Типографика

| Шрифт | Переменная | Где |
|---|---|---|
| Big Shoulders Stencil Display | `--font-display` | h1/h2 экрана, титулы панелей (`.budget-panel h2` и т.п.) — используется скупо, не для тела текста |
| IBM Plex Sans | `--font-body` | body, обычный текст |
| IBM Plex Mono | `--font-mono` | **все данные и числа**, uppercase-лейблы, статусы, коды стран/ресурсов |
| EB Garamond Bold | локальный `@font-face` | не используется в текущих компонентах — проверить перед удалением/использованием |

Паттерн лейблов: `uppercase`, `letter-spacing: 0.5–1px`, `font-mono`,
`color: var(--color-paper-dim)`, размер 0.6–0.75rem. Повторяется в
stat-pill-label, budget-item .label, panel-section h3/h4, timeline-date.

## Геометрия и плотность

- `border-radius: 2px` практически везде (изредка 3px в карточках) — острые,
  «штампованные» углы, не скруглённые UI-элементы. Круглые — только теги
  (`timeline-tag`, `999px`) и точки-индикаторы стран.
- Границы `1px solid var(--color-hairline)`, акцентные элементы иногда
  `border-left: 3px solid var(--color-brass-dim)` (panel-section).
- Отступы в rem, шаг 0.2–0.75rem — плотная, не «воздушная» компоновка (сводка,
  не лендинг).

## Компонентные паттерны

- **Окна** (`Window.tsx` + `useWindows.ts`) — единственный способ показать
  панель: перетаскиваемые, размер по контенту по умолчанию, ручной ресайз,
  дедупликация по `id` (повторное открытие фокусирует, не плодит копии),
  клик поднимает `zIndex`. Новая панель = новый тип окна через `openOrFocus`,
  **не** новый оверлей/модалка мимо Window.
- **Status stamp** (`.status-stamp`) — поворот `-2deg`, рамка 1.5px,
  канцелярский штамп для статусных пометок (готово, тревога и т.п.).
- **Resource ticker** — компактные «биржевые» чипы: 3-буквенный код + число +
  `title` с полным названием, не полные подписи (см. DECISIONS 2026-06-23).
- **Таблицы** (`world-table`) — моно-шрифт данных, uppercase моно-заголовки,
  hover подсвечивает строку, `.player-row` — brass-tint.
- **MapLibre popup** — переопределён через `!important` под ту же палитру
  (`.maplibregl-popup-*`) — единственное место с `!important`, потому что
  стили библиотеки грузятся после App.css.

## Взаимодействие

- Primary-действие: `background: var(--color-brass)`, `color: var(--color-ink)`,
  hover — светлее (`#d6ad5e`), `:disabled` — `opacity: 0.5`.
- Danger-действие: `border/color: var(--color-signal)`, hover — `signal-tint` фон.
- Hover на границах вторичных элементов почти всегда `border-color: var(--color-brass-dim)`.
- Скроллбары кастомные (webkit) — тонкие 4px, hairline/brass-dim.

## Локализация (обязательное сквозное правило)

Две независимых плоскости — новая панель обязана думать про обе (`docs/LOCALIZATION.md`):
1. Игровые данные (`Region.names`, будущие `Country.name`) — `LocalizedText`, не `string`.
2. UI-строки — `react-i18next`, `t('key')` в неймспейсе компонента
   (`client/src/i18n/locales/{ru,en}/<component>.json`), не хардкод-литерал.
   Исключение: `client/src/map/` — рабочая система под инкремент-only правилом
   (см. ниже), i18n там не трогать без явного запроса.

  не недоработка light-mode.

## Domain boundary — кто может здесь работать

`client/` целиком, включая `client/src/map/**`, — домен **Claude** (с
2026-07-12, было Gemini кроме карты; карта перешла раньше, 2026-07-11 — см.
`docs/DECISIONS.md`, `AGENTS.md` §"Координация моделей"). Интерфейс больше не
заморожен: полный редизайн идёт по `docs/plans/12_UI_REDESIGN.md`. Карта —
рабочая система, не чужая территория, но геометрию/топологию/рендер
полигонов/размещение подписей не переписывать без причины (инкремент вместо
переписывания, AGENTS.md) — в скоупе редизайна только UI-слой поверх карты.
`docs/GEMINI_MAP_ENGINE.md` — прежние промпты/правила MAS-пайплайна, история,
справочно.

Gemini сохраняет роль в текстах/контенте/иконках (генерация через Nano
Banana) и исторической калибровке данных — не в UI-коде. Крупную реализацию
по-прежнему сопровождать записью в `docs/DECISIONS.md` (существующая
конвенция дока для решений, не признак чужого домена). Иконки
`.maplibregl-popup-*` (CSS-оверлей поверх карты) — это UI, не геометрия,
трогать можно; сама геометрия/рендер/лейблы карты — нет, никогда без прямого
запроса пользователя.
