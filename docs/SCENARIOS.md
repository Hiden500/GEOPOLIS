## Назначение

Дом для статуса сценариев: что есть сейчас (1946) и чего не хватает, чтобы
1836/2000 стали реальными точками старта, а не отсутствовали вовсе.
Историческая достоверность стартового состояния — правила в
`docs/HISTORICAL_ACCURACY.md`, не дублируются здесь.

**⚠️ Числа стран 1946 (датасет d/MAP) — не откалиброваны по надёжным
источникам, не reference-данные.** При переходе на модель "ВВП-якорь + доли"
(`docs/ECONOMY.md`, `docs/DECISIONS.md` 2026-06-26) страны механически
сконвертированы на доли через архетип-дефолт по `economyType`, без
исторической калибровки. Это сознательно — числа никогда не были
откалиброваны по надёжным источникам (`HISTORICAL_ACCURACY.md` требует это
для финального контента), и перекалибровка имеет смысл только после того,
как карта/регионы 1946 стабилизируются (ведёт пользователь отдельно, см.
`docs/TODO.md`). Не тюнинговать баланс под эти страны как если бы это была
реальная цель.

## Что уже решено

- **3 независимые точки старта как целевая модель**, не одна сквозная
  партия на 264 года (`docs/DECISIONS.md`, 2026-06-22): у каждого сценария
  свой tech tree, свой набор стран, свой баланс — несовместимые
  технологические уклады делают общую систему на весь период
  нежизнеспособной. Реализована пока только 1946-точка; 1836/2000 —
  будущая работа, не код сегодня (заглушки удалены 2026-07-26).
- **Порядок работы**: сначала 1946 полностью, потом клонировать пайплайн на
  1836/2000 (`docs/DECISIONS.md`, 2026-06-22). Это объясняет, почему до
  2026-07-26 существовали временные заглушки в реестре сценариев — они
  были ожидаемо временными, не забытыми, и удалены как мёртвый код, когда
  выяснилось, что их держит только собственное отсутствие альтернативы
  (`docs/DECISIONS.md`, 2026-07-26).

## ⚠️ Открытые вопросы

Ни один не в `docs/DECISIONS.md` как явный список — выведены из факта, что
1836/2000 не начаты:

1. **Набор стран 1836.** "Век империй" (`AGENTS.md` пример: существует
   Османская/Австрийская империя, отсутствует Германия) — нужен список
   держав эпохи, отдельный от 1946.
2. **Набор стран 2000.** "Современный мир" — нужен пост-СССР список
   (Россия/Украина/etc вместо СССР, согласно примеру в
   `HISTORICAL_ACCURACY.md`).
3. **Карта/регионы для 1836 и 2000 не существуют вообще.** Прежняя тестовая
   заглушка (`testRegions`) удалена 2026-07-26 вместе со сценариями
   (`docs/DECISIONS.md`) — нужна реальная география эпохи с нуля, не правка
   заглушки. Карта/регионы явно "ведутся пользователем отдельно"
   (`docs/TODO.md`) — не приоритизировать здесь.
4. **Tech tree по эре.** Понятие "каталог именных технологий" отменено
   полностью решением 2026-07-06 (см. `docs/DECISIONS.md`, `docs/TECH_TREE.md`)
   — технологии теперь домен-инвестиции, не каталог. Вопрос сузился до того,
   какие домены доступны в 1836/2000 через `shared/src/data/eras.ts`
   (`technologyEra` ссылается в `ERAS` по `id`), не полного дизайна каталога
   с нуля.
5. **Баланс.** Даже при наличии исторических данных, игровой баланс
   (стартовые `economy`/`military` значения) для 1836/2000 не существует —
   только для 1946 (откуда взялось решение P1 про масштаб, `ECONOMY.md`).

## Предлагаемое направление

Не предлагаю конкретный список стран 1836/2000 — это историческое
исследование (`AGENTS.md`: "использовать надёжные источники, не выдумывать
числа"), не архитектурное решение. Актуальный образец для клонирования на
1836/2000 — пайплайн `scripts/map/` (`import_to_game.py`/
`generate_country_registry.py`), который теперь и генерирует 1946; когда
работа над 1836/2000 начнётся, это тот же пайплайн, применённый к другому
датасету/эпохе — это явно одобренный паттерн ("клонировать пайплайн"), не
новая инфраструктура.
