# Черновик: каталог исторических развилок для сценария 1946

**Статус: черновик на ревью, не реализовано, не подключено к движку.** Ни
схема, ни конкретные записи не финальны — числа (`baseWeight`, пороги
предусловий) тюнингуемые placeholder'ы по тому же принципу, что THREAT-пороги
в `AiBehaviorTick.ts`. Ничего из этого файла не действует на игру, пока не
принято решение об авторстве/частоте (см. открытый вопрос в
`docs/DECISIONS.md`) и не написан код, который это читает.

## Зачем

Сейчас LLM получает только снимок текущего состояния мира каждый месяц — у
неё нет понятия "что исторически должно было произойти примерно сейчас".
Для сценария, начинающегося сразу после Второй мировой, это заметно: почти
всё содержимое ранней Холодной войны (1946-1953) — уже заряженные
предпосылки на дату старта, а не что-то, что вообще нужно "изобретать"
LLM с нуля. Без явной подсказки слабая модель либо промолчит, либо
придумает не тот конфликт не в том месте.

Идея — не диктовать исход, а **напоминать LLM, что вот в этой временной
точке было исторически вероятно, если предпосылки ещё не изменены игроком**.
Правило `AI_RULES.md`/`LLM_RULES.md` про вероятностность истории и запрет на
жёсткие рельсы остаётся в силе: движок только проверяет предусловия и решает,
показывать ли подсказку — не заставляет LLM ничего разыгрывать.

## Предлагаемая схема

```ts
interface HistoricalHingePoint {
  id: string;
  title: string;
  windowStart: string; // "YYYY-MM"
  windowEnd: string;    // "YYYY-MM" — после этой даты развилка считается устаревшей, не подсказывается
  primaryCountries: string[]; // реальные country id — LLM подсказка ссылается на них, не на имена
  historicalOutcome: string;  // короткое описание для контекста LLM и человека-ревьюера
  preconditions: Precondition[]; // ВСЕ должны выполняться, иначе развилка молчит (уже неактуальна)
  baseWeight: number; // 0..1, ориентир вероятности при выполненных предусловиях — не жёсткий rng-бросок,
                       // подсказка LLM о том, насколько это "должно было случиться"
  divergenceHint: string; // что именно из действий игрока могло бы это изменить
  representable: boolean; // false = нет игровой сущности для одной из сторон, см. "Заблокированные"
  blockedReason?: string;
}

type Precondition =
  | { type: "relationBelow"; a: string; b: string; threshold: number }
  | { type: "relationAbove"; a: string; b: string; threshold: number }
  | { type: "noGuaranteeFrom"; target: string; guarantor: string }
  | { type: "stabilityBelow"; country: string; threshold: number };
```

`Precondition` — минимальный набор примитивов, для которых уже есть готовые
поля в `GameState` (`diplomacy.relations`, `diplomacy.guarantees`,
`politics.stability`) — никакой новой механики движка не требуется, только
проверка на чтение раз в месяц.

Проверены реальные id из `server/data/scenarios/1946/countries.json` (не
выдуманы) — там же сверено распределение регионов, где это существенно
(Китай ниже).

```json

  "title": "Начало холодной войны: доктрина Трумэна и план Маршалла",
  "windowStart": "1947-03",
  "windowEnd": "1948-12",
  "primaryCountries": ["SUN", "USA"],
  "historicalOutcome": "США переходят к политике сдерживания, запускают план Маршалла для Западной Европы; мир раскалывается на два блока.",
  "preconditions": [{ "type": "relationBelow", "a": "SUN", "b": "USA", "threshold": 40 }],
  "baseWeight": 0.85,
  "divergenceHint": "Если игрок (за SUN или USA) уже вывел отношения в дружественную зону, раскол может не оформиться так резко или отложиться.",
  "representable": true
```

Уже частично подтверждено живым тестом с ChatGPT в этой сессии — модель сама
сгенерировала похожий сюжет ("СССР-США ухудшаются после фултонской речи") без
всякой подсказки. Эта запись формализует то, что LLM и так тянется делать.

### 2. `chinese_civil_war` — Гражданская война в Китае

```json
{
  "id": "chinese_civil_war",
  "title": "Гражданская война в Китае: победа коммунистов",
  "windowStart": "1946-01",
  "windowEnd": "1949-12",
  "primaryCountries": ["CHN", "TWN"],
  "historicalOutcome": "Коммунисты (CHN) при поддержке СССР постепенно занимают материк; националисты (TWN) отступают на Тайвань к концу 1949.",
  "preconditions": [
    { "type": "relationAbove", "a": "SUN", "b": "CHN", "threshold": -20 },
    { "type": "noGuaranteeFrom", "target": "TWN", "guarantor": "USA" }
  ],
  "baseWeight": 0.75,
  "divergenceHint": "Гарантия США Гоминьдану (TWN) или разрыв SUN-CHN меняет баланс сил гражданской войны — вплоть до сохранения статус-кво материка за TWN.",
  "representable": true
}
```

На дату старта 1946 в датасете уже заложена именно эта расстановка: `TWN`
("Republic of China (Kuomintang)") держит 34 региона материка, `CHN`
("China", т.е. коммунистические районы) — 8, `QMS` (советская администрация
Маньчжурии) — 9 отдельно. Развилка не создаёт новую сущность, только
формализует уже существующее в данных противостояние.

## Заблокировано (нужна новая игровая сущность до того, как это можно скриптовать)

Не спекулирую составом/кодами новых стран — только фиксирую пробел, решение
о них отдельное (как поле `tier`/курируемый список держав раньше).

- **Раздел Индии (1947)** — территории под кодом `QCG` (British Colonies),
  нет отдельной сущности "Британская Индия"/будущих Индии и Пакистана.
- **Индонезийская национальная революция** / **Первая Индокитайская война**
  (1946-1949/1954) — территории под `QCN` (Netherlands Colonies) и `QCF`
  (France Colonies), нет местных сущностей-повстанцев (Республика Индонезия,
  Вьетминь).
- **Арабо-израильская война 1948** — есть `PSE` (Palestine Mandate), нет
  `ISR`/сущности для арабских добровольческих сил — раздел Палестины сейчас
  не представим как двусторонняя развилка.

## Открытые вопросы перед реализацией (не входит в этот черновик)

1. Кто ведёт этот каталог дальше — куратор вручную по образцу карты, или
   можно предложить черновик по другим сценариям (1836/2000) так же.
2. Частота проверки движком — раз в месяц вместе с остальным промтом,
   выглядит естественно (`LLMService.generatePrompt`), но не решено.
3. Что происходит после того, как развилка "сыграла" (LLM её реализовала,
   изменила, или явно отклонила) — нужен флаг "закрыта", чтобы не подсказывать
   повторно каждый месяц до конца окна.
4. Соотношение с ротацией второстепенных стран (см. обсуждение в
   `docs/DECISIONS.md`) — не решено, разные механизмы, могут жить параллельно.
