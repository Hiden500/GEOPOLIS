# Целевой слой (счёт силы, позиция, цели игрока)

Last updated: 2026-07-16 (реализован UI национального брифинга)

> **Реализовано** (2026-07-11): индекс национальной силы + позиция игрока в
> мировом рейтинге (`GameState.playerStanding`) + самопоставленные цели игрока
> (`Country.goals` типизированы и оцениваются движком). Модель выбрана
> пользователем — **игрок сам ставит цели**, движок детерминированно
> отслеживает выполнение (не навязанная движком победа/поражение). Числа —
> тюнингуемые плейсхолдеры.

## Назначение

Даёт игроку обратную связь «насколько я силён / расту ли» и смысл партии
(цели, к которым он идёт) — категория B аудит-плана `docs/plans/11_MVP_ROADMAP.md`.
Вся логика серверная/симуляционная; рендер (панель рейтинга, экран целей) —
клиентский, вне периметра этого дока.

## Индекс национальной силы

`shared/src/utils/nationalPower.ts::getNationalPower(country)` — взвешенная
сумма нормализованных компонент из уже трекаемых величин:

- **ВВП** (`/POWER_GDP_SCALE`, вес `POWER_WEIGHT_GDP`) — доминирует, как реальная
  мера мощи державы.
- **Военная сила** (`activePersonnel × combined-arms + техника × вес`,
  `/POWER_MILITARY_SCALE`, вес `POWER_WEIGHT_MILITARY`) — та же мера, что
  `WarTick.sideStrength`, чтобы «сила на карте» и «сила в рейтинге» не расходились.
- **Население** (`/POWER_POPULATION_SCALE`, вес `POWER_WEIGHT_POPULATION`).
- **Технологии** (сумма тиров доменов, вес `POWER_WEIGHT_TECHNOLOGY`).

Константы — `shared/src/defines/objective.ts`. Абсолютное значение не важно —
служит только для ранжирования стран. Территориальная компонента (число
регионов) зарезервирована, пока не в формуле.

## Позиция игрока

`computePlayerStanding(countries, playerCountryId)` ранжирует все страны по
силе (убыв., ничьи по id) и возвращает `{ power, rank, total }`. Пересчитывается
каждый ход в `server/src/simulation/ObjectiveTick.ts::objectiveTick` (после
агрегации и боевых тиков — по состоянию на конец месяца), кладётся в
`GameState.playerStanding`. Также выставляется на старте в `CreateGame`.
Хранится (производное состояние) ради дешёвого доступа UI/промта без пересчёта
128 стран на каждый рендер.

## Цели игрока

`Country.goals: StrategicGoal[]` (`shared/src/types/GrandStrategy.ts`) —
дискриминированный union по `kind`, движок умеет оценивать эти виды
детерминированно (без LLM-суждения):

| kind | параметры | выполнено, когда |
|------|-----------|------------------|
| `reach_gdp` | `target` | `economy.gdp ≥ target` |
| `reach_power_rank` | `targetRank` | `playerStanding.rank ≤ targetRank` |
| `control_regions` | `targetCount` | легально владеет ≥ `targetCount` регионов (оккупация не в счёт — цель про устойчивый контроль) |
| `reach_tech_tier` | `domain`, `targetTier` | тир домена ≥ `targetTier` |

`evaluatePlayerGoals` (в `objectiveTick`) каждый ход проверяет незавершённые
цели игрока; при выполнении ставит `completed = true` и кладёт мировой факт
«X achieved its strategic goal: …» в промт LLM (тот же паттерн
`pendingWorldFacts`, что кризисы/тиры). `completed` принадлежит движку.

### Установка целей (контракт для UI)

- **`PUT /objective/goals`** (`server/src/routes/objective.ts`), тело
  `{ goals: [{ id, kind, …параметры, title? }] }` — заменяет весь список целей
  игрока. Валидация — `setGoalsSchema` (Zod, `validation/schemas.ts`); `completed`
  от клиента не принимается (движок сбрасывает в false). Команда —
  `commands/objective.ts::setPlayerGoals` (не трогает цели ИИ-стран).
- `GameState.playerStanding` доступно клиенту в каждом ответе состояния — UI
  рендерит «ты #N из M».

### Обратная связь после хода

`GameService.advanceMonth()` сохраняет в опциональном
`GameState.lastTurnReport` только последний детерминированный diff игрока:
даты/длина хода, изменившиеся `power/rank/gdp/treasury/population/stability/
legitimacy/regions` и id впервые завершённых целей. Это bounded snapshot, не
event sourcing и не растущая история. `NationalBriefing` показывает standing,
прогресс целей и до трёх изменений; старые saves без поля остаются валидны.

## Осознанно вне этого слоя (кандидаты)

- Навязанная движком победа/поражение (сверхдержава к дате, коллапс) — модель не
  выбрана (пользователь предпочёл самопоставленные цели).
- Цели в свободном тексте с оценкой выполнения LLM — фаззи, нужен живой Gemini;
  сейчас цели строго типизированы и оцениваются детерминированно.
- Цели для ИИ-стран (сейчас целевой слой — только про игрока).
- Территориальная/дипломатическая компонента индекса силы.
