# Geopolis — концепт

> Единый источник истины: что такое Geopolis, идентичность, системы, границы v1,
> ключевые принципы. Синтез дизайн-цикла (Фазы 0–3). Продуктовые решения приняты;
> инженерные контракты помечены отдельно. Детали реализации и последовательность —
> в дорожной карте (`docs/plans/11_MVP_ROADMAP.md`).
>
> Статус: черновик, в работе (2026-07-24).

## 1. Что такое Geopolis

Geopolis — одиночная grand strategy в альтернативной истории. Игрок ведёт державу
сквозь десятилетия мировой истории (горизонт видения — 1836–2100; играбельный старт —
холодная война, 1946), без микроменеджмента.

Отличие от жанра (Paradox и пр.): мир не движется по скриптам и не считается игроком
вручную. Миром движет **LLM-режиссёр** поверх детерминированного движка. Свобода «что
может произойти» — от языковой модели; надёжность «что при этом происходит с числами» —
от движка.

Родословная — Pax Historia (популярная LLM-стратегия) и её боли, которые Geopolis
решает адресно:

| Боль Pax Historia | Ответ Geopolis |
|---|---|
| LLM выдумывает числа (экономика «на словах») | Все числа у движка; LLM не источник ни одного числа |
| Рельсы (событие вписано в промт как неизбежное) | Движок даёт пороги-предпосылки, не сценарий; развилки, не расписание |
| Дорогой ход, растущий с историей (весь мир в промт каждый прыжок) | В промт идут агрегаты (~18 стран из 128), не весь мир; рост стоимости мал и купируется бюджетами промта |
| Деградация долгих кампаний (контекст пухнет) | Летопись с суммаризацией + жёсткие бюджеты промта и сейва |
| Рассинхрон карта↔нарратив («территория отошла молча») | Нарратив пишется только после того, как движок применил изменение |

**Player Experience Goal.** Ощущение — макро-управление державой (EU4/Victoria) с
понятной долгой дугой (Civ, «ещё один ход»), без микроменеджмента. База — наблюдение
за живым миром + намерения свободным текстом при переменном темпе; кризисы (война,
дефолт, переворот, ультиматум) переключают в плотный режим решений с ценой — вплоть до
game over (падение государства = конец кампании). Мир не на рельсах: державы преследуют
цели и реально угрожают, жёсткость настраивается сложностью.

**Эпохи.** Видение — три эпохи: 1836–1945 (индустриализация, колониализм), 1946–1999
(холодная война), 2000–2100 (ИИ, космос, кибер). Механика строится **эпохо-агностично**
через «профиль эпохи» (данные/конфиг, не хардкод); релиз и данные — инкрементально
от 1946.

## 2. Идентичность: алфавит примитивов воздействия

Ядро игры и главная ставка дизайна.

Развилка была: свобода Pax Historia (LLM двигает мир) ценна, но несла боли; жёсткий
каталог фиксированных команд убил бы свободу. Решение —

**Алфавит примитивов воздействия**: малый набор (~15–20) элементарных примитивов-глаголов,
которыми LLM выражает *любое* событие. Примитив = «буква»; событие = «слово» из букв.
Примеры: `изменить_отношение`, `сместить_правительство`, `разжечь_недовольство(регион)`,
`сдвинуть_идеологию`, `бегство_капитала`, `построить_объект`, `переместить_объект`.

- LLM свободно **комбинирует** примитивы в событие — свобода «ЧТО» (как в PH).
- Движок **валидирует предпосылки** каждого примитива и **считает числа** последствий —
  надёжность «можно ли / насколько».

Алфавит vs готовый каталог команд = буквы vs готовые слова. Свобода PH и надёжность
движка — в одной схеме. Выбор цикла: **широкий алфавит** (свобода важнее безопасности,
ценой сложности валидатора).

**Единый язык изменения мира.** Одним алфавитом действуют и LLM, и игрок: построить порт,
заложить верфь — те же примитивы, что применяет режиссёр. Один валидатор, без дублирующих
путей (build отдельно, события отдельно).

**4 зоны свободы LLM:**

1. **Режиссёр кризисов** — движок даёт порог → LLM выбирает ветку и подачу → движок считает.
2. **Голос мира** — нарратив, летопись, история места.
3. **Переводчик намерения игрока** — свободный текст игрока → валидные примитивы.
4. **Альт-исторические развилки** — отклонения от реальной истории с проверкой предпосылок.

**Границы LLM (что она НЕ делает):** не трогает числа; не создаёт/не удаляет страны
произвольно (только lifecycle-командами с инвариантами); не меняет карту напрямую (только
через примитивы); не пишет скриптовые рельсы (движок даёт пороги, не сценарий).

**Честная цена (не серебряная пуля).** Схема *переносит* сложность, не устраняет: валидатор
примитивов — новое сердце сложности (слабый → произвол PH; строгий → LLM бессильна); каждый
примитив требует балансировки формул; предпосылки требуют богатого состояния мира. Открытые
риски рамки (закрыть при детализации алфавита): «режиссёр кризисов» не должен стать новыми
рельсами (граница «давление vs навязывание»); «влияние в рамках» не должно стать косметикой
(нужно несколько разных исходов, не один предрешённый); эмерджентность проектируется связями
систем, а не возникает от их числа.

> **Статус.** Направление принято. Детальный состав примитивов и контракт валидатора —
> предмет отдельной будущей сессии. Здесь ядро названо, но не специфицировано — это главный
> известный пробел концепта.

## 3. Ключевые принципы

Сквозные правила, из которых выводятся все системы.

1. **Числа — движку, свобода — LLM в рамках.** Движок владеет всем состоянием и расчётами.
   LLM влияет через примитивы; влияние валидируется и считается движком.
2. **Богатое состояние + простые правила.** «Не переусложнять» — про МЕХАНИКИ, не про
   СОСТОЯНИЕ. Состояние мира (демография, экономика, отношения, идеология) наращиваем —
   примитивам нужна опора для предпосылок и последствий; число отдельных механик, наоборот,
   сокращаем (спец-события = сборки примитивов, не отдельные подсистемы).
3. **Три роли — сквозной формат каждой системы:**
   - **Движок** — детерминированные числа; выставляет ФАКТ при пороге, не решает исход.
   - **LLM** — факт + контекст → нарратив + примитивы; решает, разыграть или проигнорировать;
     чисел не трогает.
   - **Игрок** — причина, не зритель: задаёт курс, реагирует на кризисы примитивами.

   Вес ролей РАЗНЫЙ по системам: чем измеримее система, тем меньше в ней LLM (экономика в
   мирный ход — LLM=0, включается в кризис; перевороты — LLM центральна). Это дизайн-сигнал,
   не недоработка.
4. **Почему не рельсы (три уровня).** Порог — следствие решений игрока, не расписание; LLM
   решает, как и разыгрывать ли; игрок — причина событий, не их зритель.
5. **Эпохо-агностичность.** Одно ядро + «профиль эпохи». Расхождения эпох трёх видов:
   вкл/выкл подсистемы (колонизация 1836 → мертва 2000); пере-калибровка тех же систем
   (прямые войны 1836 vs прокси при ядерном сдерживании); новые надстройки поздней эпохи
   (2000: кибер/космос/ИИ).
6. **Против расползания.** Каждая система обязана иметь точку влияния (LLM или игрок).
   Чистый фон, не питающий другие системы, — кандидат на рез из v1.

## 4. Состояние мира — фундамент

Принцип «богатое состояние + простые правила» здесь материализуется: примитивам нужна
опора — нельзя разжечь сепаратизм, если неизвестно, «кто населяет регион и почему
недоволен». Поэтому состояние мира наращиваем, а несущими для всей схемы влияния являются
два слоя — демографический состав регионов и идеология — плюс связанная с ними ось типа
экономики (§4.3).

### 4.1. Демографический состав регионов

Сегодня регион знает только число жителей — на этом нельзя построить ни национализм, ни
сепаратизм, ни деколонизацию (выходят рельсы: движок «назначает» восстание произвольно).
Решение — **лёгкий демо-состав** (не Victoria-pops):

- Регион хранит **доминантную группу + 1–3 меньшинства** (нация/культура, опционально
  конфессия) с долями.
- Настроение/недовольство **не хранится** — движок **выводит** его из: идеология власти vs
  позиция группы + экономика региона + репрессии/уступки + оккупация.

Хранимое минимально, производное считается на лету — состояние богатое, но дешёвое.
Демо-состав — **фундамент, а не фича**: на него опираются сепаратизм, распад (§5.5), сферы
влияния (§5.4), деколонизация и любой примитив, адресующий население.

> **Data-долг.** Наполнение демо-состава ~1366 регионов — крупная задача наполнения данными;
> внешний этно-конфессиональный источник и его лицензия пока не найдены (открытый риск, в
> дорожной карте).

### 4.2. Идеология: спектр под именованными зонами

Идеология **двигаемая** (не фиксированный ярлык) и хранится как **гибрид спектра и зон**:

- Под капотом — **две непрерывные оси**: экономическая (лево ↔ право) и политическая
  (авторитаризм ↔ демократия). Движок хранит **координаты** страны.
- Сверху — **именованные зоны** (области спектра): «коммунизм», «фашизм», «либеральная
  демократия» и т.д. — для читаемости LLM и игроком.

Что это даёт:

- **Нюанс.** СССР, Югославия и Китай под одним ярлыком «коммунизм» — на спектре в разных
  точках; союзы = близость координат, а не совпадение ярлыков.
- **Плавный дрейф.** Примитив `сдвинуть_идеологию` смещает координаты постепенно, без скачков
  «ярлык А → ярлык Б».
- **Главное — геометрия недовольства.** Недовольство группы = **дистанция** «позиция власти vs
  позиция группы» на спектре. Это убирает ручные таблицы «нация X недовольна при режиме Y»:
  недовольство считается из расстояния, напрямую стыкуясь с демо-составом (§4.1) и примитивом
  `разжечь_сепаратизм`.

Размен по нашему принципу: усложняем СОСТОЯНИЕ (координаты стран), но УПРОЩАЕМ механику
(недовольство и союзы = геометрия, а не таблицы правил).

> **Data-долг.** Стартовые координаты ~128 стран 1946 — задача наполнения (субъективна, но
> именованные зоны дают проверяемость). В дорожной карте.

### 4.3. Тип экономики — отдельная ось

Тип экономики (плановая / смешанная / рыночная) — **отдельная от идеологии ось**, статистически
с ней связанная (коммунизм тяготеет к плановой, но возможны рыночный социализм или
госкапитализм). Работает как модификатор производства и политики (плановая: гос-контроль
выпуска, ниже коррупции-от-рынка, ниже роста/инноваций; рыночная — наоборот). Двигается
примитивом `провести_реформу` с политической ценой (историческая цель 1946 «отход от плановой» =
серия реформ). Механика — в §5.1 и §5.2.

## 5. Системы

Каждая система — в сквозном формате: контекст → ключевые решения → три роли → почему не
рельсы → границы v1. Вес LLM разный: у измеримых систем (экономика) в мирный ход LLM = 0;
у политических — LLM центральна.

### 5.1. Экономика · производство · ресурсы

Контекст: макро-каркас есть (ВВП, доли бюджета, долг с risk-premium), но ВВП не умеет падать,
инфляция без границ, население растёт экспонентой; производство — «чистые деньги» без
мощностей и сырья; ресурсы добываются, но не потребляются (только продаются). Цель — замкнуть
микро-фундамент под макро, не уходя в Victoria-микро.

**Ключевые решения:**

- **Глубина — макро + последствия.** ВВП-якорь + доли бюджета + долг. Добавить: рецессию (ВВП
  умеет падать), инфляцию с границами, **логистический рост населения** (ёмкость K от
  еды/инфраструктуры/тех — лечит демографический взрыв).
- **Производственная мощность = агрегат региональных вкладов** (регион-пул, не абстрактный
  страновой). Потеря региона = вклад выпадает автоматически. Оживить уже существующее мёртвое
  (сектор industry региона, developSectors, тип экономики).
- **Сырьё потребляется через гейт** (бинарно): нет ключевого ресурса → слот техники не
  производится. Риск резких обрывов принят, смягчаем буфером/порогом при балансе.
- **Военный выход = мощность + сырьё (гейт) + деньги** (заменяет «чистые деньги»). Гражданский
  выход → ВВП/благосостояние, без отдельной сущности «товары» в v1.
- **Долговая цепочка.** Долг/инфляция/безработица → стабильность↓ (эмерджент) + дефолт как
  кризис-событие при пороге долг/ВВП около 1.0 (калибровочный порог с гистерезисом восстановления —
  контракт §7). Экономика **никогда** не даёт game over напрямую — только через нестабильность →
  переворот/раскол → военное добивание.

**Три роли:**

| Роль | Что делает |
|---|---|
| Движок | Считает ВВП/мощность/добычу/долг/инфляцию; агрегирует регион-пул; выставляет факт «рецессия»/«дефолт» при пороге |
| LLM | В мирный ход — 0 (система измерима); в кризис (дефолт) — режиссирует событие + примитивы (`бегство_капитала` и т.п.) |
| Игрок | Доли бюджета, инвестиции в сектора/регионы, приоритеты производства, запас сырья, мобилизация, реформа типа экономики |

**Не рельсы:** долг и рецессия — следствие бюджетной политики игрока, не расписание;
кризис-порог = его накопленные решения.

**Границы v1:** без цепочек переделов и Victoria-микро; без сущности «товары»; рабочая сила —
неявно (capacity от населения; явный labor-пул post-v1).

> **Открытая развилка (в дорожную карту).** Дать ли игроку аустерити как рычаг против долга
> (симметрия с ИИ, у которого защита от долговой спирали уже есть)? Без неё долг рискует стать
> неизбежностью, а не выбором. В ledger зафиксирована проблема, но не решение — оставлено открытым.

### 5.2. Внутренняя политика и идеология

Контекст: политика живёт на уровне страны (оси stability/legitimacy/corruption/
governmentSupport + идеология + тип экономики), регион политически пуст, идеология не движется,
переворотов в тике нет. Фундамент из §4 (демо-состав + спектр) даёт этой системе опору:
недовольство выводится геометрией «власть vs группа», а не таблицами.

**Ключевые решения:**

- **Политические примитивы** в алфавит: `сместить_правительство` · `сдвинуть_идеологию` ·
  `провести_реформу` · `разжечь_сепаратизм` · `репрессировать`↔`уступить` · `выборы`.
- **Спец-механики — сборки примитивов, не отдельные системы.** Переворот, гражданская война,
  восстание = комбинации примитивов + предпосылки (детально — §5.5).
- **Репрессии vs уступки — с ценой.** Подавление: недовольство ↓ кратко, но дистанция/отчуждение
  группы растёт (загнал вглубь). Уступка: ↓, но другие меньшинства осмелели. Реформа: медленный
  сдвиг координат.
- **Выборы** — для демократий: легальная смена власти/курса, иной ритм, чем переворот. Примитив
  в алфавите с начала, детальные циклы — post-v1.

**Три роли:**

| Роль | Что делает |
|---|---|
| Движок | Хранит демо-состав + оси политики + координаты идеологии; выводит недовольство (геометрия); валидирует предпосылки; считает последствия |
| LLM | Центральна (система слабо измерима): режиссирует полит-события из примитивов, выбирает ветку и подачу кризиса |
| Игрок | Реформы/репрессии/уступки/смена курса; сдвиг идеологии и типа экономики; реакция на кризисы |

**Не рельсы:** недовольство = геометрия состояния (идеология власти + экономика + демо-состав),
не назначенное сверху; игрок выбирает ответ, LLM — подачу.

**Границы v1:** не Victoria-pops; детальные фракции и электоральные циклы — post-v1 (примитивы
заложены).

### 5.3. Война · море · техника · ядерное

Контекст: война есть, но декоративна — юниты в бой не входят (сила = абстрактные числа),
моря нет вообще (острова недостижимы), войны не завершаются движком (вечные), техника — один
безликий агрегат силы, ядерного нет. Цель — сделать войну честной проекцией силы без
юнит-микро.

**Война (суша).**

- **Абстрактный фронт**: сила + сухопутная смежность + флип региона при перевесе. Без
  юнит-микро.
- **Случайность боя** — сидированная ±25% (один механизм для суши и моря; воспроизводима из
  seed кампании).
- **Рода войск — средний путь**: у каждого рода характер (пехота/броня/авиация/флот/ПВО),
  бонус за combined-arms. Игрок задаёт производственный фокус, не микро.
- **Оборона = барьеры на границах** (рёбра графа: река/хребет/пролив держат при меньшей силе;
  реки из Natural Earth, public domain). Решает «регионы большие», делает «блокаду Тайваня»
  осмысленной.
- **Движок сам завершает войны**: капитуляция при разгроме + белый мир по истощению (чинит
  вечные войны).
- **Мобилизация — рычаг игрока**: +сила ценой гражданской экономики/стабильности (стык §5.1).
- **Game over в войне** = формальная капитуляция (все регионы аннексированы + капитуляция-
  событие). Оккупация всех регионов ≠ конец.

**Море** — полноценная морская война слоями: (1) морской граф + сила флота + присутствие →
достижимость островов и десант; (2) бой флот-vs-флот → господство; (3) конвои/блокада-
экономика. Флот = **проекция силы + намерение** (не ручное вождение): движок сам прокладывает
морской путь. Десант = гейт от флота при господстве. Морские зоны — гибрид (театры там, где
идут бои) + граф смежности (данные уже на IHO-основе, дорабатываются).

**Техника** — **16 слотов** (5 земля / 3 воздух / 4 море / 3 стратег / спутники), слот стабилен,
облик эволюционирует по тирам домена (танк 1946 ≠ 2000, слот один). Три раздельные оси
(инженерный контракт, §7): *capability* (что умеет проектировать = тир домена) / *readiness*
(что произведено, среднее поколение) / *doctrine-posture* (что разрешено; договоры РСМД —
posture, не тех-тир). **Модернизация платная** — парк не апгрейдится бесплатно при новом тире.
Производство: капитальное (верфи + содержание) / массовое / программное (ОМП и ядерное =
расщепляющийся материал + наука); категория плавает по паре (слот, тир).

**Ядерное** — MVP-MAD: программа (домен nuclear → боеголовки) → триада-носители (бомбардировщик
→ ракета → ПЛАРБ; периодизация: монополия США 1946–49 → уязвимый бомбардировщик → триада 1960+)
→ сдерживание (неуязвимый ответный удар → прямая война самоубийственна → **прокси**, мост к §5.4)
→ порог применения/табу. Эскалация — **событие LLM**, не микро-лестница.

**Тир технологий даёт широко:** разблокирует возможности (nuclear → программа, space → спутники,
industry → бонус ВВП) + эволюцию слотов + combined-arms. Ранний темп ускорить (иначе прогресс
не виден).

**Три роли:**

| Роль | Что делает |
|---|---|
| Движок | Считает силу/фронт/флипы/потери/warScore; прокладывает морские пути; завершает войну (капитуляция/белый мир); считает ядерный баланс |
| LLM | Режиссирует военную драму, эскалацию, применение ОМП (событие); объявляет войны за major под цели |
| Игрок | Производственный фокус, мобилизация, намерение флота, объявление/завершение войны, ядерная программа |

**Не рельсы:** войны и гонка вооружений — следствие решений (объявления/мобилизации/вложений в
nuclear), не расписание; исход боя = сила + сидированная случайность, не предрешён.

**Границы v1:** без юнит-микро и ручного вождения флота; без морского боя как отдельного микро;
десантных кораблей нет (гейт); углубление (окружение/логистика/доктрины/флот-vs-флот детально) —
post-v1.

### 5.4. Дипломатия · сферы · блоки · ООН

Контекст: базовая дипломатия есть (отношения/альянсы/гарантии-втягивание/санкции), но сфера
почти косметична (только coalition), прокси-войны — только текстовое правило, международных
организаций нет вообще. Ключевой инсайт: сфера / военсоюз / эконоблок / валютзона / ООН — это
**пять названий одной вещи** «объединение стран».

**Ключевые решения:**

- **Единая модель блоков**: одна общая оболочка, много блоков-экземпляров (СЭВ / ОВД / НАТО / ЕЭС /
  ООН / сферы — разные блоки с разным членством). Страна в нескольких блоках (ФРГ в НАТО + ЕЭС). На карте —
  переключаемые слои. Три измерения: военное (коллективная оборона) / экономическое (рынок +
  валютзона + помощь) / дипломатическое-трибуна (легитимность/осуждение/санкции).
- **Сфера = неформальный блок** (лидер + неравноправные клиенты). Права сферы — средняя глубина:
  экономические (доступ к ресурсам/рынку клиента) + ограничение дипломатии клиента (не вступит в
  чужой блок без разрыва) + обязанность защищать.
- **Прокси-война = механика**: патрон вливает силу/ресурсы клиенту, не вступая сам (воевать
  чужими руками — мост к ядерному сдерживанию §5.3).
- **ООН = Совбез с вето-держателями**: постоянные члены блокируют резолюции против себя/своей
  сферы — детерминированное правило по позициям, без поимённого голосования. Место в Совбезе —
  временное владение (не вечно за одной страной). Осуждение → −легитимность (стык §5.5).
- **Военные базы в сфере** = проекция силы (модификатор присутствия; принято рекомендацией,
  возражение открыто).

**Три роли:**

| Роль | Что делает |
|---|---|
| Движок | Считает влияние/пороги входа-выхода сферы; применяет эффекты блоков; исполняет вето-правило; втягивает коалиции в войну |
| LLM | Режиссирует борьбу за влияние, формирование/распад блоков, резолюции; команды влияния/гарантий/прокси |
| Игрок | Вступление/выход из блоков, спонсирование, прокси-поддержка, санкции, основание блока |

**Не рельсы:** влияние = следствие мощи и действий (эконом/воен помощь, идеология, спонсирование
переворота); блоки возникают по влиянию/идеологии, а не по расписанию (НАТО не обязано появиться
в 1949).

**Границы v1:** дипломатия-переписка (переговорный слой) осознанно отложена до публикации —
отдельной ролью и анти-абузно, не в ядре; блоки — общая оболочка, единая рантайм-семантика не
навязывается.

### 5.5. Перевороты · распад · рождение государств

Контекст: динамического создания/удаления страны в проде нет вообще (страна с 0 регионов
продолжает жить), команд смены режима/раскола/объединения нет, переворот существует только как
факт при низкой стабильности. Это несущая механика альт-истории: без неё распад СССР или
деколонизация невозможны.

**Ключевые решения:**

- **Три подсистемы — через примитивы + предпосылки, не отдельные тики:**
  - *Переворот/смена режима* (не смертельно): движок даёт давление от стабильности → примитив
    `сместить_правительство` → движок применяет (идеология/цвет/имя, сброс легитимности, пересчёт
    отношений с блоками).
  - *Распад* (не смертельно игроку — есть преемник): движок ставит условие (низкая стабильность +
    поражение) → примитив `split_state` → движок создаёт осколки, делит регионы/население/армию/
    казну так, что суммы сходятся.
  - *Рождение* (деколонизация/сепаратизм/объединение): `create_state`/`secede`/`unify`.
- **При расколе страны игрока — выбор игрока**, за какой осколок продолжать (по умолчанию наследник
  столицы). Раскол и переворот **не** game over.
- **Свобода рождения — гибрид**: исторические осколки берутся из данных региона (предопределённые
  преемники), неисторические LLM создаёт при дивергенции; движок валидирует.
- **Анти-зомби**: движок форсирует переворот/распад при затяжном экстремуме стабильности — но не
  жёстким одним исходом, а ограниченным меню исходов с таймаутом.
- **Игрок спонсирует чужой переворот** (разведоружие холодной войны — стык §5.4).
- **Жёстче, чем Pax Historia**: структурная команда карты валидируется движком по всем инвариантам;
  невалидное отклоняется **целиком** (никакого «событие осталось, а мир не изменился»). Контракт
  атомарности и lifecycle — §7.

**Три роли:**

| Роль | Что делает |
|---|---|
| Движок | Давление стабильности → факт кризиса; валидирует инварианты структурных команд; атомарно создаёт/делит/удаляет polity; форсирует при экстремуме (меню исходов) |
| LLM | Режиссирует переворот/распад/рождение из примитивов; неисторические осколки при дивергенции |
| Игрок | Выбор осколка при расколе; спонсирование чужого переворота; реформы против кризиса (§5.2) |

**Не рельсы:** кризис — следствие стабильности (экономика/идеология/война), не расписание;
исторические осколки из данных, но LLM волен на неисторические; форсирование только при затяжном
экстремуме и с выбором исхода.

**Границы v1:** правительство в изгнании — post-v1; сопротивление/партизаны детально — post-v1.

### 5.6. Карта и динамические объекты · история места

Контекст: Map Features сегодня — чистый декор (тип несёт только координаты/имя/теги, ни одного
игрового атрибута; половина типов вообще не генерится). Требования пересобраны с нуля: карта
должна показывать массовое, нести уникальные места, быть **динамической** (создавать/менять/
двигать/разрушать) и не раздувать состояние.

**Ключевые решения (модель по природе объекта):**

- **Массовое количественное** (мощность/добыча/население/недовольство) → **производные слои
  раскраски** (режимы карты уже есть). Меняется через состояние региона, пообъектно не хранится.
- **Уникальные объекты** (столица/порт/верфь/ядерный объект/крепость/landmarks) → **хранимые
  динамические объекты**: создаются/двигаются/разрушаются явно; их мало → дёшево.
- **События** (восстание/протест/спорная граница) → **временные объекты** (примитив создаёт,
  `expiresAt` чистит).
- **Динамика = единый механизм примитивов.** Игрок и LLM меняют карту одним алфавитом:
  строительство игрока (`построить_порт`/`заложить_верфь`/`возвести_крепость`) — те же примитивы,
  что применяет режиссёр. Не отдельный build-путь. Алфавит расширяется на карту:
  `построить_объект`/`переместить_объект`/`разрушить_объект`. Строительство возвращается как
  геймплей — рычаг игрока на карте.
- **История места**: каждый уникальный объект / значимый регион копит **локализованную** хронику
  (Берлин: 1948 блокада → 1953 восстание → 1961 стена); клик → инспектор показывает. Делает места
  живыми и уникальными, альт-историю осязаемой. Условие — капирование/суммаризация (копят только
  значимые места, не каждый пустой регион; боль unbounded chronicle).

**Три роли:**

| Роль | Что делает |
|---|---|
| Движок | Строит производные слои из состояния; хранит и валидирует уникальные/событийные объекты; ведёт историю места с капом |
| LLM | Примитивами создаёт/меняет объекты и события; озвучивает историю места |
| Игрок | Строит через примитивы; видит, что где; клик → инспектор + история |

**Не рельсы:** карта отражает состояние (производное), уникальные объекты меняются только
примитивами с предпосылками (порт — только на побережье).

**Границы v1:** карта-как-ввод-приказов — задача UI, post-заморозка (механически приказы уже
адресуются к объектам); точечные фича-цели («разбомбить конкретный мост») — post-v1; история места
только для значимых мест.
