# 08 — Война, волна 1: оккупация ≠ аннексия, мир, потери, долг

Приоритет: P1 — связный контур «война имеет цену и итог» поверх уже
работающих систем. Четыре механики намеренно в одном плане: они замыкаются
друг на друга.
Статус: не начато.
Зависимости: 01 (transferRegion), 03 (команды/модификаторы/defines).

## 1. Оккупация ≠ аннексия

**Проблема:** `WarTick.ts:119` меняет `region.ownerCountryId` напрямую —
захваченный регион мгновенно становится легально чужим: платит налоги
захватчику, перекрашивается навсегда; мира «верни оккупированное» не
существует. Любая долгая война необратимо перекрашивает карту.

**Модель:**
- `Region.occupiedBy?: string` поверх `ownerCountryId`.
- Война двигает ТОЛЬКО оккупацию; владение двигает только мирный договор
  (командой `transferRegion`).
- Эффекты оккупации: доход/добыча региона идут оккупанту с штрафом
  (коэффициент в defines), стабильность региона падает (модификатор).
- Конец войны: не аннексированное по договору — оккупация снимается.
- Карта: оккупация — заливка цветом оккупанта со штриховкой (у клиента
  уже есть паттерн оккупационных оверлеев 1946).

## 2. Цели войны, war score, мирные договоры

**Проблема:** война бинарна (идёт/не идёт), `peace` — одно действие LLM без
условий. Некуда «выигрывать».

**Модель:**
- `War.warScore: number` (−100..100) — движок считает из: флипов оккупации
  (`territoryFlips` уже есть), соотношения потерь, длительности (истощение
  тянет к миру). Формула в defines.
- Мир — структура, а не сигнал:
  ```ts
  interface PeaceTerms {
    annexations: { regionId: number; to: string }[];
    reparations?: { from: string; to: string; amount: number };
    puppet?: string;
    demilitarize?: string;
  }
  ```
- LLM предлагает договор; валидатор проверяет «по средствам ли» текущего
  warScore (стоимость условий в очках — defines). Слишком жадный договор
  отклоняется с причиной — модель предлагает скромнее.
- Применение: команда `makePeace(warId, terms)` — annexations через
  `transferRegion`, репарации — из казны в казну, снятие оккупаций,
  `war.active = false`.
- Белый мир по таймауту/обоюдному истощению — детерминированный fallback,
  если LLM игнорирует затухшую войну N месяцев (порог в defines).

## 3. Потери → демография

**Проблема:** война никого не убивает — population и manpower не трогаются.
На горизонте 1836–2100 мировые войны обязаны оставлять демографические ямы.

**Модель (v1):**
- WarTick начисляет месячные потери сторонам из соотношения сил и числа
  контактных регионов (коэффициенты в defines).
- Потери списываются: с `military.activePersonnel` (в первую очередь),
  с `population` регионов фронта (гражданские + мобилизационная база),
  с `military.manpower` страны.
- `War.casualties: { [countryId]: number }` — накапливается, участвует в
  warScore и в промте LLM (готовый мировой факт: «X потеряла N человек»).
- PopulationTick уже существует — восстановление идёт естественным ростом,
  яма на десятилетия получается сама.

## 4. Госдолг

**Проблема:** `EconomyState.debtInterest` существует, но самого долга нет —
висящий провод. Война без займов не финансируется, дефолтов не бывает.

**Модель (v1):**
- `EconomyState.debt: number`. Дефицит бюджета покрывается ростом долга
  (казна не уходит в минус бесконечно: ниже нуля → конвертация в долг).
- `debtInterest = debt × interestRate` (ставка в defines; выше при низкой
  legitimacy/stability — одна формула).
- Порог долг/ВВП → модификатор (штраф росту) + детерминированный мировой
  факт «X на грани дефолта» (план 02, шаг 4). Сам дефолт отыгрывает LLM
  (списание долга + тяжёлые модификаторы) — команда `default(countryId)`.
- Репарации из п.2 могут выплачиваться в долг.
- AiBehaviorTick: правило аустерити уже смотрит на treasury — согласовать
  с долгом (аустерити при долг/ВВП выше порога).

## Порядок реализации внутри плана

1 (occupiedBy) → 3 (потери; нужен фронт из 1) → 2 (мир; нужны score из 1+3)
→ 4 (долг; независим, можно параллельно).

## Критерии приёмки

- [ ] Флип фронта не меняет ownerCountryId; доход оккупированного региона идёт оккупанту со штрафом (тест).
- [ ] Мир возвращает неаннексированную оккупацию; аннексия по договору переносит владение через transferRegion (тест).
- [ ] Договор дороже warScore отклоняется с причиной (тест).
- [ ] Годовая война снижает population регионов фронта и manpower сторон (тест).
- [ ] Дефицит наращивает debt; debtInterest растёт следом; факт «долговой кризис» появляется в промте при пороге (тест).
- [ ] Кампания-смок: война мажоров 24 месяца → мир → карта и экономика в согласованном состоянии.
