> зависимости, накопленный data-долг и гейт релиза. Оценки объёма грубые (S / M / L) и

## Принципы дорожной карты

1. **Одна вертикаль вглубь, потом вширь.** Первый милстоун — вертикальный срез (§9 концепта),
   а не «все системы понемногу»: он бьёт в самое рискованное — валидатор примитивов.
2. **Ключевые зависимости** (нарушишь порядок — упрёшься):
   - **Детали алфавита примитивов + контракт валидатора = отдельная дизайн-сессия.** Блокер
     полного алфавита; срез обходится мини-набором ~5 примитивов.
   - **Демо-состав регионов = фундамент** под всю схему влияния (недовольство / сепаратизм /
     сферы) — до политики и распада.
   - **Телеметрия токенов — до бюджетов** (нельзя бюджетировать вслепую).
   - **Лицензии — гейт релиза** (не разработки): строим свободно, публикацию блокируем до зелёного.
3. **Оживить, а не построить с нуля.** Сквозной цикл уже собран (ниже); многое из состояния
   существует мёртвым кодом. Редизайн чаще «оживляет + добавляет алфавит», чем пишет заново.
4. **Инженерные контракты (§7 концепта) — сквозные.** State machine, атомарный pipeline,
   разделённые сущности, бюджеты — не отдельная фаза, а требование к каждому милстоуну, который
   трогает состояние.
5. **UI заморожен.** Дорожная карта — про движок / данные / симуляцию. Карта-как-ввод-приказов и
   панели — отдельный UI-трек (post-заморозка), здесь не планируются.

## Что уже есть (переиспользуется; проверено по коду в аудите Фазы 0)

Сквозной цикл собран целиком — фундамент, не заготовка:

- **Старт → ход → сейв:** выбор сценария/страны/языка → `POST /game/start`; `POST /game/next-turn`
  → полная симуляция (13 детерминированных тиков); autosave после хода.
- **LLM-цикл:** ручной (copy-paste) + авто (Gemini); Zod-контракт + капы + гейт хода.
- **Рычаги игрока:** бюджет, исследования-доли, свободнотекстовое намерение.
- **Состояние:** один GameState (plain data), сейв JSON, seeded RNG, летопись.
- **Мёртвое, но готовое к оживлению:** сектор `industry` региона, `economyType`,
  поля техники — существуют, тиками не читаются (§5.1/§5.2 концепта).

Редизайн опирается на это: добавляет алфавит примитивов + богатое состояние (демо-состав,
идеология-координаты) + оживляет мёртвое. Ветка цикла не влита в main; интеграцию инициирует
пользователь.

## Милстоун 0 — Вертикальный срез (валидатор примитивов) — **закрыт 2026-07-27**

Цель: доказать ядро (§9 концепта) — LLM-режиссура через алфавит примитивов под движковым
валидатором работает на нетривиальной предпосылке. **Одна полная вертикаль**, играбельная, узкая.

Статус: закрыт двумя сессиями — A (ядро недовольства и движок примитивов) и B (LLM-контракт,
путь игрока, отклик). Полный отчёт по критериям и оставшимся хвостам —
[`13_MILESTONE_0_VERTICAL_SLICE.md`](13_MILESTONE_0_VERTICAL_SLICE.md), калибровочные хвосты —
`docs/TODO.md`.

Сценарий: внутренний политический кризис в нацрегионе СССР (игрок за СССР); только цикл
недовольства, без отделения/рождения государств.

**Содержание:**

| Задача | Объём |
|---|---|
| Мини-демо-состав: СССР + 1–2 нацрегиона (Прибалтика/Украина), вручную (не полный 1366) | data (мини) |
| Идеология-координаты СССР + групп, вручную (мини) | data (мини) |
| Расчёт недовольства = геометрическая дистанция (§4.2) + экономика | S/M |
| Детекция порога → факт «кризис в регионе X» | S |
| Мини-алфавит ~5 примитивов: `разжечь_недовольство` / `подавить` / `уступить` / `реформа` / `создать_событие` | M |
| Валидатор предпосылок примитивов + атомарное применение (зачаток контракта §7.2) | M/L |
| Путь игрок → примитив (намерение → валидные примитивы) | M |
| Отклик: хроника + история места (§5.6) + объект на карте | S/M |

**Петля:** тики растят недовольство → порог → LLM режиссирует из примитивов (движок валидирует
предпосылку) → игрок решает примитивом → движок детерминированно применяет (подавил ↓кратко /
уступил ↓+осмелели другие / реформа медленный сдвиг) → новое состояние → новое давление.

**Доказывает:** валидатор работает на демо-дистанции, а не на голом числе — «новое сердце
сложности».
**Вне среза:** война, море, дипломатия, глубокое производство, полный демо-состав, полный алфавит,
красивый UI, отделение-lifecycle.
**Почему первым:** использует МИНИ-версии демо-состава и алфавита — реализуем ДО отдельной сессии
по полному алфавиту, но уже сквозь весь стек.

**Детальное ТЗ для сессии разработки:** [13_MILESTONE_0_VERTICAL_SLICE.md](13_MILESTONE_0_VERTICAL_SLICE.md).

**Закрыт 2026-07-27** (сессия A — 2026-07-26, сессия B и доводки по внешнему аудиту —
2026-07-27, слиты в `main`): доказано, что валидатор примитивов детерминированно
принимает/отклоняет предпосылку на нетривиальной демо-дистанции, а петля недовольство →
кризис → LLM-режиссура → примитив игрока → новое состояние замыкается сквозь весь стек.
Критерии готовности и известные хвосты —
[13_MILESTONE_0_VERTICAL_SLICE.md](13_MILESTONE_0_VERTICAL_SLICE.md) §«Критерии готовности».

## Милстоуны 1–6 — от среза к v1

Порядок — рекомендация синтеза по зависимостям; непересекающиеся задачи внутри милстоуна
параллелизуемы, но зависимости между милстоунами обязательны. Инженерные контракты §7 концепта —
сквозные (каждый милстоун, трогающий состояние, соблюдает атомарность и lifecycle).

### Сквозной критерий закрытия — достижимость глаголов, а не список пунктов

**Решение пользователя 2026-08-30** (`docs/DECISIONS.md`). Милстоун закрыт не
когда его пункты сделаны, а когда **глаголы, которые он разблокирует,
прозвучали в прогоне живой модели** — для глаголов игрока — прошли
`translatePlayerOrder` и применились. Таблица «чем разблокируется каждый из
десяти» ниже перестаёт быть комментарием к перестановке порядка и становится
рабочим артефактом: она же список милстоунов, она же критерий их закрытия.

**Одно число вместо шести списков:** сколько глаголов из 22 достижимы.
База — **10 из 22** (`.agent/runs/campaign-5y-2026-08-21/`, 60 ходов, 0 ошибок,
262 действия). Работа, не доходящая до партии, счётчик не двигает: мёртвое поле
остаётся мёртвым при любом числе зелёных тестов. Именно так были пропущены
`sovereigntyStatus`/`overlordIds` (размечены на 157 стран, не читает ни одна
механика), `industry` и `economyType` (в состоянии есть, тики не читают),
`build_extraction` (произнесён 8 раз, применён 0 — заперт потолком данных).

**Чего счётчик НЕ меряет и чем это дополняется.** Он меряет богатство мира, а
не интерес партии: во всех трёх прогонах 2026-08-21 **ноль человеческих
решений**. Второе число критерия v1 — партия, сыгранная пользователем насквозь
(см. «Критерии приёмки v1»).

### Порядок исполнения на 2026-08-30 (владелец продукта)

```text
P-1 геометрия ∥ P-3 промт → P-4 стартовая дипломатия → P-2 бюджет промта → М4-ядро → М2 → М3 → М4-глубина → М5 → М6
```

Три уточнения к порядку 2026-08-09, каждое с основанием:

1. **`geometry` и `world` не параллелятся.** `scripts/map/**` делится двумя
   доменами, и обе стороны заканчивают полным прогоном пайплайна, переписывающим
   `regions.core.json`, `regions.state.json` и `world_1946.geojson`
   (`.agent/orchestration/geometry.md`). Регенерация мира — одна ветка за раз.
2. **Геометрия закрывается первой.** Перенаполнение мира на неокончательной
   геометрии придётся делать дважды.
3. **Промт-диагностика (объём S) идёт ПЕРЕД М4-ядром (объём L).** Основание —
   контрольный случай `guarantee`: механика полная, войны не требует, слот
   свободен в 80% ходов, и ноль за 480 ходов. Плюс разбор
   `.agent/runs/war-never-happens-2026-08-21/`: единственное упоминание войны в
   промте — запрет, разрешающей строки нет ни одной, а глаголы с явным
   разрешением (`research_shift`, `production_shift`) — в топе. Значит у немоты
   есть КОНКУРИРУЮЩАЯ причина «не разрешено», и пока она не отделена от
   «нечему действовать», М4-ядро можно построить и обнаружить, что глаголы
   молчат по-прежнему. Один заход S отвечает, нужен ли заход L.

### Порядок исполнения переставлен 2026-08-09 — война перенесена в ядро

**Решение пользователя:** «воевать можно — это ядро». Отсюда порядок исполнения
больше не совпадает с нумерацией:

```text
М1 → М4-ядро → М2 → М3 → М4-глубина → М5 → М6
```

**Номера НЕ меняются.** На «М<цифра>» и «Милстоун N» ссылаются 85 мест в
`docs/**`, включая архив решений; перенумерация сломала бы их все и породила
ровно тот класс гниения, против которого заведена проверка ссылок в public
eval. Милстоун 4 поэтому не переезжает, а **делится на ядро и глубину**, и
переставляется ядро.

**Основание — замер, а не предпочтение** (организатор, 2026-08-09; 20 файлов
`.agent/runs/**/llm.jsonl`, 480 записей ходов). Режиссёр за все прогоны
произнёс **12 глаголов алфавита из 22**. Пять дают 93% всего: `research_shift`
803, `diplomacy` 729, `spawn_incident` 491, `repress` 254, `production_shift`
215. Не встретились НИ РАЗУ:

```text
war  peace  sanction  guarantee  support_proxy
annex  puppet  split_country  merge_countries  create_country
```

Это целиком конфликтный и территориальный слой. Роадмап называл главным
блокером Милстоуна 1 детализацию алфавита — замер говорит, что блокер не в
проектировании этих десяти, а в том, что **им не на что действовать**.

Оговорка, которая держится честно: «не использован» может значить «ситуация не
возникла» — прогоны шли за СССР и США в холодной войне. Прямое доказательство
рядом: `build_extraction` встретился 8 раз и **применён 0 раз** — модель его
произносит, движок отвергает; он заперт данными
(`fill_region_economy_1946.py`, потолок 10/10 у всех пар), то есть недостижим,
а не бесполезен.

**Замер воспроизведён независимо доменом `logic`** (2026-08-09): те же 20
файлов, 480 записей, 0 нечитаемых строк, те же 12 глаголов и те же десять
отсутствующих; пятёрка даёт 93,8% (2483 из 2648 применений). Домен снял три
объяснения-конкурента, чтобы вывод не стоял на непроверенном: граница
агентности ни при чём (`splitByAgency` отказывает только при
`source === player`, а `diplomacy` и `repress` того же класса звучат сотнями
раз); контракт глаголы не прячет (все десять описаны, `war` упомянут 13 раз —
чаще любого другого); конкуренция за структурный слот не объясняет (слот занят
98 ходов из 480 и всегда `enact_reform`, то есть в 80% ходов был свободен).

Для `annex` «нечему действовать» — не вывод, а код: `PrimitiveEngine.ts`
требует непустой `heldRegionsOf(source, target)`, а оккупация возникает только
войной. Ноль войн ⇒ `annex` структурно невозможен. То же у `puppet`.

### Контрольный случай, который в эту схему НЕ ложится — `guarantee`

Найден доменом `logic` при перепроверке. Механика полная
(`PrimitiveEngine.ts`, `DiplomacyService.addGuarantee`), контракт описывает её
отдельным абзацем с последствием, **войны не требует, торговли не требует**,
слот делит с `diplomacy` только по конкретной упорядоченной паре — при 157
странах пар достаточно. И **ноль за 480 ходов**.

Значит «не произнёс» ≠ «нечему действовать» **хотя бы однажды**, и та же
причина может душить часть остальных девяти. Пока это не выяснено, критерий
«шесть глаголов достижимы в прогоне» может оказаться недостижимым по причине,
которую М4-ядро НЕ лечит. Проверка промтовая и дешёвая, ведёт её домен `logic`
фоном между заданиями милстоуна, с замером на живой модели.

Вывод о переносе войны в ядро это не отменяет — `annex` и `puppet` заблокированы
структурно, доказано кодом, — но сужает обещание: ядро гарантирует достижимость
шести глаголов только если `guarantee` не вскроет вторую причину.

**Чем разблокируется каждый из десяти** — три разные причины, а не одна:

| Глаголы | Что нужно | Где |
|---|---|---|
| `war`, `peace`, `annex`, `puppet`, `guarantee`, `support_proxy` | война, которую завершает движок, и её исходы | **М4-ядро** |
| `split_country`, `merge_countries`, `create_country` | машинерия ЕСТЬ (lifecycle М1, тесты зелёные) — нет ПРИЧИН: переворотов и распада | М2 |
| `sanction` | торговля должна жать | М3 |

**Почему переезжает ядро, а не весь Милстоун 4.** Море переехать не могло
физически: морской смежности не было в состоянии партии. **Эта причина снята
2026-08-20** (T-12 домена `geometry`, контракт К-6): экспорт сделан —
1174 связи суша↔вода, 395 рёбер вода↔вода, берег записан у всех 133 регионов
без сухопутных соседей, регионов вообще без связей ноль. **Блокер сместился с
данных на решение:** `adjacentWaterIds` не читает ни один потребитель, а
`isCoastalRegion()` в `generateMapFeatures.ts:113` — литеральный `return false`,
поэтому порты не генерируются и десанту некуда идти. Техника зависит от
производства, то есть от М3.
Ядерное — надстройка над войной. Достижимость шести глаголов даёт только
пара «юниты с реальной силой» + «движковое завершение войн».

> **Генерация без прогона через валидатор и выборочной сверки с источником не

> `scripts/map/validate_demographics_1946.py`.

не лицензированный датасет**. Это чище для публикации, чем импорт чужой базы:

Их `regions.pmtiles` (~105.8 МБ), `countries.pmtiles` (~62.7 МБ) и
seed-geojson построены на **GADM**: источник назван их же документацией
(`docs/assets-and-data.md:13` — «GADM level-1 borders») и подтверждается кодом
(`GID_0`/`GID_1` в `scripts/build-default-map.mjs`, `scripts/extract-regions.mjs`,
`src/Editor/exportPreset.js`; в `server/ownerMigration.js` GADM назван словами в
шапке файла, токена `GID_*` там нет). У GADM условия академические/
некоммерческие, редистрибуция без отдельного разрешения запрещена, а заявления
о полученном разрешении в их репозитории нет — искали, прямого опровержения
тоже нет, поэтому по умолчанию считаем, что разрешения нет.

Запрет покрывает тайлы, seed-geojson и любые производные пресеты: «пересобрать
свою геометрию из их файлов» — та же редистрибуция, а не обход. Их датасет
городов (`cities-seed.json` / `cities.pmtiles`) отдельно: провенанс у них не
назван вовсе, поэтому он не рассматривается до установления источника.

**Это не потеря, а аргумент в нашу пользу.** Наш провенанс чище их: 1399
регионов стоят на geoBoundaries (CC-BY 4.0) + Natural Earth (public domain),
обязательства исчерпываются атрибуцией из пункта NOTICE выше, коммерческое
использование не блокировано. Их главный актив нам закрыт, но заменять нам
нечего — своя геометрия уже есть и с более чистым правом.

**Если когда-либо берём их КОД — копирайт-строк ДВЕ, и определяются они
пофайлово.** Лицензия везде MIT, но копирайт разный: корневой `LICENSE` —
«Copyright (c) 2026 the Open-Historia Organization», `src/Editor/LICENSE` —
«Copyright (c) 2026 Nicholas Krol». Их же `src/Editor/LICENSE` ограничивает
вторую строку тремя адресами (`src/Editor/`, `scripts/extract-regions.mjs`,
`server/mapEditorStore.js`) — **и построчные баннеры это опровергают**: строка
`© 2026 Nicholas Krol, MIT (see src/Editor/LICENSE)` встречается в 118 файлах
дерева (без `node_modules/` и вендоренного `fmg/`), из них лишь 5 — внутри
`src/Editor/`; остальные — `src/Game/AI/main.jsx`, `src/Game/AI/gameplay.js`,
`src/runtime/gameState.js`, `server/server.js`, README и другие. Практическое
следствие: атрибуция определяется чтением шапки КОНКРЕТНОГО взятого файла, а не
списком из их LICENSE, и в NOTICE/THIRD_PARTY нужны обе строки. Их
`docs/conventions.md` требует эти построчные баннеры не удалять.

### Реестр источников данных (лицензионный аудит 2026-07-30)

Проверено дословно по страницам правообладателей при исследовании внешних моделей;
полная таблица с цитатами — `.agent/audits/models-research-2026-07-30.md` §3.

**Разрешено** (коммерческое использование + редистрибуция):

| Источник | Лицензия | Зачем нам |
|---|---|---|
| **Clio Infra** (депозит IISH Dataverse) | **CC0 1.0** | Единственный проверенный источник с РЕАЛЬНЫМ 1946: годовая добыча по 12 ресурсам, 44–108 стран на ресурс. Население — только декады (1940/1950) |
| **HYDE 3.2** (DANS) | **CC0 1.0** | Гридд населения + субнациональные коды для региональных весов. Шаг 10 лет |
| Natural Earth | public domain | Геометрия; точка на страну — `LABEL_X`/`LABEL_Y` в слое стран |
| Wikidata | CC0 | Координаты, исторические государства с датами |
| CEPII (GeoDist, Gravity) | Etalab Open Licence 2.0 | Расстояния, колониальные связи; покрывает и sui generis право на БД |
| Maddison Project 2023 | CC BY 4.0 | Исторические ВВП/чел |
| Gapminder | CC BY 4.0 | Фертильность, продолжительность жизни; коммерческое разрешено явно |
| HMD — **сами таблицы смертности** | CC BY 4.0 | Переобучение коэффициентов модели смертности |
| Federico-Tena World Trade | CC BY 4.0 | Торговля 1800–1938 по историческим политиям |
| BEA / BLS / Census напрямую | public domain | Обход ограничений FRED |

**Запрещено — и две ловушки, срабатывающие тихо:**

- **Correlates of War** (NMC, MID, Trade) — двойной запрет: «not to be used for any
  commercial activity» И «not to distribute the dataset to any third party».
  ⚠️ **Особо опасен именно потому, что по переменным подходит идеально** (военные
  расходы, персонал, энергия, сталь, городское население — готовый индекс мощи).
  Риск в том, что за ним потянутся, не открыв условия.
- **`world-countries` (npm) и REST Countries** — ODbL с share-alike, причём поле
  `license` в `package.json` **отсутствует вовсе**, поэтому автоматические сканеры
  лицензий его пропускают. Тот же класс, что GADM.
- Также нельзя: Jordà-Schularick-Taylor (NC+SA), Conference Board TED (запрет
  включает `databasing`), Mitchell IHS (subscription content), Barro-Lee (all rights
  reserved; копия на Mendeley залита третьим лицом и прав не создаёт), Polity5 и
  данные Center for Systemic Peace, FRED для bulk-редистрибуции, **HMD Input Data**
  (в отличие от таблиц), HYDE **3.3** (конфликт NC-SA против CC BY внутри архива),
  Mark Harrison / Economics of WWII (лицензии нет вообще).
- UNKNOWN, требуют письма правообладателю: UN (UNdata и общие условия un.org прямо
  противоречат друг другу), IMF, V-Dem, EPR/GeoEPR, ATOP, COW Trade.

**Два следствия, важные для планирования:**

1. **Свободно лицензированного субнационального экономического датасета на 1946 не
   существует** — ни один из проверенных не заходит раньше 1953, гриддовые идут
   десятилетиями. Значит наш путь для 1399 регионов единственно возможный и
   лицензионно чистый: национальный агрегат (Clio Infra, CC0) × региональный вес
   (HYDE 3.2, CC0) = собственная производная работа.
2. **Формулы лицензий не требуют** — это математические описания в литературе.
   Блокируются только готовые ДАТАСЕТЫ. Там, где нужны коэффициенты под несвободной
   лицензией (модель смертности), путь — переобучить их самим на CC BY 4.0 данных
   MIT-кодом: результат становится нашим произведением.
