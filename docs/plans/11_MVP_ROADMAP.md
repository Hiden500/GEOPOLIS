# 11 — Дорожная карта: от вертикального среза к v1

Приоритет: P0 (мета-план — порядок реализации редизайна).
Статус: **переписан под редизайн-цикл (2026-07-24)**. Заменяет прежний MVP-roadmap
(2026-07-11, «разморозка UI + починка существующего») — тот подход относился к
до-редизайнному видению. Здесь — порядок реализации концепта.
Источники: [`../CONCEPT.md`](../CONCEPT.md) (продуктовые решения) + ledger дизайн-цикла
(`../../.agent/plans/design-partner-audit.md`).

> Продуктовые решения приняты в концепте. Здесь — **последовательность** их реализации,
> зависимости, накопленный data-долг и гейт релиза. Оценки объёма грубые (S / M / L) и
> уточняются при реализации.

## Принципы дорожной карты

1. **Одна вертикаль вглубь, потом вширь.** Первый милстоун — вертикальный срез (§9 концепта),
   а не «все системы понемногу»: он бьёт в самое рискованное — валидатор примитивов.
2. **Ключевые зависимости** (нарушишь порядок — упрёшься):
   - **Детали алфавита примитивов + контракт валидатора = отдельная дизайн-сессия.** Блокер
     полного алфавита; срез обходится мини-набором ~5 примитивов.
   - **Демо-состав регионов = фундамент** под всю схему влияния (недовольство / сепаратизм /
     сферы) — до политики и распада.
   - **Телеметрия токенов — до бюджетов** (нельзя бюджетировать вслепую).
   - **Лицензии — гейт релиза** (не разработки): строим свободно, публикацию блокируем до зелёного.
3. **Оживить, а не построить с нуля.** Сквозной цикл уже собран (ниже); многое из состояния
   существует мёртвым кодом. Редизайн чаще «оживляет + добавляет алфавит», чем пишет заново.
4. **Инженерные контракты (§7 концепта) — сквозные.** State machine, атомарный pipeline,
   разделённые сущности, бюджеты — не отдельная фаза, а требование к каждому милстоуну, который
   трогает состояние.
5. **UI заморожен.** Дорожная карта — про движок / данные / симуляцию. Карта-как-ввод-приказов и
   панели — отдельный UI-трек (post-заморозка), здесь не планируются.

## Что уже есть (переиспользуется; проверено по коду в аудите Фазы 0)

Сквозной цикл собран целиком — фундамент, не заготовка:

- **Старт → ход → сейв:** выбор сценария/страны/языка → `POST /game/start`; `POST /game/next-turn`
  → полная симуляция (13 детерминированных тиков); autosave после хода.
- **LLM-цикл:** ручной (copy-paste) + авто (Gemini); Zod-контракт + капы + гейт хода.
- **Рычаги игрока:** бюджет, исследования-доли, свободнотекстовое намерение.
- **Состояние:** один GameState (plain data), сейв JSON, seeded RNG, летопись.
- **Мёртвое, но готовое к оживлению:** сектор `industry` региона, `developSectors`/
  `investInSector`, `economyType`, поля техники — существуют, тиками не читаются (§5.1/§5.2 концепта).

Редизайн опирается на это: добавляет алфавит примитивов + богатое состояние (демо-состав,
идеология-координаты) + оживляет мёртвое. Ветка цикла не влита в main; интеграцию инициирует
пользователь.

## Милстоун 0 — Вертикальный срез (валидатор примитивов)

Цель: доказать ядро (§9 концепта) — LLM-режиссура через алфавит примитивов под движковым
валидатором работает на нетривиальной предпосылке. **Одна полная вертикаль**, играбельная, узкая.

Сценарий: внутренний политический кризис в нацрегионе СССР (игрок за СССР); только цикл
недовольства, без отделения/рождения государств.

**Содержание:**

| Задача | Объём |
|---|---|
| Мини-демо-состав: СССР + 1–2 нацрегиона (Прибалтика/Украина), вручную (не полный 1366) | data (мини) |
| Идеология-координаты СССР + групп, вручную (мини) | data (мини) |
| Расчёт недовольства = геометрическая дистанция (§4.2) + экономика | S/M |
| Детекция порога → факт «кризис в регионе X» | S |
| Мини-алфавит ~5 примитивов: `разжечь_недовольство` / `подавить` / `уступить` / `реформа` / `создать_событие` | M |
| Валидатор предпосылок примитивов + атомарное применение (зачаток контракта §7.2) | M/L |
| Путь игрок → примитив (намерение → валидные примитивы) | M |
| Отклик: хроника + история места (§5.6) + объект на карте | S/M |

**Петля:** тики растят недовольство → порог → LLM режиссирует из примитивов (движок валидирует
предпосылку) → игрок решает примитивом → движок детерминированно применяет (подавил ↓кратко /
уступил ↓+осмелели другие / реформа медленный сдвиг) → новое состояние → новое давление.

**Доказывает:** валидатор работает на демо-дистанции, а не на голом числе — «новое сердце
сложности».
**Вне среза:** война, море, дипломатия, глубокое производство, полный демо-состав, полный алфавит,
красивый UI, отделение-lifecycle.
**Почему первым:** использует МИНИ-версии демо-состава и алфавита — реализуем ДО отдельной сессии
по полному алфавиту, но уже сквозь весь стек.

## Милстоуны 1–6 — от среза к v1

Порядок — рекомендация синтеза по зависимостям; непересекающиеся задачи внутри милстоуна
параллелизуемы, но зависимости между милстоунами обязательны. Инженерные контракты §7 концепта —
сквозные (каждый милстоун, трогающий состояние, соблюдает атомарность и lifecycle).

### Милстоун 1 — Ядро надёжности + полный алфавит

Цель: превратить мини-механику среза в полноценное ядро.

- **Детализация алфавита примитивов + контракт валидатора** — **отдельная дизайн-сессия**
  (главный блокер; §2 концепта). — L
- Атомарный command-pipeline (§7.2): plan → валидация на клоне → пост-инварианты → commit;
  idempotency-key; нарратив только после commit. — L
- Агентность: `player_proposed` (LLM за игрока — предложением) + approval необратимого. — M
- State machine кампании + `PolityLifecycleResult` (§7.1): `campaignStatus`, перенос всех ссылок,
  property-тесты сумм/id/висячих ссылок. — L
- **Телеметрия токенов** (usageMetadata → JSONL + перцентили) — до бюджетов. — S

**Зависит от:** Милстоун 0 + отдельной сессии по алфавиту.

### Милстоун 2 — Политика + демо-состав (фундамент вширь)

Цель: расширить срез до полной политической системы на всём мире.

- **Полный демо-состав ~1366 регионов** (data-задача; этно-конфессиональный источник и лицензия —
  открытый риск). — L(data)
- Идеология-координаты ~128 стран (data-задача). — M(data)
- Полный набор политических примитивов (§5.2). — M
- Перевороты / распад / рождение государств (§5.5) на lifecycle из М1. — L
- Оживить `economyType` (плановая/смешанная/рыночная) + реформы. — M

**Зависит от:** демо-состав (фундамент под всю схему влияния), lifecycle (М1).

### Милстоун 3 — Экономика + производство

- Калибровка: рецессия (ВВП умеет падать), инфляция с границами, логистический рост населения +
  **guard-тесты 50 лет** в CI (закрыть тест-слепоту). — M/L
- Регион-пул мощности (оживить `industry`-сектор, `developSectors`/`investInSector`). — M
- Гейт-сырьё: ресурсы **потребляются** (нет ресурса → слот не производится). — M
- Долговая цепочка: долг/инфляция/безработица → стабильность↓ + дефолт-кризис (гистерезис). — M

**Зависит от:** политика (долг → нестабильность стыкуется с §5.2).

### Милстоун 4 — Война + море + техника + ядерное

- Юниты дают реальную силу (не декорация) + combined-arms + барьеры на границах (реки NE) +
  сидированная ±25%. — L
- Движковое завершение войн (капитуляция при разгроме + белый мир по истощению). — M
- Море: морской граф + зоны (data) + флот-проекция + десант-гейт + бой флот-vs-флот. — L
- Техника: 16 слотов + 3 оси (capability/readiness/doctrine) + платная модернизация (§7.3). — L
- Ядерное MVP-MAD: программа → триада → сдерживание → прокси → табу. — M/L

**Зависит от:** производство (техника = мощность + сырьё), lifecycle (капитуляция → game over).

### Милстоун 5 — Дипломатия + блоки + ИИ + проекты

- Единая модель блоков (сфера/военсоюз/эконоблок/валютзона/ООН) + слои карты + прокси-война +
  ООН-вето + права сферы (§5.4). — L
- Стартовая дипломатия (data-задача; сейчас пусто — F59). — M(data)
- Пять тиров + разгрузка на оси (§7.3) + макрорегионы (продуктовые правила + data) + региональные
  лидеры. — M/L
- ИИ-державы: utility-функция целей + balance of power + сложность (§5.8). — L
- Система проектов + гонки вех (§5.7: проекты = отложенные примитивы). — M/L

**Зависит от:** демо-состав (сферы), война (прокси/коалиции), техника (ядерное сдерживание → прокси).

### Милстоун 6 — Советник + цели

- Советник-LLM (отдельный вызов; дешёвая/локальная модель; per-роль модели). — M
- Цели: approval-цикл, raw + структурирование, готовые пороги, decision-log с капом. — M
- Разделение целей (PlayerObjective / AiPolicyGoal / AdvisorGoalView, §7.3). — M
- Приватность-guard (нет сетевых вызовов кроме LLMProvider) + санитайзер промта. — S/M

**Зависит от:** цели ИИ (М5); агрегаты всех систем как вход советнику.

### Post-v1 (после релиза)

Автопилот (§5.9), разведка/шпионаж, дипломатия-переговоры, эпохи 1836 и 2000, миграция/беженцы,
детальные фракции/выборы, товары/уровень жизни, точечные фича-цели. См. §8 концепта.

## Критерии приёмки v1

- [ ] Вертикальный срез (М0): кризис недовольства → примитив игрока → детерминированное
      последствие → петля — работает сквозь весь стек.

      (property-тесты зелёные).

- [ ] Экономика с последствиями (рецессия/инфляция/логистическое население); guard-тесты 50 лет
      зелёные без замалчивания порогов (М3).
- [ ] Война завершается движком; море (достижимость островов + десант); техника-слоты; ядерное
      MAD (М4).
- [ ] Единая модель блоков + ИИ с целями и balance of power + проекты/гонки вех (М5).
- [ ] Советник советует под цели игрока, спорит, различает факт/оценку (М6).
- [ ] Бюджеты соблюдены: SAVE < ~3–5 МБ, PROMPT < ~8–10k токенов, телеметрия токенов есть.
- [ ] Лицензии зелёные (гейт релиза).
- [ ] Полная верификация зелёная (tsc + vitest server/client + guard-тесты + Python-валидаторы),
      докфутпринт по каждому милстоуну.
