## Волна 2 — ядро философии «LLM не угождает игроку»

### 2.1 Кризисные генераторы (не-LLM события)
Давление должно идти извне модели: детерминированные генераторы — бизнес-цикл
(рецессия раз в ~8–12 лет по seeded RNG), неурожаи, пандемии, стихийные
бедствия. Движок бросает кризис как обязательный мировой факт (механизм
pendingWorldFacts, план 02) + модификаторы; LLM обязана отыграть. Главный
инструмент против «модель всех мирит и всё прощает».

### 2.2 Внутренняя политика: революции, гражданские войны, сепаратизм
stability/legitimacy сейчас — счётчики без развязки. Детект движком
(«stability < порога N месяцев» → факт) → LLM решает форму (реформы,
переворот, восстание, распад) → исполнение командами. Гражданская война —
главный потребитель `splitCountry` (план 07). Открывает 1848, распады
империй, деколонизацию.

### 2.3 Договоры и международные организации как объекты
Союз сейчас — строчка в `allies`. Нужен объект `Treaty { members, clauses[],
since }` (паттерн War): оборонительный пакт, торговое соглашение, ненападение.
НАТО/Варшавский блок/Лига Наций — договоры с набором clauses. Нарушение —
детерминированный факт с дипломатической ценой.

## Волна 3 — до масштабирования контента

### 3.1 Информация / туман войны — принять решение
Одиночная игра: видит ли игрок точные чужие цифры? Полная прозрачность
обесценивает разведку и сюрпризы; полный fog дорог. Средний путь: точность
видимых данных зависит от отношений/эпохи (LLM видит всё). Решить ДО
UI-инспекторов чужих стран — потом дороже.

### 3.2 Диффузия технологий
157 стран независимо исследуют 14 доменов — Афганистан в вакууме исследует
ядерную физику. Пассивный дрейф домена к уровню мирового лидера ×
открытость (торговля/отношения/санкции режут). Одна формула в ResearchTick;
даёт смысл технологическим эмбарго.

### 3.3 Миграция
1836–2100 — век переселений. Медленный перенос населения в регионы с высоким
development/stability, усиленный войнами (беженцы). Один тик; карта населения
к 1950 становится правдоподобной без ручной подкрутки.

### 3.4 Флот, блокады, проливы
Морские регионы и флот в данных есть, море ни на что не влияет; десантов нет
(задокументированный пробел WarTick). v1 без морских зон: блокада как санкция,
требующая превосходства флота (режет exportIncome — крючок уже в TradeTick);
проливы/каналы — MapFeature с владельцем и модификатором торговли; стройки
Суэца (1869) и Панамы (1914) — hinge points. Морские десанты — минимальная
логика «контакт через океанский регион при превосходстве флота».

### 3.5 Эластичность мировых цен (Trade v2)
Мировое предложение/спрос двигают цену категории (~30 строк в TradeTick).
Эмбарго и ресурсные войны получают реальные зубы.

## Волна 4 — до сценария 2000 и длинных кампаний

### 4.1 ЯО и лестница эскалации
`nuclearWarheads` в данных есть, механики нет. Применение — отдельное действие
с жёсткими движковыми условиями (война + доктрина/отчаяние), последствия
детерминированы (разрушение регионов через damageExtraction/модификаторы,
мировая реакция, MAD-ответ). Сдерживание = модификаторы дипломатии. Точка,
где «числа у движка» важнее всего: LLM не решает буднично.

### 4.2 Числовая стабильность на 264 годах
3168 месячных тиков сложного роста: ВВП ×~2000 за кампанию, баланс констант
калиброван на 1946–1960 и развалится к 2050; inflation копится и ни на что
не влияет. Варианты: периодическая ренормализация («деноминация» всех денежных
величин), либо переход расчётов на per-capita/относительные величины.
Обсудить до Trade v2.

### 4.3 Автоматизация игрока
264 года × ручной бюджет = усталость к 1880. Дёшево: `spendingShares` и
`researchAllocation` уже существуют — «автопилот» = их включение для игрока.

### 4.4 Поздние эпохи как «престиж-гонки», не подсистемы
Космос = проекты в `technology.projects` (поле есть и пустует) с вехами-фактами;
климат = медленный глобальный модификатор на food/stability с 2000+;
кибер = вид санкций/операций. Всё ложится в существующие примитивы.

### 4.5 Наследие / итог кампании
Песочнице нужно зеркало, не win-экран: летопись (план 02), графики держав по
декадам, «очки наследия», экспорт летописи кампании в файл — самый шароёмкий
артефакт LLM-игры, почти бесплатный.

### 4.6 Лидеры (лайт)
Лидер = 3 строки текста (имя, характер, повестка) в состоянии страны,
генерируется LLM, влияет на нарратив + 1–2 модификатора. НЕ система
персонажей уровня CK.

## Сознательно НЕ делать

| Механика | Почему нет |
|---|---|
| POP-система Victoria (классы/культуры/религии по регионам) | чёрная дыра объёма; LLM даёт колорит дешевле |
| Персонажи уровня Crusader Kings | лидер-лайт (4.6) покрывает ценность |
| Производственные цепочки (руда→сталь→танк) | каталог «только сырьё» верен; переделы = абстрактная промышленность |
| Гексы/тактические бои, погода, поклеточное снабжение | не тот жанр: бой решается фронтами и договорами |
| Вложенные провинции внутри регионов | решено в плане 07: эпохи карты + ярусы акторов |
| Мультиплеер | одиночная игра по замыслу; не закладываться |

## Сквозные напоминания

- Каждая механика = команды + модификаторы + defines (план 03), а не новые
  прямые мутации в тиках.
- Каждая механика обязана давать LLM либо факт (pendingWorldFacts), либо
  действие с капами — иначе она невидима для нарратива.
- Числа — стартовые ориентиры; калибровка на кампаниях-смоках
  (`campaignSmoke.test.ts` — расширять сценариями на десятилетия).
