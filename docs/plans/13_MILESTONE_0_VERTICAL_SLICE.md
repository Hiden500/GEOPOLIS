## Цель среза

Доказать **ядро** редизайна на одном кризисе через полный стек: LLM-режиссура из примитивов под
**движковым валидатором** работает на нетривиальной предпосылке (демо-дистанция «власть ↔ группа»,
а не голое число). Это самое рискованное место дизайна (§2 «новое сердце сложности»), поэтому срез
бьёт в него, а не в войну.

**Одна полная вертикаль, играбельная, узкая.** НЕ «все системы понемногу».

## Сценарий

Внутренний политический кризис в национальном регионе СССР, игрок за СССР. Глубина — **только цикл
недовольства** (без отделения/рождения государства — lifecycle-контракт §7.1 в срез НЕ тянем).

## Что доопределить ПЕРВЫМ (оставлено на реализацию — тестовый v0)

Дизайн намеренно не детерминирует эти числа; определить в начале разработки (мои стартовые
кандидаты — плейсхолдеры, калибровка на симуляции):

1. **Регион и демо-состав** (вручную, 1–2 региона):
   - Кандидат: **Литовская ССР** (`SUN_LT` или реальный id из `regions.core.json`) — литовцы ~80 %
     (доминант), русские/поляки — меньшинства. Исторический якорь: «лесные братья» 1944–53.
   - Опц. второй: Западная Украина (украинцы/поляки) — для проверки «соседи осмелели».
2. **Идеология-координаты** (§4.2, две оси экономическая × политическая):
   - СССР — крайне лево + авторитаризм.
   - Группа «литовцы» — «желаемая» позиция ближе к центру/национализму → **большая дистанция** →
     высокое недовольство.
3. **Формула недовольства** (§4.2 геометрия): `discontent(регион) = f(идеол_дистанция «власть↔группа»,
   благосостояние региона, история репрессий/уступок)`. Стартовый вид:
   `base + k1·distance + k2·(1 − welfare) − эффекты_примитивов`; `k1/k2/base/порог` — плейсхолдеры.
4. **Предпосылки ~5 примитивов** (численно): порог дистанции для `incite_unrest`; порог discontent
   для `spawn_incident`; требование контроля региона для `repress`/`grant_autonomy`; политическая
   цена для `enact_reform`.
5. **`incite_unrest` vs `stoke_discontent`** — выбрать по фактическому имени переменной состояния.

## Петля (реализовать)

1. Тики живут; движок растит `discontent` региона от демо-дистанции (§4.2) + экономики.
2. Порог → факт «кризис в регионе X» (механизм `pendingWorldFacts`).
3. LLM режиссирует событие из примитивов (`incite_unrest` + `spawn_incident` + нарратив); движок
   **валидирует предпосылку** (§3 PRIMITIVES: validate → compute → apply; reject целиком).
4. Игрок решает примитивом: `repress` / `grant_autonomy` / `enact_reform` (через текст → перевод, с
   показом распознанного, или кнопкой — гибрид-интерфейс §PRIMITIVES.1).
5. Движок детерминированно: `repress` → discontent ↓ кратко, отчуждение/дистанция ↑; `grant_autonomy`
   → ↓, но соседние группы осмелели; `enact_reform` → медленный сдвиг координат. → новое состояние →
   новое давление (петля). Отклик: хроника + история места (§5.6) + объект на карте.

## Переиспользовать (не строить с нуля)

Тики (`simulateMonth`), `PoliticsState`, `pendingWorldFacts`, `chronicle`, LLM-цикл (промт/ответ/гейт),
`MapFeatureService` CRUD. Многое в состоянии уже есть мёртвым кодом (§5.1/§5.2 концепта).

## Инженерные контракты (соблюдать с самого начала)

- **§7.2 атомарный pipeline (зачаток):** примитив = validate → compute на клоне → apply; нарратив
  пишется ТОЛЬКО после успешного применения; reject → диагностический факт (не ложный канон);
  idempotency на ход.
- **Агентность (§7):** LLM за игрока — предложением; игрок подтверждает (гибрид-интерфейс).
- **§7.1 lifecycle — НЕ в срезе** (отделение/распад не реализуем; страна не создаётся/не делится).
- **Числа — движок:** LLM даёт качественные params, движок считает magnitude (PRIMITIVES §1/§3).

## Вне среза (осознанно)

Война, море, дипломатия, глубокое производство, полный демо-состав (1366), полный алфавит (~18),
красивый UI, отделение-lifecycle, советник, проекты. Это последующие милстоуны (план 11).

## Критерии готовности

- [ ] Тики растят недовольство нацрегиона от демо-дистанции + экономики; guard-тест: разные
      координаты → разное недовольство.
- [ ] Порог → `pendingWorldFact` «кризис в регионе X» срабатывает детерминированно.
- [ ] LLM-ответ с примитивами проходит валидатор: валидные применяются, невалидные → reject целиком
      + диагностический факт; нарратив только после commit.
- [ ] Игрок отвечает примитивом (текст→перевод с подтверждением ИЛИ кнопка); три ответа
      (`repress`/`grant_autonomy`/`enact_reform`) ведут в **различимо разное** состояние
      (property-тест §5-риск-2: ветки не схлопываются).
- [ ] Петля замыкается: новое состояние → новое давление; отклик виден (хроника + история места +
      объект карты).
- [ ] Числа — только движок (LLM не задаёт magnitude); проверить по коду валидатора.
- [ ] Верификация зелёная по затронутому scope (server tsc + vitest; при UI-касании — client), без
      маскировки предсуществующих failure.
