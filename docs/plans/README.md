# Планы по итогам независимого аудита (2026-07-10)

Источник: сессия независимого архитектурного аудита (Senior Game Architect роль,
без опоры на внутренние соглашения). Каждый файл самодостаточен: содержит
контекст, текущее состояние со ссылками на код, целевую модель, шаги и
критерии приёмки — рассчитан на реализацию в отдельной холодной сессии.

## Главный вердикт аудита

**Стек (TypeScript / Node / Express / React / MapLibre) менять НЕ нужно.**
Игра пошаговая, тик месячный, 1366 регионов × 128 стран — это единицы
миллисекунд на тик; узкое место хода — вызов LLM, не язык. Любая миграция
на Unity/Godot/Rust — выброшенные 6–12 месяцев. Все проблемы — архитектурные
и чинятся рефакторингом.

## Зависимости между планами

```
01 (сохранения/гигиена) ──► всё остальное (базовая гигиена состояния)
03 (команды/модификаторы) ──► 04 (ресурсы), 06 (фичи), 08 (война)
05 (данные) ──► 07 (сценарий 1836)
02 (LLM) — независим, можно параллельно с 03
```

Порядок реализации: **01 → 02 → 03 → 08 → 04/05/06 (в любом порядке) → 07**.
Бэклог 09 разбирается по волнам после этого.

## Правила работы с этими планами

- При реализации плана: обновить статус в таблице выше, зафиксировать
  отклонения от плана прямо в файле плана (раздел «Отклонения при реализации»).
- Реализованные механики мигрируют в системные доки (`docs/*.md`) —
  файл плана после этого помечается «реализовано, см. docs/X.md».
- Все числовые константы в планах — стартовые ориентиры для баланса, не истина.
