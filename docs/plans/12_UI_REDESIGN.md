## 1. Замороженный эталон

Визуальный эталон HUD 1946 — мокап, утверждённый пользователем 2026-07-12
(артефакт «Geopolis · 1946 v6»; статичная копия HTML — приложить в репо как
`docs/plans/assets/1946-hud-reference.html` при старте среза 2, если ещё не
приложена). Любой отход от эталона по компоновке — согласовывать, не
самовольно.

Ключевые решения эталона:
- **Карта-центрик:** карта — постоянный холст; HUD по краям.
- **Шапка из залитых блоков + прозрачные промежутки:** левый блок (флаг встык
  на 2 ряда статов + статы 2 ряда) → вкладки отдельной панелью под ним (по
  ширине контента, до 9-й кнопки) → прозрачный промежуток → бейдж состояния
  хода → правый блок (дата + «Следующий ход», под ним прозрачные техкнопки).
- **Выдвижная панель слева** — основной способ показать раздел («книгу»);
  вкладки всегда кликабельны, переключение не закрывает панель.
- **Полноэкранные режимы — только там, где не влезает в панель:** дерево
  технологий, широкие леджеры, переговоры о мире.
- **Контекст-панель справа** — только при выделении региона/страны (не висит).
- **Плавающие окна** — только «сравнить два объекта рядом».
- **Уведомления** — колокольчик с бейджем → выдвижной леджер справа; критические
  тревоги мигают на колокольчике.
- **Окно приказов** (свободный текст намерения игрока для LLM) — левый нижний
  угол, сворачивается.
- **mapmodes + зум** — правый нижний угол; легенда в одном стеке над кнопками.

## 2. Список «НЕ возвращать» (проверять каждый срез)

Явно удалено/решено — не реинтродуцировать:
- ❌ Контролы паузы/скорости времени (тиков реального времени нет).
- ❌ Подписи у статов в шапке (только иконка + число + tooltip); понятность
  обеспечивает слой онбординга, не подписи.
- ❌ Текст «Атомный век» в шапке (не несёт нагрузки).
- ❌ Пустые залитые панели: у каждого залитого фона — содержание; промежутки
  прозрачные.
- ❌ Выведение copy-paste LLM-цикла на первый план как основного экрана.
- ❌ Хардкод локали в форматировании чисел (`toLocaleString("ru-RU")`,
  `InspectorPanel.tsx`/`BudgetPanel.tsx`) — формат через активную локаль
  i18n (чинит находку аудита №2).
- ❌ Схлопывание нескольких однотипных окон в одну позицию
  (`useWindows.ts` `getSettingsKey` по категории — чинит находку №3).
- ❌ Сырой `err.message` игроку (находка №13) — понятные сообщения.

## 3. Дизайн-токены (тема 1946) и архитектура тем

Токены-как-код (CSS custom properties), **не хардкод по компонентам**. Значения
темы 1946 «радарная ситуационная комната»:

| Токен | Значение | Роль |
|---|---|---|
| `--ink` / `--ink-2` | `#0e1311` / `#121815` | фон-канва (сине-зелёный графит) |
| `--steel` / `--steel-2` / `--steel-3` | `#182019` / `#1f2a22` / `#263329` | панели, hover, приподнятое |
| `--hairline` / `--hairline-2` | `#2c3a30` / `#3a4b3d` | границы |
| `--paper` / `--paper-dim` / `--paper-faint` | `#e8e4d4` / `#9ba08c` / `#6b7161` | текст, вторичный, третичный |
| `--accent` / `--accent-2` / `--accent-dim` | `#e6a338` / `#f6bf5e` / `#8a6a2a` | фосфорный янтарь радара (интерактив/активное) |
| `--accent-tint` | `rgba(230,163,56,.13)` | фон выделенного |
| `--ok` / `--warn` / `--crit` | `#7aa653` / `#c9762a` / `#cf4436` | семантика (радар-зелёный / оранж / сигнал) |

Типографика: display — индустриальный condensed гротеск эпохи (в мокапе
`Bahnschrift`/`Franklin Gothic Condensed` как системная заглушка; в реальной
сборке — **self-hosted `@font-face` data-URI**, НЕ CDN; целевое начертание —
condensed industrial); данные — моно с `tabular-nums`; тело — гуманистический
гротеск. Геометрия: острые углы (2px), плотная компоновка.

**Архитектура тем:** один набор компонентов + набор токенов на эпоху.
Токены 1946 живут под селектором темы (напр. `:root[data-era="1946"]`), чтобы
1836/2000 добавлялись как альтернативные наборы токенов + ассеты (иконки от
Nano Banana в стиле эпохи) без переписывания компонентов. Реализуем только
1946; но не хардкодить значения так, чтобы вторую тему нельзя было подключить.

- **Статус (2026-07-13): реализовано.** Токены — `client/src/styles/tokens-1946.css`
  (`:root[data-era="1946"]`, `data-era` статично на `<html>` в `index.html` —
  единственная реализованная эпоха, переключатель не нужен сейчас); шрифты —
  Oswald (display) + IBM Plex Sans (body) + IBM Plex Mono (data), self-hosted
  `client/public/fonts/*.woff2` (latin+cyrillic), Google Fonts `<link>` убран.
  **Отклонение:** self-hosted реализован как локальные файлы через `url()`
  (тот же паттерн, что уже был у `EBGaramond-Bold.ttf`), не как base64
  data-URI, как буквально написано в §3 — data-URI не даёт практического
  выигрыша против CDN (тот же принцип «без внешней сети»), а раздувает CSS;
  локальный файл проще кэшируется браузером отдельно от CSS. Дефолтный старый
  App.css (`--font-display: "Big Shoulders..."` и т.п.) пока не тронут —
  миграция по срезам 1-3, как и планировалось в §6.

### Срез 1 — Примитивы · effort: `high`
- Переиспользуемые компоненты вместо ad-hoc классов (`.stat-pill`,
  `.resource-chip`, `.timeline-tag` → единые): `Stat`, `Chip`, `Button`,
  `IconButton`, `Panel`, `Meter`, `Tag`, `Legend`. CSS Modules, не глобальный
  `App.css`.
- **Приёмка:** каждый примитив покрыт состояниями (hover/active/disabled/focus,
  видимый `:focus-visible`); каталог примитивов (простая страница-витрина).
- **Статус (2026-07-13): реализовано.** `client/src/primitives/{Button,IconButton,
  Stat,Chip,Panel,Meter,Tag,Legend}/` — каждый CSS Modules + `.tsx`, на токенах
  `client/src/styles/tokens-1946.css` (Срез 0). Витрина —
  `client/src/dev/PrimitivesShowcase.tsx`, открывается `?showcase=primitives`
  (main.tsx), вне игрового потока. Точечные тесты поведения (не снапшоты):
  `Button` (клик/disabled/type), `IconButton` (aria-pressed), `Meter`
  (aria-value*/кламп 0-100%), `Stat` (регрессия на правило «не возвращать» §2 —
  подпись только в title/aria, не в видимом тексте). Только `Button`/`IconButton`
  интерактивны — `hover/active/disabled` там; `Stat`/`Chip`/`Tag`/`Legend`/`Panel`
  не интерактивны, states к ним не применимы по дизайну.
  **Компоненты-потребители (TopStatBar/ResourceTicker/...) НЕ мигрированы на
  примитивы** — по плану миграция происходит в Срезах 2-3 при перестройке
  соответствующих экранов (§6), не задним числом здесь.
  **Проверено:** typecheck+lint клиента зелёные (примитивы не добавили новых
  ошибок; 20 предсуществующих — TODO.md P4, не мои), vitest client 91 ✅,
  `:focus-visible` подтверждён визуально через реальную Tab-навигацию в
  браузере (видимый 2px amber outline на Button и IconButton). **Оговорка:**
  `:hover` не удалось подтвердить визуально через синтетический hover
  Browser pane (`matches(':hover')` истинно, но `getComputedStyle` не
  меняется — похоже на особенность инструмента, не браузера) — каскад/
  специфичность/порядок правил проверены напрямую через CSSOM (корректны),
  но живой визуальный QA hover остался неполным, стоит перепроверить в
  реальном браузере в начале Среза 2.
- **Отклонение:** `Legend` без живого потребителя (реализован по описанию §1,
  «легенда в одном стеке над кнопками» — понадобится Срезу 2 для mapmodes).

## 5. Обязательный визуальный QA на каждый срез (не опция)

1. Рендер + скриншот (при падении инструмента — заглушить анимации и снять
   кадр). **Не сдавать UI, который не видел глазами.**
2. Проверка переполнения/наложений на узком И широком вьюпорте:
   `document.documentElement.scrollWidth > innerWidth`; обойти все 4 угла.
3. Обе локали (ru/en), включая формат чисел.
4. Видимый `:focus-visible` у всех интерактивных элементов.
5. Сверка со списком «не возвращать» (§2).
6. Отдельный проход-критик: «оценить как новый игрок с целью проекта — что не
   так?» перед сдачей.
