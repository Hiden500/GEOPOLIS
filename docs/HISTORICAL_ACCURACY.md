# HISTORICAL_ACCURACY.md

Last updated: 2026-06-21

## Историческая достоверность

По умолчанию мир обязан начинаться с исторически достоверного состояния для выбранной даты старта.

Это относится к:

* государственным границам;
* владельцам территорий;
* населению;
* экономике;
* технологиям;
* ресурсам;
* дипломатическим отношениям;
* военным силам.

---

## Источник истины

Для каждой стартовой даты используется исторический снимок мира.

Примеры:

1836 → историческая карта 1836 года

1914 → историческая карта 1914 года

1936 → историческая карта 1936 года

1946 → историческая карта 1946 года

1991 → историческая карта 1991 года

2000 → историческая карта 2000 года

---

## Государственные границы

Границы стран должны соответствовать выбранному году.

Примеры:

1836:

* существует Османская империя
* существует Австрийская империя
* отсутствует Германия

1946:

* существует СССР
* существует Югославия
* Германия разделена на оккупационные зоны

1991:

* распад СССР
* распад Варшавского договора

---

## Региональная принадлежность

Каждый регион обязан иметь исторического владельца для каждого стартового сценария.

Пример:

Регион: Киев

1836 → Российская империя

1946 → СССР

2000 → Украина

---

## Население

Начальное население должно максимально соответствовать историческим данным выбранного периода.

---

## Экономика

Начальный ВВП, промышленность и ресурсы должны отражать реальное состояние мира выбранного года.

---

## Технологии

Государства начинают игру с технологиями, доступными на выбранную дату.

Запрещено выдавать технологиям уровень выше исторически достигнутого.

---

## Альтернативная история

После начала игры история может отклоняться от реальности.

Историческая достоверность обязательна только для стартового состояния мира.

После старта симуляция развивается самостоятельно.

---

## Приоритет

Если возникает конфликт между:

* игровым удобством;
* исторической достоверностью;

предпочтение отдаётся исторической достоверности для стартового сценария.

---

## Источники по эпохам

Базовый список авторитетных источников — `AGENTS.md` ("Historical Data": UN,
League of Nations, Maddison Project, CIA, академические публикации,
историч. атласы). Ниже — что конкретно использовать для каждого слоя на
каждую стартовую дату. Реальный готовый датасет сейчас есть только для
**1946** (см. `scripts/map/README.md`) — остальное ниже — стандарт сорсинга
на будущее, когда дойдут руки до соответствующего сценария.

### 1836
* Границы/владение: историч. атласы (напр. "The Cambridge Modern History
  Atlas", Euratlas) — до образования Германии/Италии, существование
  Османской/Австрийской империй.
* Население: ранние национальные переписи где есть, иначе — оценки из
  Maddison Project (Maddison Project Database, есть данные с начала XIX в.).
* Экономика: Maddison Project (ВВП на душу по странам с 1820-х).
* Военные: ограниченно надёжных кросс-страновых данных на эту дату нет —
  фиксировать как оценку, явно помечать допущения.

### 1914
* Границы/владение: историч. атласы непосредственно перед ПМВ.
* Население: национальные переписи рубежа веков + Maddison Project.
* Экономика: Maddison Project.
* Военные: Correlates of War (National Material Capabilities dataset) —
  покрывает военные расходы/численность с 1816.

### 1936
* Границы/владение: историч. атласы межвоенного периода (Локарно/Версаль
  ещё в силе, ремилитаризация Рейнланда — март 1936).
* Население: League of Nations Statistical Yearbook.
* Экономика: League of Nations Statistical Yearbook + Maddison Project.
* Военные: Correlates of War.

### 1946 (готовый датасет)
* Границы/владение: geoBoundaries (ADM1) как геометрическая основа +
  историч. шейпы для Китая (см. `scripts/map/README.md`, `sources/`) +
  MAP-датасет (`scripts/map/out/*`, `ownership_1946.json` с полем
  `controller` для зон оккупации).
* Население: UN Demographic Yearbook (первые послевоенные выпуски).
* Экономика: Maddison Project.
* Военные: Correlates of War; для оккупационных зон — национальные военные
  архивы (структура задана `controller`-полем MAP, см. `import_to_game.py`).

### 1991
* Границы/владение: историч. атласы на момент распада СССР/Варшавского
  договора — переходный год, фиксировать конкретную дату снимка явно.
* Население: UN Demographic Yearbook.
* Экономика: Maddison Project + World Bank (данные с 1960-х доступны).
* Военные: Correlates of War (покрывает до 2010-х) + SIPRI (военные расходы).

### 2000
* Границы/владение: современные административные данные (geoBoundaries
  ADM1, актуальные на 2000) — меньше историч. неопределённости.
* Население: UN Demographic Yearbook / World Bank.
* Экономика: World Bank, IMF historical data, Maddison Project.
* Военные: SIPRI Military Expenditure Database, Correlates of War.

### Общее правило сорсинга
Когда надёжного источника нет — документировать оценку явно (откуда взято
допущение, какой диапазон погрешности), не выдавать оценку за проверенные
данные. См. `AGENTS.md` "Historical Data".
