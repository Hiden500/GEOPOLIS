## Как прогнать LLM из дерева

У linked worktree нет своего `server/.env` (он только в главном checkout и вне
git), а модельный прокси сам собой не поднимается. Всё это закрывает
`scripts/llm-run.ps1`: тянет env в переменные процесса (на диск дерева ничего
не пишет, значения не печатает), поднимает `D:\CLIProxy\cli-proxy-api.exe` на
:8317, ждёт появления модели в `/v1/models` и запускает команду из `server/`
ТЕКУЩЕГО дерева — поэтому вызывать надо, находясь в дереве.

- Проверка связи (ничего не занимает, поднимет прокси):
  `pwsh -File "D:/Pax Historia LOCAL/scripts/llm-run.ps1"`
- Сервер игры с живой моделью:
  `... llm-run.ps1" -Run "npm run dev"` — порт 3000 должен быть свободен.

Проверено 2026-08-07: 12 моделей на эндпоинте, `gemini-3.6-flash-high` рабочая.

## Грабли этой сессии

- **Команды пользователю выданы без проверки в ЕГО окружении** — ТРИЖДЫ, это
  устойчивый дефект, а не случайность.
  `git checkout --ours` без `git add` не снимает пометку «не слито»; `sed` с
  кириллическим шаблоном через PowerShell не матчится, а `git show | Out-String`
  ломает UTF-8 в консоли с не-UTF-8 кодовой страницей. Читать текст из git —
  файлом с диска, а не через конвейер оболочки.
  Третий раз (2026-08-07): `pwsh -Command '… "путь с пробелами" …'` я проверил
  в Bash-инструменте (там одинарные кавычки литеральны) и выдал пользователю,
  а кнопка «Run» отдаёт строку в PowerShell — вложенные двойные кавычки при
  передаче в нативный `pwsh` срезаются, и `D:/Pax` ушло отдельным аргументом.
  **Правило:** проверка команды в Bash-инструменте НЕ доказывает её
  работоспособность у пользователя. Надёжная форма — `pwsh -File <путь>`
  с ОДНИМ аргументом, а всё квотирование запереть внутри файла; путь без
  пробелов делает срезание кавычек безвредным.
- **`preview_start` поднимает vite из ОСНОВНОГО checkout, а не из worktree** —
  отдаёт код `main`. Поднимать вручную:
  `cd client && npm run dev -- --port 5181 --strictPort`, затем
  `preview_start {url: "http://localhost:5181/"}`.
- **Замечание пользователя прочитано неверно трижды подряд** (ЛЕНТА → ЛИСТ →
  ПОЛОСА). Прежде чем двигать панель — нарисовать схему и получить «да».
- **Когда причина ограничения исчезла, снимать и само ограничение.** Ограничение
  жило лишний круг после того, как измерение, его породившее, оказалось
