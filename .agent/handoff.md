## Грабли этой сессии

- **Команды пользователю выданы без проверки в ЕГО окружении** — дважды.
  `git checkout --ours` без `git add` не снимает пометку «не слито»; `sed` с
  кириллическим шаблоном через PowerShell не матчится, а `git show | Out-String`
  ломает UTF-8 в консоли с не-UTF-8 кодовой страницей. Читать текст из git —
  файлом с диска, а не через конвейер оболочки.
- **`preview_start` поднимает vite из ОСНОВНОГО checkout, а не из worktree** —
  отдаёт код `main`. Поднимать вручную:
  `cd client && npm run dev -- --port 5181 --strictPort`, затем
  `preview_start {url: "http://localhost:5181/"}`.
- **Замечание пользователя прочитано неверно трижды подряд** (ЛЕНТА → ЛИСТ →
  ПОЛОСА). Прежде чем двигать панель — нарисовать схему и получить «да».
- **Когда причина ограничения исчезла, снимать и само ограничение.** Ограничение
  жило лишний круг после того, как измерение, его породившее, оказалось
  испорченным.
- `/primitives/translate` требует локального LLM-рантайма на `:1234`,
  `/llm/auto` — `GEMINI_API_KEY`. Всё, что идёт через них, в этом окружении
  проверяется только до границы запроса.
- **На порту 5181 уже был живой `vite` этого же worktree** (PID проверен
  через `Get-CimInstance Win32_Process`, командная строка указывала именно на
  `worktrees/ui-port-panels`) — свой `npm run dev -- --port 5181` не поднялся
  (`EADDRINUSE`), браузер подключился к существующему; сервер на :3000 я
  поднял сам, свежий (пустая партия, значит и это не унаследованное
  состояние). Во время ручной проверки МЕНЮ/окна в ТОМ ЖЕ табе Browser pane
  (`tabId: seed`) само собой нажалось «Продолжить» и словило ошибку
  `LLM_PROVIDER=local` — между моими вызовами не было ни одного мутирующего
  (только `read_page`/`get_page_text`). Похоже на другую сессию, разделяющую
  тот же Browser pane или тот же порт 5181. Прежде чем поднимать dev-сервер
  на фиксированном порту в этом дереве — `netstat` + `Get-CimInstance
  Win32_Process` по PID, не считать порт свободным по умолчанию; и держать в
  уме, что Browser pane может быть общим ресурсом.
