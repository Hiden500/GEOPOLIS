## Грабли этой сессии

- **`import_to_game.py` пишет `regions.state.json` ОБНУЛЁННЫМ** — население и
  экономику заполняет более поздний шаг. Прогон экспорта в отрыве от пайплайна
  стирает экономику у 1444 регионов. Обжёгся дважды; спасал `git diff --stat`.
  Смотреть diff после КАЖДОГО прогона.
- **Совпадение площадей не доказывает корректность топологии.** Формулировка
  исполнителя: «площади сходятся раньше топологии». Предписанный мной
  `difference` давал идеальные числа и ронял `coverage_is_valid`.
- **Свежее дерево заводится от `main` по умолчанию.** Первый запуск ушёл на
  `main`, где нет ни мастер-карты, ни брифа. Всегда `-Base`.
- **Отслеживаемый файл внутри `sources/` ломает junction молча.** `.gitignore`
  не действует на уже отслеживаемое; git создаёт каталог, скрипт пропускает
  junction, пайплайн видит один файл вместо хранилища. Предупреждение сделано
  громким.
- **Числа в брифе исполнителю надо проверять на последствие.** Я написал
  «вернуть 217 км²», из которых 130 — открытая Атлантика: по букве Рио стал бы
  сухопутным. Исполнитель вынес развилку вместо исполнения — правильно.
- **Гейты размера живых доков падают ПОСЛЕ мержа**, когда обе стороны
  дописали по правилу. `AGENTS.md` ловился дважды. Лечится переносом
  завершённого, а не поднятием порога.
