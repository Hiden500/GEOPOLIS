  я удалил каталоги, за которыми он следил. Порт 3000 к концу сессии занял
  другой проект пользователя (`D:\Pax-Automata`). Прежде чем считать порт
  своим — `netstat -ano` + `Get-CimInstance Win32_Process` по PID.

  отдаёт код `main`. Поднимать вручную из дерева
  (`npm run dev -- --port <свободный> --strictPort`), затем
  `preview_start {url: ...}`.
