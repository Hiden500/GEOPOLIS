## Как прогнать LLM из дерева

У linked worktree нет своего `server/.env` (он только в главном checkout и вне
git), а модельный прокси сам собой не поднимается. Всё это закрывает
`scripts/llm-run.ps1`: тянет env в переменные процесса (на диск дерева ничего
не пишет, значения не печатает), поднимает `D:\CLIProxy\cli-proxy-api.exe` на
:8317, ждёт появления модели в `/v1/models` и запускает команду из `server/`
ТЕКУЩЕГО дерева — поэтому вызывать надо, находясь в дереве.

- Проверка связи (порт 3000 не нужен, прокси поднимется):
  `pwsh -File "D:/Pax Historia LOCAL/scripts/llm-run.ps1"`
- Сервер игры с живой моделью:
  `... llm-run.ps1" -Run "npm run dev"` — порт 3000 должен быть свободен.

Проверено 2026-08-07: 12 моделей на эндпоинте, `gemini-3.6-flash-high` рабочая.
**Голым `npm run dev` сервер поднимать нельзя**, если трогаешь LLM: без env он
берёт дефолт `http://localhost:1234/v1` и любой ход падает.

  окружение поднимает `scripts/llm-run.ps1`, лежавший в репозитории всё это

  не существует» — скилл не запускался. Скрипт нашёл пользователь.
- **Команда пользователю, сломавшаяся в ЕГО оболочке — третий раз в этой
  ветке.** `pwsh -Command '… "путь с пробелами" …'` я проверил в Bash-инструменте
  (там одинарные кавычки литеральны), а кнопка «Run» отдаёт строку в
  PowerShell — вложенные двойные кавычки при передаче в нативный `pwsh`
  срезаются, и `D:/Pax` ушло отдельным аргументом.
  **Правило:** проверка команды в Bash-инструменте НЕ доказывает её
  работоспособность у пользователя. Надёжная форма — `pwsh -File <путь>` с
  ОДНИМ аргументом, всё квотирование заперто внутри файла, путь без пробелов.
- **Границу удаления считать обходом графа импортов, а не по списку в
  передаточном документе.** Список осиротевшего в прошлом handoff числил
  `ScenarioSelector` и `ErrorBoundary` мёртвыми — их держит `App.tsx`.
  Удаление по списку снесло бы экран выбора сценария.
- **Отсутствующий ключ словаря не виден ни компилятору, ни тестам.** Ловится
  только открытием конкретного экрана — или тестом
  `client/src/i18n/__tests__/localeKeys.test.ts`, который теперь есть.
- **Пометки по заранее снятым номерам строк легли не туда**: перед этим я
