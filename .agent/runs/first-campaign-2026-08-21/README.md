# Первый непрерывный прогон партии через шлюз — 2026-08-21

Партия SUN, 1946-01 → 1948-01 (24 хода), модель `gemini-3.6-flash-high` через
`cli-proxy-api` (localhost:8317), `LOCAL_LLM_TEMPERATURE=0`. Время 16,9 мин.

## Зачем этот прогон

Полного прогона партии в проекте не было ни разу: все замеры делались на
двухлетних отрезках под конкретную правку промта, а `server/data/saves` содержит
только тестовые фикстуры. Здесь впервые проверялось не «работает ли правка», а
«идёт ли партия».

## Что мешало и что починено

Шлюз с лимитом отвечает 429 и уводит модель в cooldown. Провайдер не повторял
запрос — ход засчитывался ошибкой, партия теряла его целиком. Первый прогон в
этот день дал **22 потерянных хода из 24**. Повтор с экспоненциальной паузой
добавлен в `LocalOpenAIProvider` (коммит `6db3533`), после чего тот же прогон
дал **20 успешных ходов из 24**.

Оставшиеся 4 отказа — исчерпание трёх попыток на затяжном cooldown. Для длинного
прогона поднимать `LOCAL_LLM_RATE_LIMIT_RETRIES` и
`LOCAL_LLM_RATE_LIMIT_BASE_MS`; код для этого править не нужно.

### Критерий готовности М4-ядра — не выполнен

Роадмап (`docs/plans/11_MVP_ROADMAP.md`, редакция 2026-08-19) требует, чтобы пять
глаголов — `peace`, `annex`, `puppet`, `guarantee`, `support_proxy` — прозвучали
в прогоне живой модели. **Ни один не прозвучал.** `war` тоже нет.

Это подтверждает записанное там же рассуждение: «Двери в войну ядро не открывает.
Пока `war` не звучит, у пяти остальных нет контекста». Два года партии проходят
без единого военного действия.

### Где играет режиссёр

Страны, попавшие в события: USA 20, GBR 18, PSE 11, FRA 8, ITA 2, TWN 2, IND 2,
CHN 1, ALB 1, AUS 1. Палестина на третьем месте — для 1946–47 исторически
уместно (мандат и кризис), но заметно, что мир вращается вокруг четырёх стран.

## Что это значит для критерия релиза

Критерий «партия проходится насквозь» этим прогоном НЕ проверен: пройдено два
года из пятнадцати, и партия не имеет конца по конструкции — единственное
терминальное состояние `defeated` наступает только при потере всех регионов
(`shared/src/types/Campaign.ts`).

Проверено другое, и это тоже впервые: **цепочка замыкается без ручного
вмешательства** — тик, промт, ответ модели, валидатор, применение, следующий ход.

## Воспроизведение

```
cd server
npx tsx scripts/runCampaignWithLLM.ts --years 2 --player SUN --out <каталог>
```

Нужен поднятый `cli-proxy-api` и `server/.env` с `LOCAL_LLM_BASE_URL`,
`LOCAL_LLM_API_KEY`, `LOCAL_LLM_MODEL`. Файл `.env` в `.gitignore` — ключ в
репозиторий не попадает.
