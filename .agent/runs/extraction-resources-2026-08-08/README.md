# `build_extraction`: словарь ресурсов и видимость предпосылки — замер 2026-08-08

Партия USA 1946-01 → 1948-01 (24 хода), `gemini-3.6-flash-high` через шлюз,
`LOCAL_LLM_TEMPERATURE=0`, три прогона на конфигурацию (72 хода каждая).

База — конфигурация ветки `claude/dated-events` (прогоны `after-*` в
`.agent/runs/dated-events-2026-08-08/`): та же сборка, снятая в тот же день.
Отдельный baseline не гонялся намеренно — он уже был.

## Что показал каждый шаг

**Словарь ресурсов** (20 имён из `ResourceType` прямо в контракте примитивов)
поднял число попыток глагола с 1 до 7 за 72 хода и убрал угадывание имени: до
правки единственная попытка использовала `oil` — единственное слово-ресурс,
которое вообще встречалось в промте (в примере про бюджет). Применённых
по-прежнему 0: все семь попыток разбились о предпосылки.

**Показ залежей с уровнем** (`deposits: coal 10/10, oil 10/10`) сработал как
задумано — модель перестала тратить ходы на заведомо невозможное, попытки 7 → 0.
Но обошёлся в **+10,6 % промта на каждом ходу** ради сообщения, которое в
стартовом мире всюду одинаково.

**Только расширяемое** (`can expand: …` появляется лишь там, где уровень ниже
потолка; отсутствие строки объявлено ответом, а не умолчанием) даёт тот же
эффект — 0 бесполезных попыток — за **+2,1 %**, и это почти целиком постоянный
текст секции: строк регионов в стартовом мире не появляется НИ ОДНОЙ. Когда в
данных появится место для роста, строка появится сама.

## Главное: рычаг заперт данными, а не промтом

Ни одна правка промта не может дать `build_extraction` примениться, потому что
расширять негде:

- **все 2 097 пар (регион, ресурс) сценария 1946 стартуют на уровне 10 из 10.**
  Это сделано намеренно: `scripts/map/fill_region_economy_1946.py:280-284` —
  «richness = текущий output, extraction level = MAX (сразу развёрнуто)», чтобы
  стартовая добыча совпала с историческими числами (`extractionFactor = 1,0`);
- **место для расширения не появляется само.** Уровень мощностей меняет только
  `commands/resources.ts`, и вызывает его единственный потребитель — сам глагол
  `build_extraction` (`PrimitiveEngine.ts:3029`). Тик добычи истощает залежь
  (`richness`), уровень не трогает;
- **`damageExtraction` (`commands/resources.ts:52`) не вызывается ниоткуда** —
  война мощности не разрушает, то есть естественный источник «места для
  восстановления» написан и не подключён.

Итого `expand` недостижим в принципе, а доступен только `dismantle` — то есть
рычаг заперт сам на себя. Что с этим делать — продуктовое решение (см.
`docs/TODO.md`).
