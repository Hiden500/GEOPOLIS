# Прогон партии на 15 лет — 2026-08-21

Партия SUN, 1946-01 → 1960-12 (180 ходов). Первая попытка пройти полный срок.
Модель `gemini-3.6-flash-high` через `cli-proxy-api`, `LOCAL_LLM_RATE_LIMIT_RETRIES=8`.

## Итог: партия дошла до конца срока, режиссёр — нет

| Величина | Значение |
|---|---|
| Ходов симуляции | 180 из 180, до 1960-12 |
| Ходов с участием режиссёра | 17 |
| Последний ход с режиссёром | 19-й (1947-08) |
| Действий применено | 89 |
| Действий отклонено | 2 |
| Ошибок | 163 (160 из них `503 auth_unavailable`, 3 — `500`) |

## Что оборвалось и почему

С двадцатого хода шлюз начал отвечать `503 {"error":{"message":"auth_unavailable"}}`
и не переставал до конца прогона. **Это не квота и не лимит частоты** — повтор при
429, добавленный тем же днём, отработал штатно на первых девятнадцати ходах.
Прокси потерял авторизацию во время работы.

Проверено: после перезапуска `cli-proxy-api.exe` тот же запрос проходит
немедленно. То есть лечение — перезапуск процесса, а не правка кода игры.
Повтором `auth_unavailable` не чинится: сколько ни повторяй, авторизации не
прибавится. Поэтому обработку 503 в провайдер НЕ добавляли.

**Следствие для длинных прогонов:** трёхчасовой прогон требует присмотра за
шлюзом. Либо локальный рантайм без авторизации (LM Studio), либо перезапуск
прокси по расписанию, либо разбивка на отрезки по два года.

## Что этот прогон всё-таки доказал

**Симуляция не зависит от режиссёра.** Движок отработал все 180 ходов до декабря
1960 года, хотя с двадцатого хода LLM не отвечала вовсе. Тики шли, состояние
менялось, падения не случилось ни разу — партия просто осталась без событий
режиссуры. Это устойчивость, которую до сих пор никто не проверял: раньше
прогоны шли двухлетними отрезками с работающей моделью.

**Распределение глаголов снова то же.** На 89 применённых действиях:
`research_shift` 44, `diplomacy` 24, `production_shift` 12, `spawn_incident` 8,
`enact_reform` 1. Третий независимый замер подряд (2026-08-09 на 480 ходах,
`first-campaign-2026-08-21` на 24 ходах, этот) даёт один и тот же порядок.

**Военных глаголов снова ноль.** Ни `war`, ни `peace`, ни `annex`, ни `puppet`,
ни `guarantee`, ни `support_proxy` — за полтора года активной режиссуры.

## Чего прогон НЕ доказал

Критерий «партия проходится насквозь» по-прежнему не проверен. Дошедшие до 1960
года 180 ходов — это ходы движка, а не сыгранная партия: полтора года из
пятнадцати с режиссёром и ни одного человеческого решения. Судить о том, скучно
ли играть, по такому прогону нельзя.

## Воспроизведение

```
cd server
npx tsx scripts/runCampaignWithLLM.ts --years 15 --player SUN --out <каталог>
```

Перед запуском убедиться, что шлюз авторизован:

```
curl -s -H "Authorization: Bearer <ключ>" http://localhost:8317/v1/models
```
