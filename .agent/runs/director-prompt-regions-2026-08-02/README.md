# Регионы как цели + форма `target` — замер, 2026-08-02

Две правки промта, замеренные раздельно. Вторая нашлась благодаря первой:
оживший региональный слой вытащил наружу дефект формы, который до этого просто
негде было увидеть.

Условия те же, что у `director-prompt-domains-2026-08-02`: партия USA
1946-01 → 1948-01 (24 хода), `gemini-3.6-flash-high` через шлюз,
`LOCAL_LLM_TEMPERATURE=0`, по три прогона на конфигурацию. Сводка —
`analyze.py` из соседнего каталога:

```text
python ../director-prompt-domains-2026-08-02/analyze.py regions-1.llm.jsonl regions-2.llm.jsonl regions-3.llm.jsonl
```

## Правка 1 — регионы стали адресуемы

Секция `## Regions You Can Address` (id регионов игрока, стран ротации и
держателей показанных кризисов, кап 8 на страну, сортировка по недовольству) +
держатели показанных кризисов добавлены в `## Country IDs`.

Второе — починка прямого противоречия: промт разворачивал кризис в стране,
которой нет в списке, а `Narrative requirements` запрещают о такой стране и
говорить, и действовать («it does not exist in this simulation right now»).
Замер до правки: 4 из 5 показанных кризисов были в странах вне списка (VNM,
IDN, PSE, MWI).

## Правка 2 — образец ответа показывал `target` строкой

Диагностика (`diagnosis-raw-responses.llm.jsonl` — сырые ответы модели на
отказных ходах, пишутся `runCampaignWithLLM.ts` только при отказе):

```json
{"verb": "repress", "target": {"regionId": "758"}}    // строка вместо числа
{"verb": "enact_reform", "target": "ALB"}             // строка вместо объекта
```

Причина в промте: образец ответа содержал `"target": "shape depends on the verb
— see the alphabet above"`, то есть показывал строку. Модель копировала ФОРМУ
примера, а не читала описание алфавита. Исправлено на объект + явная строка в
Hard limits про числовой `regionId`.

## Что НЕ подтвердилось

Рост отказов после правки 1 (2,00 → 8,00) выглядел ценой оживления регионов.
Это оказалось не разменом, а отдельным дефектом промта: после правки 2 отказы
упали до 0,33 при СОХРАНЁННОМ региональном слое.

## Находки вне scope

- **`schemaInvalid` не называет поле.** Отказ несёт глагол и позицию в массиве,
  но не то, что именно неверно. Модель узнаёт из следующего промта, что
  «примитив три не прошёл схему», и починить это ей нечем. Правка движка, не
  промта.
- **ISO-дата просачивается в прозу.** Промт даёт `## Current Date` в виде
  `1946-08-01 — август 1946 года` и просит назвать период «так, как написано
  после тире»; модель иногда копирует всю строку, включая ISO. По
  конфигурациям: 0 / 5 / 0 / 7 заголовков из 72 — с правками не связано,
  разброс модели. Дефект существует независимо и не лечился этим заходом.

## Что НЕ проверено

- Один сценарий, одна страна игрока, горизонт два года. Поздняя партия с
  войнами и распадами не покрыта.
- Кап 8 регионов на страну не калибровался: взят как первое разумное значение
  под бюджет промта (промт вырос 24 121 → 29 090 знаков, +20 %).
- Не измерено, не станет ли поток инцидентов утомительным для игрока: 57
  `spawn_incident` за 72 хода — это примерно один инцидент за 1,3 месяца игры.
  Оценка темпа — продуктовая, за пользователем.
