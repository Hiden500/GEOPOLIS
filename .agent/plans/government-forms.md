## Objective and observable outcome

Ввести два свойства государства — **кто фактически правит** (`powerStructure`)
и **кому оно подчинено** (`sovereigntyStatus` + `overlordIds`) — на всех 157
странах сценария 1946, и сделать так, чтобы новая разметка зависимости не могла
молча разойтись с существующей (`diplomacy.puppets`).

Наблюдаемый результат:

- `server/data/scenarios/1946/government.json` — 157 записей, генерируется из
  входа пайплайна, читается движком в `Country.politics`;
- игрок видит форму власти и статус подчинения там же, где сегодня видит
  идеологию (InspectorPanel, ContextPanel, PoliticsBook), в обеих локалях;
- тест падает, если страна одновременно чья-то марионетка и юридически
  суверенна, либо если её сюзерен по `puppets` не совпадает с `overlordIds`.

## Assumptions and unknowns

- Набор из 157 записей — внешнее историческое наполнение, принятое как вход
  (провенанс фиксируется отдельным документом). Уверенность по записям:
  высокая 111, средняя 39, низкая 7.
- UNKNOWN: `overlordIds` для `disputed_administration` означает **претендента**
  (QDV→FRA), а для советских клиентов — **патрона** (QAZ→SUN). Поле в этом
  статусе двузначно; разрешение отложено (см. Decision log, TODO).
- SAVE_VERSION не бумажный барьер для этой правки: новые поля опциональны,
  удаляемое `governmentType` при загрузке старого сейва становится лишним
  ключом. Бамп версии не требуется (проверить прогоном SaveService.test.ts).

## Alternatives and selected decision

Задача ставила три направления сведения зависимости. Выбор сделан **по
данным**, а не по вкусу — см. Discoveries.

1. **`overlordIds` — источник, `puppets` — производное.** ОТКЛОНЕНО: правила
   вывода не существует. `QMH` и `QDV` имеют одинаковую пару
   (`disputed_administration`, `provisional_coalition`), но `QMH` — марионетка
   СССР, а `QDV` — антиколониальное восстание против Франции. Любое «правило»
   свелось бы к списку исключений, то есть к четвёртому представлению.
2. **Новое поле заменяет `puppets`.** ОТКЛОНЕНО: `puppets` — рантайм-отношение
   с операциями в алфавите примитивов (`palette.ts`), `sovereigntyStatus` —
   юридический факт сценария. Замена либо лишила бы алфавит операции, либо
   сделала бы юридический статус рантайм-мутируемым без механики.
3. **ВЫБРАНО: оба живут с разделённым смыслом, противоречие ловит тест.**
   `sovereigntyStatus`/`overlordIds` — юридическое положение;
   `puppets` — эффективное следование внешней политике сюзерена.
   Множества не равны и не обязаны быть равны, но обязаны не противоречить.

## Discoveries

Прогоном по боевым данным (`server/data/scenarios/1946/countries.json`, 157
стран) против набора из 157 записей:

| Факт | Число |
|---|---|
| Записей в наборе / стран в сценарии | 157 / 157, полное совпадение id |
| Уникальных субъектов в `puppets` | 75 (77 записей: SDN и VUT — кондоминиумы) |
| Сюзеренов | 13 |
| Несуверенных по новому набору | 89 |
| Расхождений «сюзерен по `puppets`» ↔ `overlordIds` | **0** |
| Марионеток, суверенных по новому набору | **0** |

`puppets` ⊂ несуверенные, дельта = 14: 10 зон оккупации, 3 оккупированные
территории (JPN, QMS + QPS уже марионетка), 2 спорные администрации (QDV, QRI).

Разбивка по статусам показывает, что дельта **не случайна**:

| Статус | всего | из них марионетки |
|---|---|---|
| colony / protectorate / mandate / dominion / trust_territory / condominium | 70 | **70** |
| sovereign | 68 | **0** |
| disputed_administration | 6 | 4 |
| occupied_territory | 3 | 1 |
| occupation_zone | 10 | 0 |

Шесть «классических» статусов зависимости дают марионетку всегда, суверенитет —
никогда. Рваными оказываются ровно оккупация и спорные администрации, и именно
там `overlordIds` меняет смысл (претендент vs патрон). Это и есть причина
отклонить направление 1.

Отдельно: `governmentType` в `countries.json` **не задан ни у одной из 157
стран**; `createCountry` ставит `"Unknown"`, и все три места показа выводят
`[ярлык идеологии, governmentType].filter(Boolean).join(" · ")` — то есть
игрок сегодня видит «Социал-демократия · Unknown». Поле занимает ровно тот
смысловой слот, который вводит `powerStructure`.

## Decision log

- **2026-07-29. Направление 3.** Два представления, разный предикат, инвариант
  вместо равенства. Цена названа: при рантайм-изменении `puppets` примитивом
  `sovereigntyStatus` не обновляется — до появления механики деколонизации/
  вассалитета. Инвариант держится на слое данных (валидатор пайплайна + тест по
  загруженному сценарию), а не в `findStateViolations`: тот модуль явно
  объявляет дипломатию вне своей границы, а превращение добавления марионетки в
  откат транзакции изменило бы семантику алфавита, собранного прошлой сессией.
- **2026-07-29. `governmentType` — легаси, удаляется.** Ноль авторских
  значений, единственный потребитель — показ, показывает литерал `Unknown`.
  `powerStructure` занимает его место в UI.
- **2026-07-29. Поля живут в `PoliticsState`, не в новом `Country.government`.**
  Отдельный блок разнёс бы описание государства по двум местам: `ideology`,
  `ideologyCoordinates` и удаляемый `governmentType` уже здесь.
- **2026-07-29. `overlordIds: string[]`, а не `string | string[] | null`.**
  Кондоминиум даёт двух сюзеренов; единая форма списка снимает union из всех
  потребителей, пустой список = суверен.
- **2026-07-29. Название вроде «Британская колония» собирается как
  «Колония — Великобритания».** Прилагательная форма метрополии на русском
  требует согласования по роду со статусом (колония ж., протекторат м., зона
  ж.) — 11 статусов × 13 метрополий вручную, с новым полем данных или словарём
  по id. Отказ от прилагательной формы стоит стилистики и не стоит ничего
  больше; имя метрополии берётся из `LocalizedText` страны.
