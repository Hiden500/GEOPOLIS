# Идеология как модификатор союзов, а не запрет
Status: complete
Owner: Claude (сессия «alliance-affinity»)
Starting commit: b1f298d (merge `main` → `claude/alliance-affinity`, основание `claude/ideology-data` 6ffe786)

## Objective and observable outcome

Убрать булев идеологический гейт из формирования союзов и заменить его
влиянием на отношения и на порог согласия — наравне с общим врагом, соседством
и зависимостью (решение пользователя, `docs/DECISIONS.md` 2026-07-27
«Идеология влияет на союзы модификатором, а не запретом»).

Наблюдаемый результат:

1. Число стран сценария 1946, не способных заключить союз ни с кем, падает со
   **103 из 157** до **0** — измеряется прогоном по реальным данным, не
   рассуждением.
2. Союз идеологических антиподов при общем враге ФОРМИРУЕТСЯ дрейфом (без
   участия LLM/игрока) и РАСПАДАЕТСЯ после исчезновения врага — обе половины
   проверяются прогоном тика.
3. Пары идеологически родственных стран без общего врага союз сами по себе НЕ
   образуют: структурного тяготения на это не хватает по построению констант.

## Alternatives and selected decision

Центральный вопрос — **как возникают отношения у пар, которых нет в
состоянии**. Тик обходит только существующие записи, а они пусты, поэтому
«дрейф по идеологической близости» сам по себе не запускается.

- **A. Полная матрица.** 12 246 пар в сейве. Отвергнуто: прямо противоречит
  правилу «избегай раздувания save-файлов».
- **B. Отношения выводятся на лету, не хранятся** (`relation = структура +
  хранимая дельта`). Красиво и даёт нулевую цену хранения, но переопределяет
  смысл поля, которое читают 20 мест в трёх модулях, включая UI; каждое
  пришлось бы провести через хелпер. Отвергнуто как несоразмерный радиус
  правки для этой сессии.
- **C (выбрано). Дрейф к структурному тяготению по кандидатному набору.**
  Отношения остаются хранимым числом (все читатели не меняются), но каждый
  ход тянутся не к нулю, а к цели, выведенной из состояния пары. Кандидатом
  пара становится, если у неё есть КАНАЛ: общая граница, зависимость/формальная
  связь, влияние, участие в одной войне — либо уже существующая запись
  (то есть кто-то по ней действовал).

**Почему кандидатный набор не приближение, а точность.** Пара без канала и без
записи получает тяготение не больше `IDEOLOGY_AFFINITY_SPAN/2 ×
CONTACTLESS_IDEOLOGY_SALIENCE` = 10 пунктов по модулю — то есть заведомо ниже
минимального порога союза (30) и выше порога соперничества (−70). Пропуск таких
пар ничего не теряет, и это проверяется тестом на константах, а не обещанием.

**Цена, названная прямо.** Сейв растёт на записи материализованных пар: на
старте 1946 это ≤ 344 пары × 2 направления ≈ 688 чисел (десятки килобайт), и
растёт дальше только вместе с числом войн и действий. Общие соперники НЕ
делают пару кандидатом (только усиливают давление у пары, у которой канал уже
есть) — иначе полсотни стран, назначивших соперником одну сверхдержаву, дали бы
ту самую полную матрицу через чёрный ход.

## Форма модификатора

Идеологическая дистанция `d ∈ [0,1]` — та же `ideologyDistance` из
`shared/src/utils/discontent.ts` (евклид, нормировка на `2√2`).

**Структурное тяготение** (цель дрейфа, пункты шкалы −100..100):

```
affinity = IDEOLOGY_AFFINITY_SPAN × (0.5 − d) × salience
         + COMMON_ENEMY_AFFINITY × pressure
         + DEPENDENCY_AFFINITY × dependency
         + (воюют друг с другом ? AT_WAR_AFFINITY : 0)
```

`salience` — во сколько идеология вообще важна этой паре: полная при живом
канале, `CONTACTLESS_IDEOLOGY_SALIENCE` без него. Так соседство входит в модель
не отдельным слагаемым «дружбы» (соседство исторически столько же ссорит,
сколько сближает), а множителем важности: сосед с чужим режимом отталкивает
сильнее, чем такой же режим за океаном.

**Порог согласия на союз** вместо общих 70 для всех:

```
formation(d, pressure) = ALLY_RELATION_THRESHOLD
                       + ALLY_IDEOLOGY_THRESHOLD_SPAN × (d − 0.5)
                       − ALLY_COMMON_ENEMY_RELIEF × pressure
break(d)               = ALLY_BREAK_THRESHOLD + ALLY_BREAK_IDEOLOGY_SPAN × (d − 0.5)
```

**Четыре инварианта, выводимые из констант (и проверяемые тестом):**

1. `formation ≤ 80 < RELATION_SCALE_MAX` — союз достижим для ЛЮБОЙ пары.
   Это и есть закрытие дефекта 103 стран.
2. `formation(d,p) > break(d)` при всех `d,p` — тик не может создать союз,
   который сам же снимет в том же проходе.
3. `max affinity без общего врага` (50) `< min formation без врага` (60) —
   мир не сваливается в блоки на первом же тике без причины.
4. `affinity(антиподы, полное давление) > formation(антиподы, полное давление)`
   и `affinity(антиподы, без давления) < break(антиподы)` — союз антиподов
   при общем враге возможен и без него не держится.

## Discoveries

- **Падение, не названное в промте.** После слияния `main` (демография 504
  регионов) с `claude/ideology-data` (координаты 157 стран) падал
  `milestone0Loop.test.ts` «режиссёр не может ответить за игрока»: тест брал
  `regionCrisisLatch[0]`, а самой горячей точкой стал болгарский регион, не
  принадлежащий игроку. Это смысловой конфликт слияния, не регрессия сессии;
  починено выбором региона по свойству (латченный И контролируемый игроком),
  порог и предмет проверки не тронуты.
- **`areIdeologicallyCompatible` не проверялся ни одним тестом по существу.**
  Тест «does not add an ally when relations are high but ideologies are
  incompatible» проходил из-за отсутствия взаимности (у второй стороны вообще
  нет записи), а не из-за идеологии: гейт до него не доходил.
- **`Country.politics.ideology` НЕ теряет последнего читателя.** Кроме гейта
  его читает `PoliticsTick` через `IDEOLOGY_LEGITIMACY_BASE` и
  `GOVERNMENT_TYPE_CORRUPTION_BASE`, а `resolveIdeologyCoordinates` — фолбэком.
  Поле остаётся; см. Final outcome.

  без спроса.

  одной войне — частный случай первого.
