# Research-отчёт Фазы 1 — Geopolis (дизайн-партнёрский цикл)

Дата: 2026-07-23. Статус: на стоп-точке, ждёт отмашки на Фазу 2.
Метод: 5 веб-разведчиков (Pax Historia · аналоги · LLM-инфраструктура ·
контекст/память/eval · данные/хранение/калибровка) + первичные артефакты PH от
пользователя (system prompt, пресет, полный запрос, схема, ответ модели) + мои
замеры. Градация источников везде: [П] первичный · [В] независимый вторичный ·
[М] маркетинг · [А] anecdote · [И] inference · [?] неизвестно. Полные отчёты
разведчиков с URL — в транскриптах агентов сессии 2026-07-23; ключевые
утверждения продублированы в ledger (design-partner-audit.md, разделы «Фаза 1»).

## 1. Главные выводы (сжато)

1. **Архитектурная ставка Geopolis подтверждена со всех сторон.** «Движок владеет
   числами и состоянием, LLM — капованные команды + нарратив» — это одновременно:
   (а) противоположность документированных болей PH [П: их промт], (б) паттерн
   Cicero/VotC/RimWorld-модов [П/В], (в) рекомендация академической линии
   (propose→validate→apply; WarAgent secretary) [П].
2. **Стоимость — не наше ограничение.** Наш цикл ≈ $0.0025/ход, кампания 54 года
   ≈ **$1.62** [П: тариф ai.google.dev + мой fixture-замер]. PH: вход раунда 1
   ≈ 19-20k ток (наш ×4-5), к 80-му раунду ~100k (наш ×20), цена прыжка растёт
   0.52→32 токена к 250-му раунду [П-артефакты + В]. Кэш-оптимизации нам НЕ нужны
   (explicit-кэш при редких ходах убыточен из-за storage $1/1M/час).
3. **Наши реальные дефициты — не там, где у PH.** У нас: пустая стартовая
   дипломатия (F59), отсутствие последствий (долг игрока без наказания, F60),
   демографический взрыв (F61), 10% регионов вне войны (F64), незащищённая
   агентность игрока (F52), неизмеряемое качество LLM (нет eval). Все шесть
   имеют готовые решения с полки — см. §4.

## 2. Pax Historia: что мы теперь ЗНАЕМ (не предполагаем)

Источники: system prompt + пресет + полный запрос + схема + ответ [П],
опыт пользователя [П-участник], research-док Pax-Automata + vgtimes + Strategium
+ YC [В/А]. Детальный реестр 15 категорий жалоб — в ledger.

| Аспект | PH (факт) | Geopolis (факт) |
|---|---|---|
| Состояние | Только карта (polity/regions/features); экономики нет | Полный GameState, все числа у движка |
| Числа | Псевдо-движки в пользовательских пресетах; «все модели, кроме дорогих, выдумывают» | Zod-команды с капами; LLM не источник чисел |
| Промт | ВЕСЬ мир каждый прыжок + ВСЕ действия за партию + чаты; 941 регион строками | ~18 стран агрегатами, окна истории; 2-4.4k ток |
| Идентификация | По точным ИМЕНАМ (name-chaining хрупок) | По ID (после регрессии SOV/ROM) |
| Валидация | Нет (движок ругается на невозможный transfer, но событие остаётся) | Схема+капы+применимость (свои дыры — F1-F11) |
| Рельсы | Инструкцией: «historical events should always occur» | Hinge points: «подсказка, не сценарий» |
| Агентность игрока | Защищена промтом («Never execute actions FOR the player») | НЕ защищена ничем (F52) — единственное, где PH впереди |
| Стартовые данные | Битые уже на раунде 1 (армия Бразилии у Мексики, персоны-батальоны) | Валидируются двумя слоями (свои дыры — F35) |
| Язык | Code-switching в RU-выводе виден в их же ответе | Тот же риск (C9), нужен eval-чек |

«Что не повторяем» из опыта PH: рост цены хода с длиной кампании; накопление
всех действий игрока в промте; журнал договоров «только в тексте переписки»;
советник, жгущий токены дороже игры; монетизация, ломающаяся от смены лимитов
провайдера (Patron заморожен после урезания Google-квот [В DTF]).

## 3. Чему учимся у аналогов (8 профилей, полные — в транскрипте)

- **Cicero** [П Science/Meta]: даже при обусловленном диалоге ~7% выходов
  расходятся с intent при ансамбле фильтров → несколько % расхождений
  нарратив↔состояние — НОРМА; нужен фильтр, а не надежда.
- **AI Diplomacy (Every)** [П]: невалидные приказы 6-14% у топ-моделей →
  «невалидное — метрика модели, не краш»; двухканальная память (дневник страны +
  годовая консолидация дешёвой моделью); lie-detection сравнением каналов.
- **WarAgent** [П arXiv]: secretary-валидатор предусловий поверх whitelist
  (≤4 ретрая); состояние как компактные таблицы (Board&Stick) — мультитёрн →
  сингл-тёрн; точность решений LLM о войне без движка — 54.6% (не доверять).
- **Generative Agents** [П/В]: главный класс ошибок — retrieval, не генерация;
  полный LLM-цикл на агента — «тысячи долларов», не масштабируется на 128 стран.
- **AI Dungeon** [П Latitude]: ~4 переделки памяти → конечная точка = «память и
  автосуммаризация как независимые слои»; числа = «memory poisoning» — LLM не
  должен хранить/воспроизводить числа.
- **Voices of the Court (CK3)** [П]: whitelist эффектов («LLM cannot invent new
  ones») + Action Approval «safety valve» для тяжёлых действий + дешёвая модель
  на суммаризацию.
- **WorldSim** [П/В]: антипаттерн «контекст = сейв»; цена вынудила ввести кредиты.
- **RimWorld-моды** [М/В]: Smallville-память работает на flash-классе почти
  бесплатно; каскад fallback-моделей при лимитах.

## 5. «Сознательно не делаем» (кандидаты в концепт-документ)

- Полный мир/история в промте (боль PH, LoCoMo: context dilution).
- LLM-числа в любом виде, включая «псевдо-движки в промте» (боль PH, memory
  poisoning AI Dungeon, 54.6% WarAgent).
- Идентификация сущностей по именам (боль PH; у нас ID).
- Обязательные исторические рельсы (инструкция PH; у нас hinge-подсказки).
- LLM-repair-вызовы на каждый невалид (цена; движковый downgrade дешевле).
- NLI/critic-верификатор нарратива в рантайме (дорого, AUC 0.66-0.86; наш мир
  замкнут — хватает whitelist-чека).
- Reflection/память с LLM-записью (дорого; нарушает «движок владеет фактами»).
- Полный event sourcing (усугубит рост журналов).
- Свою модель обучать (Cicero: сотни GPU).
- Один провайдер как догма: интерфейс уже есть; gpt-5.4-nano — паритет цены со
  строгой схемой; DeepSeek/Qwen дешевле, но без строгой схемы (нужен repair-слой);
  локальные — только как оффлайн-фолбэк после собственного RU-теста.

## 7. Следствия для Фазы 2 (продуктовые развилки, решает пользователь)

1. Видение игрока: «аквариум с редкими вмешательствами» vs «плотное управление»
   (главный вопрос; PH-опыт пользователя — вход).
2. Агентность: может ли LLM действовать за страну игрока, и что под
   approval-окно (война? смена режима?) — §4.11.
3. Крупные события: какие 2-4 команды добавляем первыми (annex-механика?
   распад? объединение?) — §4.17.
4. Стартовая дипломатия: авторская таблица на основе ATOP/COW (некоммерческая
   лицензия!) vs чисто ручная — §4.1.
5. Последствия для игрока: дефолт/наказания (готов ли пользователь к «игра
   может наказать») — §4.7.
6. Море: только гейты десанта/блокады или больше — §4.9.
7. Мульти-месячный ход (H11): оставить/убрать — связано с видением темпа.
