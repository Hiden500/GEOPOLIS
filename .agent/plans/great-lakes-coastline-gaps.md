## Assumptions and unknowns

Авторитетность озера (не суши) в этой конкретной области обоснована прямым
измерением (0.0 км² разрыва против сырой `game_map.json` для всех 4
озёр), не предположением по умолчанию — см. Progress п.1. Если у ДРУГИХ
озёр (не проверялись) окажется противоположная ситуация (суша ближе к
истине, чем озеро), этот же скрипт для них НЕ подойдёт без проверки
направления авторитетности заново для каждого конкретного случая.

## Alternatives and selected decision

Рассмотрено: расти ОЗЕРУ (как `fix_sea_coastline_gaps.py` делает для
моря) — отклонено ПОСЛЕ измерения: озеро уже точно совпадает с сырой
сушей (0.0 км² разрыва), значит деформировать точный NE10m-контур озера
ради патча кураторской суши было бы неверным направлением, маскирующим
реальный дрейф кураторской суши, а не исправляющим его.

Рассмотрено: `absorb_compact_gaps`-подобный либеральный проход (без
проверки компактности) — отклонено: этот вариант существует специально
для случая mutable=море (настоящие озёра уже все авторитетны как
water_geoms, проглотить нечего); для mutable=суша обычная защита
`absorb_slivers` (не проглатывать что-то похожее на озеро) — штатный,
нужный механизм, снимать его не за чем (независимая проверка подтвердила:
0 настоящих пропущенных разрывов среди "компактных блобов").

## Discoveries

Направление авторитетности (озеро vs суша) — НЕ константа для всего
датасета, зависит от того, какая сторона имеет более свежий/точный
источник в конкретном месте (здесь — озеро, т.к. NE10m-рефреш точен;
для суши в других местах этой же сессии — наоборот, суша авторитетна).
Всегда измерять перед тем, как выбирать направление роста.

Диагностические скрипты, копирующие `absorb_slivers`'s логику мозаики без
клипа входных геометрий по bbox, дают вводящие в заблуждение отчёты о
дальних, не относящихся к делу водоёмах — сам движок устойчив
(`land_touch`), только копии могут ошибаться.

`n_skipped_blob` в `absorb_slivers` — диагностический счётчик, не строгая
гарантия "N реальных пропущенных разрывов"; считает до проверки покрытия.
