# Предлагаемая очерёдность — приоритет утверждает пользователь

Порядок задан одним соображением: **сначала перестать врать самим себе, потом
чинить геометрию.** Площади считает домен `world` после меня, и он берёт их из
производных файлов; пока производный файл может молча разойтись с картой,
любая моя правка геометрии приезжает к нему в неизвестном виде.

1. **T-1 — гейт устаревания производных артефактов** (G1, G2, C1). Прямая
   причина: файл под git описывает карту на 55 регионов больше живой, и это
   нашлось случайно. Здесь же чинятся оба читателя.
2. **T-2 — критерий `orphan` и allowlist кусков** (G4, G5, G6). Второй,
   потому что allowlist — запись «закрыто навсегда»: положить её поверх
   критерия, дающего 23 ложных сироты из 23, дороже, чем не класть вовсе.
3. **T-3 — рендер перешейка** (C2). Пятнадцать минут, закрывает
   пользовательскую жалобу или опровергает мой численный вердикт.
4. **T-4 — уборка 14+1 планов** (G8). Механическая, к геометрии отношения не
   имеет, идёт последней и может уехать в чужую ветку целиком.
5. **Ганьсу/Синьцзян** (G3) — **не брать**. 18,5 км² на регионе 405 565 км² —
   0,0046%, невидимо и в игре, и на экране. Риск не в площади, а в неизвестном
   событии, которое её сдвинуло; этот риск уже удержан потолком в ALLOWLIST,
   который упадёт при росте. Работа даст запись в журнале и ноль в партии.
6. **Восемь источников** (G7) — **не брать без решения пользователя**: это не
   инженерная задача, а закупка внешних данных с проверкой provenance и
   лицензии, и мастер под git делает её несрочной.

# Ограничение параллельности

`scripts/map/**` делится с доменом `world`, и обе стороны заканчивают полным
прогоном пайплайна, переписывающим `regions.core.json`, `regions.state.json` и
`world_1946.geojson`. Пока живёт ветка этого домена, заданий домену `world` не
выдаётся. Регенерация мира — одна ветка за раз.
