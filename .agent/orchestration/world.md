# Реестр домена `world`

Очередь, критерии приёмки и вердикты аудита по наполнению мира и его
историчности. Формат — `.agent/orchestration/README.md`. Числа сюда попадают
только те, что снял оркестратор или аудитор своим прогоном; числа из отчёта
исполнителя — нет.

Область роли — `.agent/roles/world.md`: страны и их состав на старте, события,
дерево технологий, исторические границы как требование, имена и их
мультиязычность, реестр источников `docs/provenance/`.

## Почему файл заведён пустым

Реестр создан 2026-08-21 отдельно от заданий. Причина техническая:
`scripts/hooks/role-guard.mjs` читает счётчики строго по пути
`.agent/orchestration/<роль>.md`, и при отсутствии файла возвращает `null` —
то есть третий якорь роли («состояние вне контекста») для `world` не работал
даже при назначенной роли. Задания сюда пишет роль, а не тот, кто завёл файл.
