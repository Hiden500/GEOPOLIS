## 1. Готово к внедрению

### Завершение войны — торговая модель (Fearon, Wittman, Slantchev) + режим (Goemans)

**Дорогая часть уже написана:** `applyPeaceTerms` считает аннексии по бюджету
`warScore`, `makePeace` начисляет легитимность, репарации, снимает оккупацию.
Отсутствует ТОЛЬКО триггер — порядка 30 строк условия.

Логика: война идёт, пока хотя бы одна сторона считает продолжение выгоднее мира
(Виттман); кончается, когда оценки СХОДЯТСЯ — не когда кто-то признаёт поражение
(Слэнчев, «принцип конвергенции»).

```
для каждой активной войны:
  score  = computeWarScore(war)              // уже есть, −100..100
  months = длительность войны                // уже есть

  // Ветвь 1: капитуляция (торга не происходит)
  heldShare(loser) = |контролируемые| / |свои по ownerCountryId|
  если heldShare < CAPITULATION_HELD_SHARE
     или столица оккупирована ≥ CAPITULATION_CAPITAL_MONTHS:
        concludeWar(war); continue

  // Ветвь 2: торг
  p = 0.5 + (score/200)·evidence(months) + prior·(1 − evidence(months))
  evidence(months) = months / (months + BELIEF_HALF_LIFE)   // оптимизм выдыхается
  gain(side) = (territoryFlips.toSide / months) × WARSCORE_PER_NET_FLIP
  cost(side) = casualtyShare/manpower + militarySpending/(treasury+taxRevenue)
             + WAR_STABILITY_DRAIN
  resolve(side) = regimeResolve(powerStructure) × f(legitimacy)   // Goemans
  accept(side) = gain × p × resolve < cost
  если accept обеих сторон: concludeWar(war)
```

**Новых полей состояния — ноль.** `warScore` уже интегрирует историю (кумулятивные
флипы + потери), спад оптимизма выводится из длительности.

**Гоманс ложится на `powerStructure` почти буквально** (12 значений, размечены на
все 157 стран, механиками НЕ читаются):

| `powerStructure` | Поведение | Множитель упорства |
|---|---|---|
| `competitive_multiparty`, `limited_multiparty` | быстрый выход из проигранной войны | < 1 |
| `dominant_party`, `one_party` | среднее | ≈ 1 |
| `personalist`, `military` | «игра на воскрешение» | > 1 |
| `provisional_coalition`, `fragmented` | не держат курс | ≪ 1 |
| `colonial_administration`, `occupation_administration` | решает сюзерен (`overlordIds`) | делегировать |

**Три ловушки, видные по коду до реализации:**
1. `makePeace` НЕ делает всего, что делает мир: `PEACE_RELATION_RELIEF` (+50 к
   отношениям) и `reassignCapitalIfLost` применяются ВНЕ неё, в
   `PrimitiveEngine.ts:2126-2132`. Тик, зовущий `makePeace` напрямую, пропустит и
   потепление, и переезд столицы — а второе уронит инвариант «столица среди своих
   регионов». **Нужен общий `concludeWar(game, warId)` для обоих путей.**
2. Мир от движка не должен тратить структурный слот хода и идти через
   `applyPrimitiveBatch`.
3. Навязанный мир отнимает у игрока агентность. Предложение: капитуляцию применять
   принудительно, торг — ПРЕДЛАГАТЬ. **Продуктовое решение пользователя.**

**Предупреждение о первом эффекте:** на старте 1946 `manpower = 0` у всех, техника
нулевая, поэтому отношение сил в первые годы = отношение населений. Модель даст
быстрый белый мир почти для всех ранних войн — это верный ответ на мир без армий,
но калибровать `BELIEF_HALF_LIFE` придётся именно на нём.

### Обобщённый Ланчестер + ширина фронта

```
r = Deff / Aeff
lossA = total × r^e / (r^e + 1)
lossD = total × 1   / (r^e + 1)
total = WAR_CASUALTY_BASE_PER_FRONT_REGION × F × ((Aeff+Deff)/REF)^θ
Aeff  = min(attackerStrength, attackerFrontCount × FRONT_CAPACITY)
```

**`e = 1, θ = 0` побитово воспроизводят сегодняшнее поведение** — это строгое
обобщение, негативный контроль тривиален.

Эмпирика против нынешнего `e = 1`: Дюпюи на 675 дивизионных боях 1904–1991 и 243
сражениях 1600–1900 не находит устойчивой связи «отношение сил → отношение потерь»;
подгонки Хелмболда дают показатель заметно ниже квадратичного.

`Aeff` даёт эффект Фермопил: узкий фронт защищает слабого. Сегодня 10-миллионная
армия на одном контактном регионе дерётся так же, как на десяти.

### Локальная боевая мощь вместо глобального порога (Дюпюи)

```
localAttack  = Aeff / attackerFrontCount
localDefense = Deff / defenderFrontCount × terrain(region)
terrain(region) = 1 + URBAN_DEFENSE × region.urbanization
                    + AREA_DEFENSE  × log(region.area / REF_AREA)
flip if localAttack > localDefense × FLIP_THRESHOLD_RATIO
```

Все входы уже в `Region`. Дюпюи эмпирически опроверг правило 3:1: в послевоенных
боях наиболее частое соотношение атаки 0,54…0,97 к 1, атакующий побеждает в 75%
таких случаев.

Появляется главная стратегическая развилка войны — **концентрация против
распыления**; сегодня второй фронт буквально бесплатен.

### Мобилизация отдельно от недовольства (Эпштейн)

```
G = groupDiscontent × (1 − legitimacy / COUNTRY_POLITICS_SCALE_MAX)
P = 1 − exp(−k · coerciveCapacity / активные)
мобилизован, если G − R·P > T
```

Прямой ответ на записанную претензию «модель не отличает чуждых от готовых
воевать». **Новая чистая производная функция `regionMobilization`, ничего не
хранится** — буквальное соблюдение `CONCEPT.md` §4.1.

Побочно чинит перекос данных: у демократии низкое `G` и низкое `P`, у жёсткого
режима высокое и то и другое — произведение перестаёт быть монотонным по оси.
Появляется механика каскада: репрессия работает, пока сил хватает на всех сразу.

⚠️ Константы Эпштейна (`L = 0.82, T = 0.1, k = 2.3`) — числа абстрактной решётки,
НЕ откалиброванные на реальных конфликтах. Брать форму правила, не значения.

### Горизонтальные неравенства — симметризация `regionWelfare`

Конфликтогенны ОБА отклонения от среднего по стране, не только бедность
(Cederman, Weidmann & Gleditsch 2011). Замена `clamp01(ratio)` на меру от
`|ln(ratio)|`.

Измеренный эффект: кризисных регионов **184 → 223**, способных к восстанию **2 → 9**.
Открывает исторический класс, которого модель не умеет: богатая провинция, не
желающая кормить метрополию (Катанга, Биафра, Голландская Ост-Индия).

### Перевёрнутая U «режим → устойчивость» (PITF, Hegre et al.)

Устойчивы оба полюса, опаснее всего промежуточные режимы. Проверено в том числе на
периоде **1946–1992**. Наша измеренная кривая монотонна: −0,8 → 0,500; +0,2 → 0,157.

Вход есть: `politics.ideologyCoordinates.political` + `POLITICAL_BANDS`, средняя
ступень `managedCompetition` — ровно «частичная демократия». Функция
`regimeIncoherence(political)` с пиком в нуле → множитель в `stabilityEquilibrium`,
где сегодня нет ни одного политического входа.

Чинит перекос каталога групп МЕХАНИКОЙ, а не переразметкой 460 записей, и делает
`enact_reform` путём через опасную зону вместо безусловного улучшения.

⚠️ **Продуктовое утверждение о мире + трогает стабильность всех 157 стран.**
Требует решения пользователя.

### Селекторат — вторая валюта для репрессии

Режим с широкой коалицией платит за репрессию поддержкой, с узкой — общественными
благами в долгую. Ни один не выигрывает по обеим осям → развилка появляется.
Индекс `W` — таблица из 12 чисел по `powerStructure`, который уже размечен.

Адресный ответ на дефект «легитимность делает подавление и сильнее, и дешевле».

### Накопление капитала (Харрод–Домар → Солоу)

```
g = s/v − δ          (Харрод–Домар, первый шаг)
ΔK = I − δK ; Y = A·K^α·L^(1−α)    (Солоу, полная форма)
```

**`INFRASTRUCTURE_SPENDING_GROWTH_COEFFICIENT = 0.15` УЖЕ является `1/v`** — то
есть константа, выбранная на глаз, получает имя и калибруемый смысл.

Закрывает: замороженные `development`/`infrastructure` (становятся выходами от
`capital/population`), машину расхождения (убывающая отдача даёт конвергенцию —
механизм «экономического чуда» 1946–1960), односторонний рост (`s/v < δ` → падение).
`MAX_MONTHLY_GROWTH_RATE` снимается: рост ограничивается экономически, не клампом.

Цена: одно поле на регион (1399 чисел ≈ 28 КБ против 1,75 МБ сейва). Учебниковые
параметры: `α ≈ 1/3`, `δ ≈ 4–6%/год`. Иллюстрация: `s=0.20, v=4.0, δ=0.05` → 0%
(стационар); `v=2.0` (капитал разрушен войной) → +5%/год.

### Закон Оукена

```
Δu = −c·(g − g*)        поточечно
Σ Δu = α·T + β·Σ Δg     кумулятивно по длине эпизода  ← предпочтительно
```

Замыкает разорванную цепочку «спад → безработица → нестабильность»: `PoliticsTick`
УЖЕ потребляет `unemployment` через готовые пороги, а двигает её сейчас только
дефицит — экономический спад политически невидим.

Коэффициенты (Ball, Leigh & Loungani, 20 стран, 1980–2011): медиана **−0,40**,
диапазон **−0,15 (Япония) … −0,85 (Испания)**; США −0,45, R² 0,82. Закон стабилен
(sup-Wald не отвергает). Оригинальные 0,3 у Окуня занижены отсутствием лагов;
с двумя лагами −0,43.

⚠️ **Кумулировать по длине спада, а не применять помесячно:** при том же падении
выпуска более длинная рецессия даёт больший рост безработицы (потенциал растёт).
На месячном тике лаги меняют коэффициент почти вдвое.

Окунь принимал `U* = 4,0%` для США на выборке **1947–1960** — прямой ориентир для
нашей эпохи. Не калибровать стартовые `u_n` по современным NAIRU.

### Долговая динамика и дефолт

```
d_t = [(1+r_t)/(1+g_t)] · d_{t−1} − p_t + sfa_t        (p — ПРОФИЦИТ, вычитается)
λ = (r−g)/(1+g)   — growth-adjusted rate
p* = d* · (r−g)/(1+g)   — «стабилизирующий» первичный баланс
```

Все входы уже есть: `debt`, `gdp`, `debtMonthlyInterestRate()`, `computeGrowthRate()`,
`budgetBalance + debtInterest`.

⚠️ **«Debt-stabilizing primary balance» — обманчивое имя.** Уравнение НЕУСТОЙЧИВО при
λ>0: если удерживать `p*` при `d₀ ≠ d*`, траектория взрывается. К `d*` сходится
только постоянный OVERALL balance. Практическое дефолтное значение: `λ = 0.01`.

**Триггер дефолта (Sargent–Wallace):** `r > g` И достигнут потолок спроса на
облигации → принудительная монетизация → инфляция. Это отличает страну с долгом
200% ВВП и низкой инфляцией (`r < g`) от страны с 60% и гиперинфляцией.

**Кривая Лаффера для сеньоража:** `S(π) = A·π·e^(−απ)`, максимум при `π* = 1/α`;
эмпирически ≈ **174% годовых**, наблюдаемый потолок сеньоража ~6% ВВП. Выше `π*`
ужесточение печати СНИЖАЕТ доход.

**Дефицит → инфляция нелинеен по режиму:** в высокоинфляционных странах −1% ВВП
баланса → **+4,2% инфляции**; в низкоинфляционных **незначимо**. Разделение
коэффициентов поднимает adjusted R² с 0,048 до 0,334 — **единый глобальный
коэффициент стирает сигнал**. Наша формула сейчас именно единая.

### Демографический переход, ведомый смертностью

Два такта: сначала падает смертность (медицина, санитария) при высокой рождаемости —
окно быстрого прироста; затем рождаемость догоняет. Смертность привязана к доходу
кривой Престона (вогнутая, `e0 = a + b·ln(GDPpc)`).

Чинит ПОРЯДОК стран, а не только знак: сейчас США первые в мире по приросту (2,48%/год
против реальных 1,77%), Китай почти последний (0,56% против реальных 1,51%),
Бразилия 0,81% против реальных 3,24%.

**Главный факт Престона — кривая СДВИГАЕТСЯ ВВЕРХ сама:** 75–90% мирового прироста
продолжительности жизни между 1930-ми и 1960-ми объясняется не доходом, а диффузией
здравоохранения. Чтобы достичь `e0` 40–60 лет, стране нужен был доход **почти втрое
выше в 1930-х, чем в 1960-х** → ≈ **+0,19 года `e0` в год «бесплатно»**.

**Вклад дохода против технологии резко переключается в наши годы:**

| Период | Доход | Медицинское знание |
|---|---|---|
| 1913–1950 | **26,3%** | **73,7%** |
| 1950–1970 | **98,4%** | 1,6% |
| 1870–2015 | 50,2% | 49,8% |

То есть в первые два десятилетия кампании режим меняется: сначала бесплатный
послевоенный скачок здоровья, затем эпоха, где продолжительность жизни покупается
экономикой.

**Одно число на входе → полный профиль смертности существует:** log-quadratic
(Wilmoth et al. 2012), `log(m_x) = a_x + b_x·h + c_x·h² + v_x·k`, где `h = log(5q0)`,
`k = 0` по умолчанию. Константный блок **~138 чисел**, превосходит Coale-Demeny и
UN 1982 по точности. ⚠️ Лицензии на ОПУБЛИКОВАННЫЕ коэффициенты несвободны — путь
через переобучение (см. §3).

⚠️ **Отскок рождаемости при высоком развитии (J-кривая) НЕ закладывать.** Гипотеза
оспорена; на национальном уровне после 2010 рождаемость упала везде. Асимметрия
ошибки: монотонная модель ошибётся на десятые доли, J-кривая при отсутствии
разворота даёт РАСТУЩЕЕ население развитых стран и ломает позднюю игру. Вместо неё —
насыщение: пол TFR 1,3–1,7, зависящий от политик, а не от одного дохода.

### Гравитация торговли — надстройка над пулом, не замена

```
X_ni = π_ni · X_n ,   π_ni = S_i·φ_ni / Φ_n ,   Σ_i π_ni = 1
```

**Не конфликтует с решением `TRADE.md:148` «единый мировой пул принят как есть»:**
пул определяет объём и цену, гравитация — только контрагентов. Доли суммируются в 1.

**Производительность измерена, а не оценена:** точная система Anderson–van Wincoop
на 157 стран решается за **0,5 мс** (30 итераций, ошибка баланса 2,4e−06). Ни
remoteness-индекс, ни отсечение по top-k не нужны.

1946 — не «пик стабильной системы», а НАЧАЛО распада: Филиппины независимы 4 июля
1946, война в Индокитае с декабря 1946, Индия и Пакистан — 1947, Индонезия воюет с
1945. При этом торговые связи переживают политическую деколонизацию на десятилетия.
**Правильная форма — не константа, а связь с датой разрыва и хвостом затухания:**
политическая рвётся в момент независимости, торговая инерция уходит медленно.
Даёт метрополии выбор — удерживать силой или конвертировать в торговое влияние.

⚠️ **Эластичность по расстоянию для 1946 НЕ занижать.** Долгосрочный тренд подсказал
бы обратное, но единственная оценка рядом с датой — гравитационный срез на **1949**:
−0,82…−0,95, то есть на уровне современного или выше, «из-за трудности восстановления
транспортных сетей после войны».

⚠️ Половина реальных пар стран не торгует вовсе. Простая гравитация даёт полностью
связный граф; принципиальный способ получить нули — фиксированные издержки выхода
на рынок, а не отсечение по top-k.

### Кривая Филлипса — только с отдельным уравнением ожиданий

```
π = λ·π^e + (1−λ)·π_{−1} − θ·(u − u_n) + shock
π^e = δ + β·π_{−1}
```

Наклон θ упал с ~0,7 (1970-е) до ~0,2 (сейчас); падение датируется 1980-ми.
⚠️ **Ловушка единиц:** современная оценка `κ = 0.0062` измеряется в других единицах
и НЕ подставляется вместо 0,2 — сопоставимый агрегатный аналог **0,34**.

**Нельзя хранить одну зашитую кривую** (критика Лукаса): Фридман предсказал слом за
два года до него — кривая стабильна только пока средний темп роста цен стабилен.
При λ → 1 условие «любой бум оплачивается равным спадом» перестаёт действовать.

### Financial repression — механика послевоенного долга

Отрицательные реальные ставки давали государству **3–5% ВВП в год**. Это, а не
профициты, объясняет: Британия 249,1% ВВП (1946–47) → 102,4% (1960–61); США 118,9%
(FY1946) → 54,4% (FY1960).

Числа по нашему году: реальные ставки США **−8,8% в 1946** (−8…−9% в 1945–47),
Италия **−47% в 1945**. Доля лет с отрицательным `r−g`: 61% для развитых, 75% для
развивающихся; сильно отрицательны во время мировых войн и между WWII и первым
нефтяным шоком.

⚠️ **Низкий `r−g` не должен давать игроку сигнал безопасности:** перед дефолтами
дифференциалы НЕ выше обычного, кризис приходит скачком МАРЖИНАЛЬНОЙ ставки.

### Инфляция 1946: снятие контроля цен — сдвиг УРОВНЯ, не темпа

США CPI: 1944 +1,6%, 1945 +2,3% (контроль цен), **1946 +8,5%, 1947 +14,4%**,
1948 +7,7%, **1949 −1,0%**, 1951 +7,9% (Корея).

Исследователи высокой инфляции специально исключают такие эпизоды: они «по природе
скорее корректировка УРОВНЯ, чем продолжающийся процесс». **Если смоделировать
отмену госконтроля как сдвиг темпа, экономика уйдёт в вечную гиперинфляцию от одного
административного решения.**

Контекст эпохи: худшая зарегистрированная гиперинфляция — Венгрия, август 1945 —
июль 1946. С 1947 гиперинфляции в рыночных экономиках стали редкостью: 1946 стоит
на границе эпох.

## 2. Рассмотрено и отклонено (с причиной)

| Модель | Причина |
|---|---|
| Fearon & Laitin, логит гражданской войны | Ключевой регрессор — доля горной местности; поля рельефа нет. Единица наблюдения страна-год, не регион-месяц |
| Collier & Hoeffler «жадность против обиды» | Нужны доля сырья в экспорте, диаспоры, образовательная статистика — нет |
| Power transition theory | Ключевой вход «неудовлетворённость статус-кво» невыводим; без него вырождается в «паритет = война» |
| Лестница эскалации Кана | Нарративная типология, не вычислимая функция состояния. Место — в промте LLM |
| Selectorate (полная) | Требует моделировать внутреннюю коалицию поддержки; чужая область |
| Двусторонняя гравитация (потоки N×N) | Противоречит записанному решению «единый мировой пул» |
| Anderson–van Wincoop полная мультилатеральная резистентность в регрессии | Не нужна: у нас ПРЯМАЯ задача (издержки известны), смещения не существует |
| Когортно-компонентный метод | Возрастная структура на регион = 1399×4 новых чисел + переписанный `PopulationTick` |
| Полные таблицы смертности (Coale-Demeny, UN 1982) | Сотни строк на страну; компактная параметризация сводится к кривой Престона внутри демперехода |
| Эндогенный рост (AK, Ромер, Лукас) | Отсутствие убывающей отдачи даёт ту же вечную дивергенцию, которую чиним |
| Мальтузианская модель | Мир после 1946 постмальтузианский — не тот режим |
| MV=PQ как отдельная подсистема | Нужны денежная масса и скорость обращения — двух полей нет, игрок их не наблюдает |
| Гетерогенный Ланчестер | Требует родов войск и попарных коэффициентов — микроменеджмент отвергнут |
| Полная модель Слэнчева с эндогенными предложениями | Требует переговорного канала с торгом по месяцам |
| Иерархия Лейка вместо `sphereOfInfluence` | Измерительная часть держится на данных вроде военных баз — их нет |
| Agent-based геополитика (GeoSim) | Требует полного обхода мира на шаг |
| Решение Нэша для дележа территории | `warScore` уже играет роль дележа; поверх него — вторая расходящаяся модель |
| Логистика как ЗАМЕНА демперехода | Ограничивает уровень, не исправляя направление. Дополняет, не заменяет |
| Гарнизонное соотношение (Quinlivan) | У всех стран 1946 военный блок нулевой — член мёртв до наполнения |

### Практические следствия

1. **Свободно лицензированного субнационального экономического датасета на 1946 не
   существует** — ни один не заходит раньше 1953, гриддовые идут декадами. Значит наш
   путь единственно возможный и чистый: национальный агрегат (Clio Infra, CC0) ×
   региональный вес (HYDE 3.2, CC0) = наша производная работа.
2. **Все рекомендованные ФОРМУЛЫ данных не требуют вообще** — это математические
   описания в литературе. Входы берутся из нашего состояния.
3. **Коэффициенты log-quad переобучить самим** на HMD (CC BY 4.0) MIT-кодом
   (`MortalityEstimate`, функция `wilmoth()`). Результат — наше производное
   произведение, обязательство только атрибуция. Побочная выгода: можно сузить
   выборку под послевоенный диапазон.
4. **Провенанс важнее аргумента «это факты»:** после ECJ C-304/07 способ переноса не
   имеет значения. Ценность независимой сверки — аудируемый провенанс, ровно то,
   чего не хватило в истории с GADM.
